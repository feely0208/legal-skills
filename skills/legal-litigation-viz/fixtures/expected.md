# 验收检查点（fixtures/case-01.json）

```bash
node scripts/render-cli.mjs fixtures/case-01.json -o /tmp/viz.html
```

## 必须包含
1. 标题「张某诉李某民间借贷纠纷」与案号；
2. 时间轴 4 条，按日期升序（2024-05-01 → 2024-05-02 → 2025-05-01 → 2026-03-10）；
3. 「原告 / 申请人视角」标签（side=plaintiff）；
4. 法律关系图里出现「张某」「李某」「民间借贷」；
5. 证据矩阵 3 行 × 3 个事实列，E1 对应 F1/F3，E2 对应 F2；
6. 争点 2 条，含「是否存在借贷合意」；
7. 「证据缺口」列出「现金 5 万元」那条；
8. 页脚有「不构成法律意见」；
9. 文件是单个 HTML，无外部 CSS/JS 依赖（徽章图片除外）。

## 不得包含
1. 不得出现未在输入里的事实/金额/日期；
2. 日期不得倒序；
3. 不得把「赠与」写成己方事实（它是对抗辩，只能在 issues.theirs）。
