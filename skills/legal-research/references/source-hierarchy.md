# 法源效力、新旧法时效与引用格式

> 本文件是 `legal-research` 的校验口径。所有条号、日期在引用前仍需以国家法律法规数据库（flk.npc.gov.cn）现行文本为准。

## 一、法源效力层级（从高到低）

| 层级 | 形式 | 制定/发布机关 | 能否作为裁判依据 | 检索注意 |
|---|---|---|---|---|
| 1 | 宪法 | 全国人大 | 是（极少直接援引） | 一般通过下位法落地 |
| 2 | 法律 | 全国人大及其常委会 | 是 | 注意修正年份与施行日 |
| 3 | 行政法规 | 国务院 | 是 | 常以「条例」「规定」「办法」命名 |
| 4 | 地方性法规 | 省级、设区市人大及其常委会 | 是（仅本辖区） | 先确认辖区，再看是否与上位法冲突 |
| 5 | 自治条例、单行条例 | 民族自治地方人大 | 是（可依法变通） | 变通规定优先适用，但不得违背法律基本原则 |
| 6 | 部门规章、地方政府规章 | 国务院部门、省级/设区市政府 | 参照 | 不能用来否定法律、行政法规 |
| 7 | 司法解释 | 最高法、最高检 | 是 | 不得与法律冲突；注意是否被新解释取代 |
| 8 | 指导性案例 | 最高法案例指导工作办公室 | 应当参照 | 只引裁判要点，不引未生效裁判 |
| 9 | 会议纪要（九民纪要等） | 最高法会议 | 否 | 不能作裁判依据援引，只能在说理部分参照 |
| 10 | 其他案例、学术观点、媒体文章 | — | 否 | 只作线索，不能写进「依据」 |

### 三条容易踩的线

1. **纪要不是法。** 写「根据《九民纪要》第 X 条判决」是错的；正确写法是「参照《九民纪要》第 X 条的说理」。
2. **规章只能参照。** 部门规章与法律冲突时，适用法律；不能用规章给当事人加设法律没有的义务。
3. **地方性法规有边界。** 跨省交易不能拿 A 省的地方性法规去约束 B 省的行为。

## 二、冲突适用四规则

| 规则 | 含义 | 常见错法 | 例子 |
|---|---|---|---|
| 上位法优于下位法 | 效力高的优先 | 用部门规章否定法律 | 用部委办法限制法律赋予的解除权 |
| 特别法优于一般法 | 同一层级、同一事项，特别规定优先 | 只引一般法，漏掉特别规定 | 劳动用工先看《劳动合同法》，再看《劳动法》 |
| 新法优于旧法 | 同一机关、同一事项，新法优先 | 继续引已废止旧法 | 2021-01-01 后仍引《合同法》 |
| 法不溯及既往 | 原则上适用行为时法 | 用新法评价旧行为 | 2020 年的合同不能直接套 2023 年新规 |

**例外要写清**：法律另有规定的「有利溯及」、跨法行为的「分段适用」，都必须在报告里单独说明，不能一句「适用新法」带过。

## 三、新旧法时效校验

### 3.1 必查的废止/替换（2021-01-01）

《民法典》施行后，下列法律同日废止，**一律不得再引**：

| 旧法 | 改引 | 备注 |
|---|---|---|
| 合同法 | 民法典合同编 | 条号不是平移，逐条核对 |
| 物权法 | 民法典物权编 | 担保规则另有司法解释 |
| 担保法 | 民法典合同编、物权编 | 注意保证方式推定规则变化 |
| 侵权责任法 | 民法典侵权责任编 | — |
| 婚姻法 | 民法典婚姻家庭编 | 离婚冷静期等为新增 |
| 继承法 | 民法典继承编 | 遗嘱形式有变化 |
| 民法总则 | 民法典总则编 | 条号基本延续，仍需核对 |
| 民法通则 | 民法典总则编 | 部分内容未保留 |

配套：合同法解释（一）（二）随合同法废止；劳动争议四个旧解释被法释〔2020〕26号《劳动争议解释（一）》吸收。
另注意：《劳动争议解释（二）》自 2025-09-01 施行，竞业限制等规则有新增，涉及劳动案件时须同时核对（一）（二），不得只引（一）。

### 3.2 修订后条号重排、必须重查的法律

| 法律 | 现行版本 | 风险 |
|---|---|---|
| 公司法 | 2023 年修订，2024-07-01 施行 | 条文总数与旧法不同，旧条号指向不同内容 |
| 民事诉讼法 | 2021、2023 两次修正 | 起诉条件、举证责任、涉外编条号有调整 |
| 行政处罚法 | 2021 年修订 | 处罚种类、程序条号调整 |
| 劳动合同法 | 2012 年修正，2013-07-01 施行 | 劳务派遣条款调整 |
| 劳动争议解释（二） | 2025-09-01 施行 | 新增规则，需与解释（一）合并核对 |
| 工伤保险条例 | 2010 年修订，2011-01-01 施行 | 工亡补助金标准按年调整 |

### 3.3 时间效力三问（每份报告都要答）

1. **行为/合同成立时**，有效的是哪一版？
2. **起诉/裁判时**，现行的是哪一版？
3. 有没有**过渡条款**规定「施行前发生的……适用旧法」？

《民法典时间效力规定》（法释〔2020〕15号）确立的一般规则是：民法典施行前的法律事实引起的纠纷，适用当时的法律，但该规定列明的例外情形适用民法典。引用时需核对具体条款，不要概括成「一律适用旧法」。

### 3.4 一个必须分段的典型：民间借贷利率

- 2020-08-20 之前受理的案件，按当时的司法解释（24%/36% 两线三区）处理；
- 2020-08-20 之后新受理的一审案件，利率上限为合同成立时一年期 LPR 的四倍；
- 跨 2020-08-20 的借款，利息通常需要**分段计算**，不能全期套一个标准。

LPR 具体数值必须查当期公布值，**不得凭记忆写**。本技能不内置 LPR 数据。

## 四、引用格式

```
《中华人民共和国民法典》第五百七十七条
《中华人民共和国劳动合同法》第四十七条第一款
《最高人民法院关于适用〈中华人民共和国民法典〉合同编通则若干问题的解释》（法释〔2023〕13号）第X条
《全国法院民商事审判工作会议纪要》（法〔2019〕254号）第5条（仅参照说理）
（2023）浙0302民初1234号民事判决书（案号、法院、日期、要旨四要素齐全才可引）
```

规则：

1. 首次全称，之后可「以下简称《民法典》」；
2. 条、款、项依次写：「第 X 条第 X 款第 X 项」，不写「第 X 条之 X」；
3. 司法解释先全称后文号；文号记不清就只写全称并标【文号待核】；
4. 不写「根据相关法律规定」「依据国家有关规定」这类无出处表述；
5. 案例必须四要素齐全；缺一项就不写，或明确标【待核验】。

## 五、检索路径与检索式

| 找什么 | 去哪 | 说明 |
|---|---|---|
| 法律、行政法规、地方性法规、司法解释 | 国家法律法规数据库 flk.npc.gov.cn | 首选，看「现行有效」标识与施行日期 |
| 司法解释、指导性案例 | 最高人民法院官网、最高检官网 | 核对是否被新解释修改 |
| 裁判文书 | 中国裁判文书网 wenshu.court.gov.cn | 注意公开率下降，不能以「没搜到」推定不存在 |
| 权威案例 | 人民法院案例库 | 入库案例参考价值高于普通文书 |
| 商业检索 | 北大法宝、威科先行等 | 需订阅；注意其标注的时效状态 |

检索式写法：`核心关键词 + 法条编号 + 案由 + 法院层级 + 时间范围`。
例：`"违约金" "过分高于" "第五百八十五条" 案由:买卖合同纠纷 2021-2026 中级法院`。

离线环境下，把检索式和路径写进报告，由用户自行执行并回填，**不要伪造检索结果**。

## 六、报告交付前自检清单

- [ ] 每个结论后都能指到具体条号/文号/案号
- [ ] 已确认没有引用 2021-01-01 废止的七部旧法
- [ ] 条号未超出该法条文总数（民法典 1260 条、劳动合同法 98 条、劳动争议调解仲裁法 54 条、社会保险法 98 条、工伤保险条例 67 条）
- [ ] 修订过的法（公司法、民诉法、行政处罚法）已按现行文本重查条号
- [ ] 时间效力三问都有答案，跨法行为写了分段适用
- [ ] 每个数值（LPR、社平工资、赔偿标准）都有来源或标【待核验】
- [ ] 会议纪要、普通案例没有被写成「法律依据」
- [ ] 结论用「可以主张/通常/倾向于」，没有「必然/一定/保证」
- [ ] 报告末尾有依据清单与「AI 辅助生成，需承办律师复核」
- [ ] 检索路径可执行，没有编造「已检索到」的案号
