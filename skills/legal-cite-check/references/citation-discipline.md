# 引用纪律与常见错误

## 一、法条引用标准格式

```
《中华人民共和国民法典》第五百七十七条
《中华人民共和国民事诉讼法》第一百二十二条第一款
《最高人民法院关于适用〈中华人民共和国民法典〉合同编通则若干问题的解释》（法释〔2023〕13号）第一条
```

规则：

1. 首次出现用全称，之后可用「以下简称《民法典》」；
2. 条、款、项依次写明：「第 X 条第 X 款第 X 项」；
3. 司法解释先写全称，再写文号（法释〔年份〕序号）；
4. 不写「根据相关法律规定」这类没有出处的表述——宁可不写。

## 二、五类高频错误

### 1. 引用已废止的旧法（最常见）

| 错误写法 | 正确写法 | 说明 |
|---|---|---|
| 《合同法》第 107 条 | 《民法典》第 577 条 | 合同法 2021-01-01 废止 |
| 《婚姻法》第 32 条 | 《民法典》第 1079 条 | 婚姻家庭编 |
| 《物权法》第 9 条 | 《民法典》第 209 条 | 物权编 |
| 《担保法》第 18 条 | 《民法典》第 688 条（连带责任保证） | 担保制度另有司法解释 |
| 《侵权责任法》第 6 条 | 《民法典》第 1165 条 | 侵权责任编 |
| 《民法总则》第 143 条 | 《民法典》第 143 条 | 总则编 |

注意：**不是条号一一对应**。合同法 107 条对应民法典 577 条，但多数条文是重写的，必须回原文核对，不能按序号平移。

### 2. 条号越界

模型会「顺着序号编」出一条不存在的条文。典型：

- 《民法典》第 1300 条 → 民法典共 1260 条，不存在；
- 《劳动合同法》第 120 条 → 共 98 条；
- 《刑法》第 500 条 → 共 452 条。

处理：定位到该法最后一编/章，按条文主题重新找，不要猜邻近条号。

### 3. 旧司法解释继续被引用

| 旧解释 | 现状 |
|---|---|
| 法释〔2001〕14号 劳动争议解释 | 2021-01-01 被法释〔2020〕26号《劳动争议解释（一）》吸收 |
| 法释〔2006〕6号 劳动争议解释（二） | 同上 |
| 法释〔2010〕12号 劳动争议解释（三） | 同上 |
| 法释〔2013〕4号 劳动争议解释（四） | 同上 |
| 合同法解释（一）（二） | 随合同法废止，改引民法典合同编通则解释（法释〔2023〕13号） |

### 4. 修订后条文序号整体重排

- **公司法**：2023 年修订、2024-07-01 施行，266 条，序号与旧法不同；
- **民事诉讼法**：2021、2023 两次修正，涉外编等条文序号有调整；
- **行政处罚法**：2021 年修订，序号调整。

这些法本身有效，但**旧条号可能指向完全不同的内容**，必须重查。

### 5. 案号与案例

- 案号格式：`（年份）法院代字 + 案件类型代字 + 序号 + 号`，例如「（2026）浙0302民初1234号」；
- 格式对不代表案件真实存在。离线无法核验，必须到中国裁判文书网 / 人民法院案例库 / 法院系统核对；
- 引用案例要写清：案号、法院、裁判日期、裁判要旨来源。四缺一就别写。

## 三、修改示例

原文：

> 根据《合同法》第一百零七条，被告应承担违约责任。

核验后：

> 根据《民法典》第五百七十七条，被告应承担违约责任。
> （原引《合同法》已于 2021-01-01 废止；条文序号已变，已核对现行文本。）

## 四、把核验写进交付流程

1. 任何对外文书生成后，先跑 `check_citations.py`；
2. material 级错误清零才允许交付；
3. `citations.md` 随文书归档，作为「人工复核」的留痕；
4. 律所内部可把 `--strict` 挂到文书模板的发布检查里。

## 五、边界

本索引只回答「这条法是否存在、是否已废止、条号是否越界」。
它不回答：

- 这条法是否适用于本案；
- 条文的最新修订文本是否与索引一致（索引有核对日期）；
- 案例是否真实、裁判要旨是否被后续裁判改变。

这三件事只能由承办律师完成。
