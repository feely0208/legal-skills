# 引用核验技能

## 这个技能解决什么

AI 生成的法律文书最常见、也最贵的错误不是文风，是**引用**：

- 引用了 2021 年就已废止的《合同法》《婚姻法》《物权法》；
- 条号超出该法条文总数（如《民法典》第 1300 条，民法典只有 1260 条）；
- 继续引用已被新解释取代的旧司法解释（如法释〔2001〕14号）；
- 案号看起来像真的，实际查无此案。

本技能做的是**机器能核验的那部分**，并把机器核验不了的部分明确标成「需人工核验」——不把「没查到」说成「没问题」。

## 输入

- 一份文书：`.md` / `.txt` / `.docx`（`.docx` 需 `pip install python-docx`）
- 或者一个目录（批量核验，支持递归）

## 工作流程

### 第一步：先跑脚本

```bash
python3 scripts/check_citations.py <文书或目录> [-o 输出目录] [--strict]
```

输出三份文件（默认放在输入同级的 `引用核验/` 目录）：

| 文件 | 内容 |
|---|---|
| `citations.csv` | 逐条核验表：文件、行号、原文、状态、级别、说明（UTF-8 BOM，Excel 双击可开） |
| `citations.md` | 给人看的报告：汇总 + 必须处理项 + 需人工核验项 + 逐条明细 |
| `*.核验标注.md` | 在原位置给问题引用加上 `〔⚠️失效〕`/`〔⚠️越界〕`/`〔⚠️待核〕` 标记 |

`--strict`：存在 material 级错误时退出码 1，可挂到 CI 或发布前检查。

### 第二步：按状态处理

| 状态 | 含义 | 怎么处理 |
|---|---|---|
| `OUTDATED` | 引用了已废止/被取代的法律或解释 | **必须改**。按报告里的 `replaced_by` 改引新法；条号也要重查 |
| `OUT_OF_RANGE` | 条号大于该法条文总数 | **必须改**。多半是模型编的条号，回到原文找正确条号 |
| `RENUMBERED` | 法有效但条文序号因修订整体重排 | 提示级。逐条核对现行文本条号 |
| `PENDING` | 法律已公布但尚未生效 | 核对案件适用时点，别提前引用 |
| `UNKNOWN` | 法名不在离线索引内 | 人工核验。可能是地方性法规、简称或已失效文件 |
| `UNVERIFIED` | 案号 / 文号无法离线核验 | 人工核验。别直接写进提交法院的文书 |
| `OK` | 法名与条号在索引内 | **仍不保证适用**。只说明「这条存在」，不说明「这条对本案有效」 |

### 第三步：给出修改建议（不是只报错）

对每一条 material 错误，按下面格式回复：

```
第 16 行：《合同法》第一百零七条 → 已废止
建议改为：《民法典》第五百七十七条（违约责任）
注意：条文序号已变，请核对现行文本原文。
```

拿不准正确条号时，**不要猜**。写「需回到法条原文确认」，并把该条列入人工清单。

## 输出纪律

1. **只对索引负责。** 索引未收录的引用一律标 `UNKNOWN`，不得标 `OK`。
2. **不编案号、不编条号。** 核验不了就写「需人工核验」。
3. **通过 ≠ 适用。** 报告结尾必须保留这句，避免把「存在」误读成「有效」。
4. 核验结果随文书一起交付，作为「AI 生成 + 人工复核」的留痕。

## 索引范围

离线索引分两层：

1. **全量索引** `data/statutes-index.json`：**1,513 部**现行/待生效法律、行政法规、司法解释，含条文总数、效力状态、施行日期。来源 [chinese-law-corpus](https://github.com/lttxzmj/chinese-law-corpus)（CC0 1.0，文本取自国家法律法规数据库）。
2. **精编对照** `data/statutes.json`：12 部已被《民法典》等取代的旧法、4 件已被法释〔2020〕26号吸收的旧劳动争议解释、3 部条文序号因修订整体重排的法律，以及常用简称别名。

条数以官方文本中最大条号为准（刑法带附件和修正案，不能用顶层计数字段，否则会误报 505 条）。

索引是**可扩展的普通 JSON**：新增法律只需按现有字段追加，不用改脚本。
索引未覆盖的地方性法规、行业规章，请按同一结构补充，或人工核验。

## 适用边界

- 不联网、不上传、不调用任何模型；文书不出本机。
- 不做「这条法是否适用于本案」的判断——那是律师的工作。
- 不核验案例内容真伪，只对案号做格式识别和「需人工核验」提示。
- 结果不构成法律意见；正式提交前必须由承办律师核对官方原文。
