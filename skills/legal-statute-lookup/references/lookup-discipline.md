# 定位纪律：能查到哪、查不到怎么办

> 配套 `scripts/lookup.py` 与 `data/laws.json`。本文件规定「什么时候可以说找到了、什么时候必须说查不到」。

## 一、这个技能回答什么、不回答什么

| 能回答 | 不能回答 |
|---|---|
| 某法第 N 条的原文是什么 | 这条法现在是否仍有效（只能给语料标注的状态与施行日） |
| 这个条号在该法里是否存在 | 这条法的最新修正文本是否已变 |
| 这一条属于哪一编、哪一章 | 这条法是否适用于你的案件 |
| 哪个条号出现「试用期」等关键词 | 法院会怎么判、能不能赢 |
| 相邻条文是什么 | 地方性法规、部门规章、地方裁判口径 |

边界一句话：**本技能给「条文在哪、写了什么」，不给「所以你能赢」。**

## 二、条号怎么读

1. **条**：`第 X 条`。一条可以包含多款、多项。
2. **款**：条内自然段，另起一段即另一款。引用写「第 X 条第 X 款」。
3. **项**：款内以「（一）（二）」编号。引用写「第 X 条第 X 款第 X 项」。
4. **「之一」条文**：如「第 X 条之一」，是修法时插入的条文，不是笔误；本语料通常已按顺序重排，引用前核对官方文本。
5. **修正案条文**：刑法用「第 X 条」+ 修正案（十一）等表述，不写「修正案第 X 条」代替刑法条号。

常见错误：

| 错误 | 正确 | 原因 |
|---|---|---|
| 第 47 条（想说第 47 条第 2 款） | 第 47 条第 2 款 | 款不写清，指向不同规则 |
| 《劳动合同法》第 47 条之一 | 先核对是否存在该条 | 不是所有法都有「之一」 |
| 「民法典 585 条」 | 《民法典》第五百八十五条 | 正式引用用汉字条号、书名号 |

## 三、本地语料的覆盖与局限

**收录 29 部**（按类别）：

- 民事：民法典（1260 条）、民事诉讼法（306 条）、消费者权益保护法、广告法、反不正当竞争法
- 劳动社保：劳动合同法（98 条）、劳动法（107 条）、劳动争议调解仲裁法（54 条）、社会保险法（98 条）、工伤保险条例（67 条）
- 公司主体：公司法（266 条）、合伙企业法、企业破产法
- 刑事程序：刑法、刑事诉讼法
- 行政：行政诉讼法
- 知产：专利法、商标法、著作权法
- 数据与网络：个人信息保护法、数据安全法、网络安全法
- 资源与市场监管：土地管理法、城市房地产管理法、食品安全法、道路交通安全法
- 司法解释：民法典合同编通则解释、婚姻家庭编解释（一）、总则编解释

**没收录**：地方性法规、自治条例、部门规章、地方政府规章、绝大多数司法解释、党内法规、行业规范、国际条约。

**四条硬限制**：

1. 语料不是官方文本，可能有排版差异、旧版本残留；
2. `status`/`effectiveDate` 是语料标注，不是实时校验；
3. 顶层 `articleCount` 不可信（刑法带附件会算成 505），**以最大正文条号为准**；
4. 未收录 ≠ 不存在。地方规定、部门规章大量存在，只是不在本库。

## 四、条号重排：这些法不能凭记忆

| 法律 | 现行版本 | 处理 |
|---|---|---|
| 公司法 | 2023 修订，2024-07-01 施行，266 条 | 旧条号（如旧第 26 条出资）指向不同内容，必须重查 |
| 民事诉讼法 | 2021、2023 两次修正，2024-01-01 施行，306 条 | 起诉条件为第 122 条；其他条号引用前核对 |
| 行政处罚法 | 2021 修订 | 未收录，去 flk 查 |
| 劳动合同法 | 2012 修正，2013-07-01 施行 | 劳务派遣章节条号有调整 |
| 工伤保险条例 | 2010 修订，2011-01-01 施行 | 一次性补助标准按年调整，条文本身稳定 |
| 劳动争议解释 | 解释（一）2021-01-01；解释（二）2025-09-01 | 本库未收全文；竞业限制等规则须核对两份解释 |

判断口诀：**先看施行日，再看条号；施行日新于记忆的，一律重查。**

## 五、常见误查对照

| 用户说法 | 问题 | 正确处理 |
|---|---|---|
| 「劳动法第 47 条」 | 混淆《劳动法》与《劳动合同法》 | 先问是哪部；两法条号体系不同 |
| 「民法典第 1300 条」 | 超出 1260 条 | 报越界，回主题重找，不猜邻近条号 |
| 「合同法第 107 条」 | 已废止 | 改引《民法典》第 577 条，并说明不是平移 |
| 「社保法规定试用期不用缴」 | 与法条相反 | 引《社会保险法》第 58 条：用工之日起 30 日内登记 |
| 「第 82 条是赔偿金」 | 第 82 条是二倍工资，赔偿金是第 87 条 | 按主题重新定位 |
| 「竞业限制最长 3 年」 | 法定上限 2 年 | 引《劳动合同法》第 24 条 |
| 「仲裁时效 2 年」 | 劳动仲裁一般 1 年 | 引《劳动争议调解仲裁法》第 27 条；民事时效才是 3 年 |
| 「工伤认定单位有 1 年」 | 单位 30 日，职工 1 年 | 引《工伤保险条例》第 17 条 |

## 六、未收录时怎么办

1. 明确告知「本库未收录，不等于不存在」；
2. 给出检索路径：国家法律法规数据库 flk.npc.gov.cn → 按名称/发文字号检索 → 看「现行有效」标识与施行日期；
3. 地方规定：先确定省级/设区市，再到当地人大或政府门户的「法规规章」栏目；
4. 用户回填条号与原文后，再补速查卡；
5. 全程不猜条号、不写「大概是」。

## 七、风险标记口径

| 标记 | 含义 | 处理 |
|---|---|---|
| 🔴 | 法律已废止、条号越界、条文被新法取代 | 不能引用；改引现行法并重查条号 |
| 🟡 | 修订后条号可能重排、款/项指向不清、语料状态存疑 | 引用前核对官方文本，报告里注明 |
| ⚪ | 简称、表述差异、排版问题 | 提示即可，不影响引用 |

标记只说明「这条能不能直接用」，不说明案件结果。

## 八、输出前六项自检

- [ ] 条号 ≤ 该法最大正文条号
- [ ] 原文与脚本输出逐字一致，未改写
- [ ] 标明了「本地语料，非官方全文」
- [ ] 修订过的法已提示条号可能重排
- [ ] 关键词命中已说明「不等于适用」
- [ ] 未收录项已说明范围，没有编造
