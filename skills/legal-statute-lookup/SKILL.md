# 法条速查技能

## 这个技能解决什么

写文书、回客户、开庭前，最常见的动作是「那条是第几条来着」。凭记忆报条号，错一个数字就可能被对方抓住，或者引到修订前的旧条号上。

本技能只用**本地语料**做三件事：定位到条、给出条文原文、提示相邻条文与易错点。它不判断适用，也不冒充官方文本。

## 适用 / 不适用

| 适用 | 不适用 |
|---|---|
| 已知法名 + 条号，想看条文原文与所在编章 | 要逐字引用官方文本、核对最新修订 → flk.npc.gov.cn |
| 已知法名 + 主题（试用期、违约金、竞业限制），找条号 | 要判断该条能否支撑本案请求 → `legal-research` |
| 看到一个条号，想确认它属于哪一编/章、前后条是什么 | 要核对文书里已有引用是否失效/越界 → `legal-cite-check` |
| 口语描述场景，想找可能的法条入口 | 要出带结论和保留的意见书 → `legal-opinion` |
| 开庭前快速回忆条文与易错点 | 要算金额、写仲裁请求 → `legal-labor-arbitration` |

## 输入

**必需**：查询对象，四种形式之一：

1. 法名 + 条号：`劳动合同法 47`
2. 法名 + 主题：`民法典 违约金过高`
3. 纯条号：`第577条`（多部法都有，必须确认哪部）
4. 场景描述：`员工试用期最长能多久`

**可选**：地域（地方性法规）、时间（修订前后条号不同）、用途（引用 / 内部确认）。

信息不足时追问一次，不要连问五轮：纯条号先问「哪部法」；场景描述先给 1–2 个候选法名让用户选。

## 数据与边界

- 全文库：`data/laws.json`（随包 29 部常用法律、行政法规与司法解释，含 3 部民法典司法解释），逐条 `text`，含 `display` 与 `path`。
- **可选全量库**：下载「深鲸法条全文库」（1,513 部，约 6MB）后，把 `laws-full.json.gz` 放进 `data/`，脚本自动优先使用；`--list` 顶部会显示「语料：全量库 1,513 部」。
- 语料来源：chinese-law-corpus（CC0），**不是官方文本**；施行日与状态以数据标注为准，引用前仍要核对。
- 未收录的法律（如《票据法》《海商法》）→ 明确说「未收录」，给 flk.npc.gov.cn 路径，**不凭记忆补条号**。
- 法典条文数：以**最大正文条号**为准，不信顶层计数。刑法带附件会出现异常大条号，本库按 452 条处理。

## 工作流程

### 第零步：读法律档案

先读 `~/.deepwhale/深鲸法律档案.md`。不存在时，把仓库里的 `templates/法律档案.md` 复制过去，再逐项问用户：角色、立场、执业地域、行文风格、风险偏好、升级链。档案里没填的，不要假设。

速查本身不挑立场，但执业地域决定要不要补地方性法规，角色决定展开程度（律师要条号，当事人要白话）。

### 第一步：判断查询类型

| 类型 | 处理 | 风险 |
|---|---|---|
| 精确条号 | 跑脚本，核对是否超出最大条号 | 条号因修订重排 |
| 法名 + 主题 | `--keyword` 搜索，挑 3–5 条候选 | 关键词命中不等于适用 |
| 纯条号 | 必须先确认法名 | 多部法条号重复 |
| 场景描述 | 先转成 1–2 个法律概念，再定位 | 概念选错，整条路偏 |

### 第二步：跑本地定位

```bash
python3 scripts/lookup.py --list                        # 收录范围
python3 scripts/lookup.py 劳动合同法 47                  # 定位单条
python3 scripts/lookup.py 民法典 第五百八十五条           # 支持中文条号
python3 scripts/lookup.py --keyword 试用期 --law 劳动合同法 --limit 10
python3 scripts/lookup.py 公司法 47 --json               # 机器可读
```

输出只有三种结果：

1. **命中**：条号存在 → 出原文卡片。
2. **越界**：脚本报「未找到第 N 条（最大条号 M）」→ 说明条号可能因修订变动或本身有误，**不要换邻近条号硬凑**。
3. **未收录**：脚本报「未收录该法律」→ 说明不在 29 部范围内，给官方路径。

### 第三步：补要点，不补事实

脚本给的是原文与位置；要点、适用条件、易错点从 `references/statute-index.md` 取，取不到就只给原文，不要现编解读。

速查卡固定六项：

```
【定位】《劳动合同法》第 47 条（经济补偿的计算）
【原文】（脚本输出，逐字保留，不改写）
【位置】第四章 劳动合同的解除和终止
【要点】按工作年限每满一年一个月工资；6 个月以上不满 1 年按 1 年；不满 6 个月半个月。
【相邻】第 46 条（何时支付）、第 48 条（违法解除）、第 87 条（赔偿金 = 2 倍）
【易错】高收入者有三倍社平封顶 + 12 年上限；月工资是解除前 12 个月平均工资，不是实发。
【标记】⚪ 条号高置信；引用前仍建议核对官方文本
```

### 第四步：标风险等级

速查卡末尾加一行标记，三档：

- 🔴 不能引用：法律已废止、条号越界、条文已被新法取代；
- 🟡 引用前必核：修订后条号可能重排、款/项指向不清、语料状态与官方不一致；
- ⚪ 提示：表述差异、简称、排版问题。

三档只描述「这条能不能直接用」，不评价案件胜负。

### 第五步：把边界说清楚

回答结尾固定三句（可合并成一段）：

- 条文来自本地语料，**不是官方全文**，不能作为逐字引用依据；
- 条号可能因修订调整（公司法、民事诉讼法、行政处罚法尤其），引用前核对现行文本；
- 是否适用于本案，需结合事实判断，本技能不做适用结论。

## 输出规范

- 单条查询：`法条速查-<法名简称>-<条号>.md`，一页以内。
- 多条约查：`法条速查-<主题>-<YYYYMMDD>.md`，开头一张「条号—主题—核验状态」总表，每条一节。
- 对话里直接给卡也可以，但涉及对外引用时必须落成 `.md` 留痕。
- 需要作为正式文书附件时，用 `chinese-doc-formatter` 转 `.docx` / `.pdf`。
- 末尾固定：

```
来源：本地语料 data/laws.json（非官方全文）；正式引用以国家法律法规数据库 flk.npc.gov.cn 为准。
声明：AI 辅助生成，需承办律师复核。
```

## 质量闸门（交付前自检）

- [ ] 条号在该法最大条号范围内（民法典 1260、劳动合同法 98、劳动法 107、调解仲裁法 54、社会保险法 98、工伤保险条例 67、公司法 266）
- [ ] 原文与脚本输出一致，没有改写、没有「大意是」
- [ ] 没有把旧法（合同法/婚姻法/物权法等）条号当现行条号
- [ ] 修订过的法已提示「条号可能重排」，没有假装确定
- [ ] 命中关键词时说明「命中不等于适用」
- [ ] 未收录时说了「未收录」，没有编条号
- [ ] 明确写了「非官方全文」，给了官方核验路径
- [ ] 速查卡标了 🔴/🟡/⚪ 风险等级
- [ ] 带「AI 辅助生成，需承办律师复核」标识

## 输出示例

```markdown
# 法条速查：1 年期合同的试用期上限

| 条号 | 主题 | 核验状态 |
|---|---|---|
| 劳动合同法第19条 | 试用期期限 | 本地全文命中 |
| 劳动合同法第20条 | 试用期工资 | 本地全文命中 |
| 劳动合同法第83条 | 违法约定试用期的赔偿 | 本地全文命中 |

## 第 19 条
【原文】劳动合同期限三个月以上不满一年的，试用期不得超过一个月；劳动合同期限一年以上不满三年的，
试用期不得超过二个月；三年以上固定期限和无固定期限的劳动合同，试用期不得超过六个月。
同一用人单位与同一劳动者只能约定一次试用期。……
【位置】第二章 劳动合同的订立
【要点】1 年期合同试用期上限 2 个月；同一单位同一劳动者只能约定一次。
【相邻】第 20 条（工资下限）、第 83 条（超期赔偿）
【易错】「1 年合同最多 1 个月」是错的，1 年以上不满 3 年为 2 个月；只签试用期合同的，试用期不成立。

来源：本地语料 data/laws.json（非官方全文）；正式引用以 flk.npc.gov.cn 为准。
声明：AI 辅助生成，需承办律师复核。
```
