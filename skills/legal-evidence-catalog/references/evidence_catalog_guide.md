# 证据目录制作指南

以中国律师视角，系统梳理提交法院的证据目录（证据清单）制作规范。

## 一、法律依据

### 1.1 核心法条

| 法条 | 内容 | 适用说明 |
|------|------|---------|
| 《民事诉讼法》第66条 | 证据的8种法定类型 | 证据类型必须在此范围内选择 |
| 《民诉法解释》第99条 | 举证期限与证据目录提交 | 证据目录应在举证期限内提交 |
| 《证据规定》第19条 | 证据目录的格式要求 | 应逐一分类编号，说明来源、证明对象 |
| 《证据规定》第14条 | 电子数据的具体范围 | 电子数据的认定与归类 |
| 《证据规定》第20条 | 提交证据材料的要求 | 提供原件或经核对的复印件 |

### 1.2 实务规范

- 《人民法院民事诉讼举证须知》（各地法院版本）
- 《最高人民法院关于统一适用的民事诉讼证据规定》相关条款

## 二、证据目录格式规范

### 2.1 标准表格结构

法院证据目录标准格式（A4横向或纵向，建议横向以容纳更多列）：

| 列名 | 列宽建议 | 对齐方式 | 说明 |
|------|---------|---------|------|
| 序号 | 0.8cm | 居中 | 阿拉伯数字，从1开始 |
| 证据名称 | 3.5cm | 左对齐 | 证据的全称，加书名号 |
| 证据类型 | 1.5cm | 居中 | 8种法定类型之一 |
| 证据来源 | 2.5cm | 左对齐 | 证据从何处取得 |
| 页数 | 0.8cm | 居中 | 阿拉伯数字 |
| 份数 | 0.8cm | 居中 | 提交的份数 |
| 原件/复印件 | 1.2cm | 居中 | "原件"或"复印件" |
| 证明对象/证明目的 | 5.0cm | 左对齐 | 精炼描述，对准要件事实 |
| 备注 | 2.0cm | 左对齐 | 补充说明（可选） |

### 2.2 排版要求

- **纸张**：A4纸
- **页边距**：上2.54cm、下2.54cm、左3.18cm、右3.18cm（标准Word边距）
- **表头字体**：黑体，小四号（12pt），加粗
- **正文字体**：宋体，五号（10.5pt）
- **标题**：黑体，二号（22pt），居中
- **表头行**：深蓝色背景 (#2F5496)，白色字
- **表格线**：Grid样式，1pt实线
- **签署栏**：在表格下方，留有足够签署空间

## 三、各类证据的填写要点

### 3.1 书证

**常见类型**：合同、协议、函件、收据、发票、账册、银行流水、产权证、营业执照等

**填写要点**：
- 证据名称应包含文件性质和关键信息，如《XX采购合同》《2025年3月XX银行转账凭证》
- 页数填写文件的实际页码数（双面打印的按2页计算，单面按1页计算）
- 来源应明确，如"XX银行调取"、"原告自行保存"、"XX机关出具"等
- 如为多份同类文件，可集中一项但拉通列表说明，或逐一列出

### 3.2 电子数据

**常见类型**：微信聊天记录、短信记录、电子邮件、网页截图、电子支付记录、区块链存证、电子签章文件等

**填写要点**：
- 证据名称应包含平台/工具名称和内容摘要，如"原告与被告微信聊天记录截图（2025.3.1-2025.6.1）"
- 页数按截图的打印页数计算
- 来源注明"原告手机截图"、"XX邮箱导出"、"XX区块链存证平台存证"等
- 备注可说明"原始载体为原告手机，庭审时可当庭核验"
- 重要电子数据建议进行公证或第三方存证
- 法律依据：《证据规定》第93条（电子数据真实性审查）、第94条（推定真实的情形）

**电子数据真实性增强措施**：
- 当庭演示或登录原始载体
- 公证机构出具的公证书
- 第三方电子存证平台存证（如时间戳、区块链存证）
- 电子数据鉴定机构出具的鉴定意见

### 3.3 视听资料

**常见类型**：录音、录像、监控视频、电话录音等

**填写要点**：
- 证据名称应包含录制时间、地点、参与人物和内容概要，如"2025年5月15日原告XX与被告XX在XX咖啡厅的谈话录音"
- 页数可填"1份"或附文字整理稿的页码
- 来源注明录音/录像方式，如"原告手机录音"、"XX物业监控调取"
- 备注应注明"录音/录像文件存于光盘/U盘"或"附文字整理稿"
- 法律依据：未经对方同意录制的谈话录音的合法性存在争议，应根据《民诉法解释》第106条判断

**视听资料注意事项**：
- 私密空间的偷拍偷录不具有合法性（《民诉法解释》第106条）
- 公开场合或双方当事人参与的谈话录音通常具有合法性
- 应附完整的文字整理稿，标注时间轴
- 不应经过剪辑、拼接处理

### 3.4 物证

**常见类型**：实物、产品样品、涉案物品等

**填写要点**：
- 证据名称应描述物品的基本特征，如"XX品牌XX型号手机（IMEI: XXX）"
- 页数不适用时填"/"或"实物"
- 份数填实物数量
- 来源注明"原告购买"、"被告交付"等
- 备注注明"实物当庭提交"或"实物较大，照片代替，实物可现场勘验"
- 对于不便当庭提交的物证，可用照片或录像代替，但应说明原因

### 3.5 证人证言

**常见类型**：证人出庭申请书、书面证人证言、证人调查笔录等

**填写要点**：
- 证据名称注明证人姓名和作证方式，如"证人XX出庭作证申请书"、"证人XX书面证言"
- 页数按证明材料页数填写
- 来源注明"证人XX出具"
- 备注注明证人与当事人的关系（有利害关系/无利害关系）
- 法律依据：《证据规定》第67-78条（证人作证规则）

### 3.6 鉴定意见

**常见类型**：司法鉴定报告、价格评估报告、工程造价鉴定、笔迹鉴定、产品质量鉴定等

**填写要点**：
- 证据名称应包含鉴定机构和鉴定类别，如"XX司法鉴定中心出具的笔迹鉴定意见书（XX鉴[2025]文鉴字第XX号）"
- 来源注明鉴定机构全称
- 备注注明鉴定机构和鉴定人的资质情况
- 法律依据：《证据规定》第36条（鉴定意见形式要件）

### 3.7 勘验笔录

**常见类型**：现场勘验记录、物证检验记录等

**填写要点**：
- 由法院/相关机关制作的勘验笔录
- 证据名称注明勘验对象和时间，如"XX法院2025年6月1日对XX现场的勘验笔录"

### 3.8 当事人陈述

**常见类型**：当事人自书说明、情况说明、事实陈述

**填写要点**：
- 证据名称如"原告关于XX事实的情况说明"
- 应与其他客观证据配合使用，不宜作为核心孤证

## 四、证据排列原则

### 4.1 时间顺序排列

最常用的排列方式：按争议事实的客观发生时间先后排列证据，便于法官按时间脉络了解案情。

### 4.2 证明对象集中排列

将证明同一待证事实的多份证据集中排列，形成证据链。

**示例**：
- 证据1-3：证明合同关系的存在
- 证据4-6：证明已方已履行合同义务
- 证据7-8：证明对方违约的事实
- 证据9-10：证明损失金额

### 4.3 综合排列

结合时间顺序和证明对象，先按证明对象分组，组内按时间排序。

## 五、常见错误与注意事项

### 5.1 常见错误

| 常见错误 | 正确做法 |
|---------|---------|
| 证据类型填"其他" | 必须在8种法定类型中选择最接近的一类 |
| 证明目的写"证明全部诉讼请求" | 必须精炼到具体的待证事实 |
| 复印件标为原件 | 如实标注，虚假标注可能构成诉讼不诚信 |
| 页码填报"若干" | 必须填具体数字 |
| 证据名称使用过于简略 | 用全称/规范名称 |
| 同一份文件拆分到多个条目 | 一份完整的文件为一个条目 |
| 来源写"不知"或"不明" | 必须说清证据从何而来 |

### 5.2 法院提交须知

- **份数要求**：一般情况下，法院提交1份（入正卷），对方当事人各1份。具体以法院通知为准
- **举证期限**：必须在法院指定的举证期限内提交，逾期可能不被采纳
- **原件留存**：复印件提交法院，原件自行妥善保存，庭审时带至法庭以备核对
- **装订要求**：证据较多的应装订成册，附目录

### 5.3 电子证据特别注意事项

1. 截屏打印时应显示完整的时间信息
2. 聊天记录应保持连续性，不得断章取义
3. 电子邮件应打印完整的邮件头信息（发件人、收件人、时间、主题）
4. 网页证据建议公证或打印时保留完整的URL和时间
5. 电子支付记录应有银行或支付平台的官方印章/电子签章

## 六、模板参考

### 6.1 证据目录标题格式

```
                    证 据 目 录

案号：（XXXX）XX民初XX号
案由：XX纠纷
原告：XXX
被告：XXX

提交人：原告 XXX                    提交日期：XXXX年XX月XX日
```

### 6.2 证据目录尾部格式

```
提交人声明：
以上证据材料经本人核对，复印件与原件一致。

提交人（签名/盖章）：
日期：    年    月    日
```
