# 阅卷笔录技能

以中国执业律师视角，全面阅读并分析案卷材料，系统性梳理案件事实、证据体系、争议焦点、法律适用和程序事项，形成专业规范的阅卷笔录，最终在桌面生成以案件名命名的文件夹，内含 Word 阅卷笔录、PDF 文件、Markdown 报告和交互式思维导图。

## 完整工作流程

### 第零步：收集案件信息

在开始阅卷分析前，向用户确认以下信息（信息充分时直接开始）：

#### 必须确认

| 信息项 | 说明 |
|--------|------|
| 阅卷人信息 | 阅卷律师/代理人姓名、所在律所 |
| 案件信息 | 案号、审理法院、案由、当事人名称（原告/被告/第三人全称） |
| 案卷材料 | 需阅卷的文件路径列表（逐一读取，如起诉状、答辩状、证据、庭审笔录等） |

#### 自动判断阅卷视角

若用户未明确说明代理方，从以下线索自动推断：
- **起诉状/原告证据** → 阅卷人可能代理原告
- **答辩状/被告证据** → 阅卷人可能代理被告
- **案由和材料性质** → 综合判断阅卷目的
- **用户表述** → "我方的证据"、"对方的起诉状"等措辞

**视角差异**：

| 维度 | 原告方阅卷 | 被告方阅卷 |
|------|-----------|-----------|
| 关注重心 | 己方举证是否充分、对方答辩要点 | 原告证据漏洞、己方抗辩依据 |
| 事实梳理 | 按请求权基础梳理要件事实 | 按抗辩事由梳理反驳事实 |
| 证据评估 | 己方证据链完整度 | 对方证据三性瑕疵 |
| 策略重点 | 补充举证、强化证明 | 瓦解对方证明体系 |

#### 选填信息

| 信息项 | 说明 |
|--------|------|
| 阅卷日期 | 首次阅卷及后续补充阅卷日期 |
| 审理阶段 | 一审/二审/再审/重审 |
| 审理程序 | 普通程序/简易程序/特别程序 |
| 是否已开庭 | 已开庭/未开庭/多次开庭 |
| 特殊说明 | 保全/管辖异议/反诉/追加当事人等特殊情况 |

### 第一步：读取案卷材料

用 `scripts/read_evidence.py` 逐份读取案卷文件：

```bash
python "<skill目录>/scripts/read_evidence.py" "文件路径" --output "/tmp/review_doc_N.txt"
```

支持以下格式：

| 格式 | 扩展名 | 读取方式 |
|------|--------|---------|
| PDF | .pdf | pdfplumber / PyPDF2 |
| Word | .docx | python-docx |
| 旧版Word | .doc | olefile |
| 图片 | .jpg/.jpeg/.png/.bmp | AI视觉识别（通过Read工具直接读取） |
| Excel | .xlsx/.xls | openpyxl / xlrd |
| CSV | .csv | 内置（自动检测编码） |
| 纯文本 | .txt | 内置（自动检测编码） |
| JSON | .json | 内置 |
| HTML | .html/.htm | beautifulsoup4 |

**图片证据处理**：对于图片格式的文件（.jpg/.jpeg/.png/.bmp），脚本会返回 `[IMAGE]` 标记及文件路径，此时应使用 **Read 工具**直接读取图片文件，Claude 将自动识别图片中的文字内容和图像信息。

如果文本超过 50000 字符，用 `--max-chars` 参数调整上限。

全部材料读取完成后，开始阅卷分析。

### 第二步：案卷材料分类梳理

**务必同时阅读 `references/review_notes_guide.md` 获取阅卷笔录的格式规范、各类案卷材料的审查要点和实务注意事项。**

将读取的材料按以下维度分类：

#### 2.1 诉讼文书类

| 材料类型 | 核心审查内容 |
|---------|-------------|
| 起诉状 | 诉讼请求（金额/行为/确认）、请求权基础、事实理由概述 |
| 答辩状 | 答辩意见、事实抗辩、法律抗辩 |
| 反诉状 | 反诉请求、反诉事实与理由 |
| 变更诉讼请求申请书 | 变更内容及对审理范围的影响 |
| 追加当事人申请书 | 追加当事人的理由及影响 |

#### 2.2 程序文书类

| 材料类型 | 核心审查内容 |
|---------|-------------|
| 受理/应诉通知书 | 立案时间、举证期限起算 |
| 举证通知书 | 举证期限截止日、证据交换安排 |
| 开庭传票 | 开庭时间/地点、审判组织成员 |
| 保全裁定/协助执行 | 保全范围、金额、期限 |
| 管辖权异议裁定 | 管辖权争议是否存在、裁定结果 |
| 追加/变更当事人裁定 | 当事人变化对诉讼的影响 |

#### 2.3 证据材料类

| 材料类型 | 核心审查内容 |
|---------|-------------|
| 原告证据 | 证明目的、证据链完整度、三性评估 |
| 被告证据 | 证明目的、反证价值、三性评估 |
| 法院调取证据 | 调取原因、证据内容、对双方影响 |
| 鉴定意见 | 鉴定机构资质、检材来源、鉴定结论可靠性 |
| 勘验笔录 | 勘验过程、勘验结论 |

#### 2.4 庭审材料类

| 材料类型 | 核心审查内容 |
|---------|-------------|
| 庭审笔录 | 双方陈述、举证质证过程、证人作证内容、法庭询问要点 |
| 代理词/辩护词 | 双方核心论点、法律适用观点 |
| 质证意见 | 对方对己方证据的质疑要点 |
| 补充意见 | 庭后补充的主张和证据 |

### 第三步：系统性案卷分析

#### 3.1 案件大事记（时间线）

按时间顺序梳理案件关键节点：

```
YYYY年MM月DD日  →  事件描述（来源：证据X）
YYYY年MM月DD日  →  事件描述（来源：诉状/答辩状/证据X）
```

每个事件必须标注信息来源，区分"有证据支撑的事实"和"单方主张的事实"。

#### 3.2 当事人主张对照

| 争议事项 | 原告主张 | 被告主张 | 相关证据 | 分析意见 |
|---------|---------|---------|---------|---------|
| XX事实 | ... | ... | 证据X/Y | 哪方主张更有证据支撑 |

#### 3.3 证据体系评估

**己方证据评估**（如果代理一方）：

| 待证事实 | 证据支撑 | 证明力评估 | 补强建议 |
|---------|---------|-----------|---------|
| XX要件事实 | 证据1、证据3 | 充分/较充分/不足 | 需补充XX证据 |

**对方证据弱点识别**：

| 对方证据 | 薄弱点 | 可利用程度 | 质证策略建议 |
|---------|-------|-----------|-------------|
| 证据X | 复印件/单方制作 | 高/中/低 | 要求提供原件 |

#### 3.4 法律适用分析

| 分析维度 | 内容 |
|---------|------|
| 案由定性 | 准确的案由及法律依据 |
| 请求权基础 | 适用的实体法条文及其构成要件 |
| 抗辩事由 | 对方可能提出的抗辩及应对 |
| 争议焦点预判 | 法庭可能归纳的争议焦点 |
| 举证责任分配 | 各方就各待证事实的举证责任 |
| 相关判例 | 最高法院/上级法院类似案件裁判规则 |

#### 3.5 程序事项核查

| 核查事项 | 状态 | 说明 |
|---------|------|------|
| 管辖权 | 有无/已处理/待处理 | — |
| 诉讼时效 | 是否届满/是否中断 | — |
| 举证期限 | 截止日期/是否需延期 | — |
| 财产保全 | 有无/范围/到期日 | — |
| 当事人适格 | 是否合格/是否需追加 | — |
| 反诉 | 是否提出/内容 | — |

### 第四步：阅卷摘要与策略建议

#### 4.1 核心事实摘要

以最精炼的语言概述案件的来龙去脉（300字以内），涵盖：
- 当事人之间关系的性质
- 争议发生的核心事实
- 各自主张的关键理由

#### 4.2 案件风险评估

| 风险维度 | 评估等级 | 说明 |
|---------|---------|------|
| 事实认定风险 | 高/中/低 | — |
| 法律适用风险 | 高/中/低 | — |
| 证据风险 | 高/中/低 | — |
| 程序风险 | 高/中/低 | — |
| 执行风险 | 高/中/低 | — |

#### 4.3 后续工作建议

1. 需要补充的证据
2. 需要进一步核实的事实
3. 需要申请的事项（鉴定/勘验/证人出庭/调取证据等）
4. 调解/和解策略建议
5. 庭审准备要点

### 第五步：生成JSON并输出全部文件

阅卷分析完成后，将结果整理为 JSON（格式见下方），依次运行生成脚本。

#### 5.3 运行生成脚本（顺序运行）

  "~/Desktop/<案件名称>阅卷笔录/<案件名称>-阅卷笔录.docx" \

**PDF 转换说明**：
- 脚本按 `docx2pdf (需Windows上安装Word)` → `LibreOffice` → `reportlab` 的优先级尝试
- 如果 Word 已安装，优先使用 `docx2pdf` 获得最佳转换效果
- 如果所有方法都失败，会打印安装提示，此时仅交付 DOCX、MD 和思维导图文件

## 阅卷原则

### 必须做到

1. **全面覆盖**：案卷中每份材料均须审阅，不得遗漏
2. **事实与主张分离**：明确区分"有证据支撑的事实"和"单方主张"
3. **时间准确**：大事记中的日期必须与案卷材料一致
4. **法律依据准确**：只引用现行有效法律法规，不确定时以"根据相关法律规定"代替
5. **风险如实评估**：不隐瞒己方不利事实，客观评估风险
6. **策略务实可行**：建议必须可操作，有明确的时间和责任人
7. **证据评估客观**：既评估己方证据强弱，也评估对方证据质量
8. **程序节点清晰**：标注所有重要程序节点及期限
9. **来源可追溯**：每个事实分析都应能回溯到案卷具体位置
10. **用语专业规范**：使用规范的法律术语，避免口语化表达

### 禁止事项

- 不得编造案卷中不存在的证据或事实
- 不得编造不存在的法条编号或案号
- 不得隐瞒对己方不利但客观存在的案卷材料
- 不得使用侮辱性/攻击性语言评价对方当事人或代理人
- 不得在未经核实的情况下认定某项证据"虚假"或"伪造"
- 不得对案件结果做出承诺性判断
- 不得遗漏已存在的程序期限和风险提示
- 不得以"阅卷时间有限"为由略过重要材料
