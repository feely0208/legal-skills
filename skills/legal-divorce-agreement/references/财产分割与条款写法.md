# 财产分割与条款写法

> 目标：把「归谁」写成「谁在什么时间、做什么动作、不做什么赔多少钱」。
> 条号以现行文本为准，标「待核」的需回原文核对。

## 一、先做三张表

任何协议动笔前，先把三张表填完，缺的进占位符：

| 表 | 字段 | 作用 |
|---|---|---|
| 财产表 | 名称、权属人、取得时间、出资、现值/余额、抵押/查封、分割方式、交割动作 | 防止漏项、防止「其他财产各自所有」把大额财产漏掉 |
| 债务表 | 债权人、金额、形成时间、用途、签字人、凭证、承担方 | 区分共同债务与个人债务 |
| 子女表 | 出生日期、现居、就读、健康、保险、户口 | 抚养与探望条款的事实基础 |

写完在协议里写一句：「除本协议列明的财产外，双方确认无其他共同财产」——**只在确实核对过之后写**，否则对方日后可主张漏分。

## 二、房产：六步判断法

### 第 1 步 定权属

| 情形 | 通常认定 | 注意 |
|---|---|---|
| 婚前一方全款购买、登记在该方名下 | 个人财产 | 婚后加名可能构成赠与，需看登记与约定 |
| 婚前一方首付、婚后共同还贷、登记在首付方 | 房屋归登记方，共同还贷及对应增值部分补偿另一方 | 补偿计算需确定共同还贷额、增值率 |
| 婚后购买，无论登记在谁名下 | 原则共同财产（另有约定除外） | 一方父母出资：有约定按约定；无约定或约定不明，按共同财产处理，但部分法院会结合「全额出资+登记在己方子女名下」认定赠与，需查当地裁判口径 |
| 父母部分出资 | 出资性质有争议：借款还是赠与 | 有借条/转账备注/聊天记录按证据；无证据时不当然推定为赠与或借款 |
| 拆迁安置房 | 看安置协议与被安置人 | 含未成年人份额的，不能由父母协议处分 |

依据：《民法典》第一千零六十二条、第一千零六十三条；父母出资与共同还贷的补偿规则见《民法典婚姻家庭编解释（一）》（具体条号待核）。

### 第 2 步 查负担

- 抵押：抵押权人、主债权余额、是否二押；
- 查封：被查封的房屋不能过户，先处理查封；
- 限售：地方限售政策、取得产权证年限；
- 共有人：是否有第三人共有、是否需共有人同意。

### 第 3 步 定归属与补偿

三种写法，选一种并写透：

1. **归一方 + 补偿**：写补偿金额、支付节点（登记离婚后 X 日/过户前/过户后）、支付账户、逾期违约金；
2. **共同共有/按份共有**：写份额、谁居住、出售条件、优先购买权、租金分配；
3. **出售分款**：写挂牌价下限、决策机制、费用分担、分款比例与时点。

### 第 4 步 处理贷款

- 剩余贷款由谁还，写清「以谁的名义、从哪个账户扣款」；
- 变更还款人/转贷需银行同意，协议不能对抗银行；
- 带押过户：抵押期间转让抵押财产应通知抵押权人（《民法典》第四百零六条），能否办理以当地登记机构与银行规定为准；
- 若一方断供，另一方代偿后的追偿权要写。

### 第 5 步 过户与税费

- 期限：领取离婚证后 X 日内共同申请；
- 材料：离婚证、协议、身份证明、权证、完税凭证；
- 税费：契税、个税、增值税按当地政策，写「按法律规定各自承担」或明确比例；
- 一方不配合：按日违约金 + 约定「应配合而未配合的，另一方有权持生效法律文书单方申请」（能否单方办理需向登记机构核实）。

### 第 6 步 居住与户口

- 腾退期限、占用费标准；
- 是否需要居住权：居住权须书面合同并登记设立（《民法典》第三百六十六条、第三百六十八条），未登记不产生物权效力；
- 户口：无法强制迁出，只能约定违约金 + 迁出期限；涉及子女学籍的，写清学籍保留安排。

## 三、股权/出资额

| 情形 | 写法 |
|---|---|
| 另一方不成为股东 | 分割转让所得价款，或由持股方补偿；写估值基准日与支付节点 |
| 另一方成为股东 | 需其他股东过半数同意且放弃优先购买权；把「取得同意文件」写成先决条件 |
| 一方代持 | 先确权（代持协议、出资凭证、分红记录），再分割；代持关系不清时不要直接写「股权归某方」 |
| 上市公司股票 | 写数量、账户、基准日收盘价、过户或变卖分款 |
| 未实缴出资 | 写清补足义务由谁承担，避免受让方承接债务 |

依据：《民法典婚姻家庭编解释（一）》关于有限责任公司出资额分割的规定（条号待核）；《公司法》（2023 修订）股权转让与优先购买权规则。估值不要自行编数字，写【待补：评估值/双方确认值】。

## 四、住房公积金

- 分割范围：婚姻关系存续期间实际取得的公积金（含单位与个人缴存部分）；
- 婚前部分归个人；
- 提取受限：公积金提取需符合《住房公积金管理条例》规定情形，离婚一般不能直接提取 → **写成差额补偿**；
- 写法：「双方确认，截至【待补：日期】，男方公积金账户余额【待补：金额】元，其中婚姻存续期间取得部分【待补：金额】元。该部分归男方所有，男方于领取离婚证后【待补：30】日内补偿女方【待补：金额】元。」

## 五、保险

| 类型 | 分割对象 | 操作 |
|---|---|---|
| 重疾/医疗/意外 | 一般不分现金价值，关注后续保费与受益人 | 写明保费由谁承担、受益人是否变更 |
| 年金/万能/分红型 | 保单现金价值 | 归投保方，补偿另一方现金价值的一半（或约定比例） |
| 为子女投保 | 保单利益归子女 | 写明后续保费承担、投保人变更 |
| 寿险 | 现金价值 + 受益人 | 变更受益人需按合同约定并经被保险人同意 |

提示：投保人变更通常需被保险人同意（《保险法》相关规定，条号待核）；不要写「保单归女方」而不办变更手续。

## 六、债务：内外有别

1. **对外**：共同债务由双方共同偿还；内部约定不能对抗善意债权人（《民法典》第一千零六十五条、第一千零八十九条）。
2. **认定**：共同签名或事后追认；一方以个人名义为家庭日常生活需要所负；债权人能证明用于共同生活、共同生产经营或基于共同意思表示（第一千零六十四条）。
3. **写法**：

```markdown
（1）双方确认下列债务为夫妻共同债务：
    ① 债权人【待补】，本金【待补】元，形成于【待补】，用途【待补】，凭证【待补】；
（2）上述债务由双方各承担 50%，一方对外清偿超过自己份额的，有权向另一方追偿；
（3）除上述列明债务外，一方以个人名义所负、未用于家庭共同生活或共同生产经营的
    债务，由该方自行承担，与另一方无关；
（4）双方确认，本条约定仅在双方之间有效，不构成对债权人的免责。
```

4. **虚构债务**：提示一方伪造共同债务企图侵占另一方财产的，分割时可少分或不分，离婚后发现的可请求再次分割（第一千零九十二条）。

## 七、子女抚养与探望

### 抚养费

- 比例参考：有固定收入的，一般按月总收入的 20%–30%；负担两个以上子女的，可适当提高但一般不超过 50%；无固定收入的参照当年总收入或同行业平均收入（《民法典婚姻家庭编解释（一）》相关规定，条号待核）。
- 必须写：金额、支付日（每月 X 日前）、支付方式（银行转账至指定账户）、支付至何时（年满 18 周岁；成年但不能独立生活的另议）。
- 大额支出：教育（学费、择校、培训）、医疗（医保外自付部分）如何分担，写比例与事前协商机制。
- 调整机制：每【待补：2】年按【待补：CPI/收入变化】调整，或「一方收入变化超过 30% 时可协商调整，协商不成可诉」。
- 提示：协议不免除子女必要时请求增加抚养费的权利（第一千零八十五条）。

### 探望

写全七个要素，缺一个就会吵：

1. 频率（每周/每两周）；
2. 时段（周六 9:00 至周日 18:00）；
3. 接送地点与方式；
4. 节假日（春节、国庆如何轮换）；
5. 寒暑假（连续探望天数）；
6. 是否可过夜、可否带离本市/出境；
7. 临时变更（提前几日通知）、视频通话安排。

### 其他

- 子女姓名变更、户口迁移需双方配合；
- 直接抚养方不得阻挠探望；拒不协助的，另一方可申请法院采取措施（第一千零八十六条）；
- 八周岁以上子女的意愿应被尊重（第一千零八十四条）。

## 八、补偿与赔偿

| 类型 | 依据 | 写法要点 |
|---|---|---|
| 家务劳动补偿 | 第一千零八十八条 | 写明负担较多义务的事实（抚育子女、照料老人、协助工作）与金额、支付方式 |
| 经济帮助 | 第一千零九十条 | 一方生活困难（无住房、无收入、患病），写帮助方式与期限 |
| 离婚损害赔偿 | 第一千零九十一条 | 限重婚、与他人同居、家暴、虐待遗弃、其他重大过错；协议离婚时未明确放弃的，仍可能另行主张（期限与条件待核） |

## 九、违约、管辖、生效

- 违约金：日万分之【待补】或按 LPR；约定过高可能被调整（《民法典》第五百八十五条）；
- 管辖：约定与争议有实际联系的地点（《民事诉讼法》第三十五条），不动产争议注意专属管辖；
- 生效：**自双方签字并在婚姻登记机关办理离婚登记、领取离婚证之日起生效**；未登记的，协议不生效（《民法典婚姻家庭编解释（一）》相关规定，条号待核）；
- 份数：一式三份，双方各一份，婚姻登记机关存档一份。

## 十、常见错误对照

| 错误写法 | 正确写法 | 原因 |
|---|---|---|
| 「房子归女方，贷款女方还」 | 写明贷款余额、还款账户、银行是否同意变更、断供责任 | 银行不受协议约束 |
| 「抚养费每月 3000 元至 18 岁」 | 加支付日、账户、大额支出分担、调整机制 | 固定数字遇通胀/变故即争议 |
| 「各自名下财产归各自所有」 | 列明财产后再写兜底，或明确排除大额财产 | 可能被用来隐匿财产 |
| 「债务由男方承担，与女方无关」 | 加「仅在双方间有效，不对抗债权人」 | 内部约定不能对抗善意债权人 |
| 「公积金归各自所有」 | 写婚姻存续期间取得部分的差额补偿 | 可能构成显失公平 |
| 「签字即生效」 | 办理离婚登记、领取离婚证之日起生效 | 未登记不产生解除婚姻关系效力 |
| 「探望权每月两次」 | 写清时段、接送、节假日、过夜 | 无法执行 |
