# 离婚协议技能

## 这个技能解决什么

网上模板的通病是**只写「房子归男方、车子归女方」**，不写什么时候过户、贷款谁还、对方不配合怎么办。等到登记完、一方反悔，条款没法执行，只能再打一场官司。

本技能解决四件事：

1. 把「归属」写成可执行的动作：过户时点、税费承担、贷款承接、腾退与户口迁出；
2. 把「抚养费」写成可调整的机制，而不是一个固定数字写到 18 岁；
3. 把「债务」写清内外有别：内部怎么分、对外不能对抗善意债权人；
4. 把「生效条件」写在最显眼处：**未办理离婚登记的，协议不生效**。

## 适用 / 不适用

| 适用 | 不适用 |
|---|---|
| 双方已谈妥，需要一份能提交婚姻登记机关的协议 | 一方不同意离婚，需诉讼离婚（用起诉状类技能） |
| 已登记离婚，需要补充/细化财产交割安排 | 婚前财产协议、婚内财产约定（结构不同） |
| 房产、车辆、存款、股权、公积金、保险的分割条款 | 继承、分家析产纠纷 |
| 抚养费、探望权、子女教育医疗安排 | 涉外/涉港澳台离婚（法律适用、公证认证不同） |
| 律师审核当事人自带协议 | 抚养权争夺的诉讼策略与举证 |

## 输入

必需：

- 双方身份信息：姓名、身份证号、住址、联系电话；结婚登记时间、登记机关、结婚证号；
- 子女情况：姓名、出生日期、现随谁生活、就读学校、健康状况；
- 财产清单：不动产（坐落、权证号、登记人、购买时间、出资、贷款余额、抵押）、车辆、存款、股权/出资、公积金、保险、债权；
- 债务清单：债权人、金额、借款时间、用途、是否有双方签字；
- 双方已达成的一致意见：抚养安排、分割方案、债务承担。

可选：

- 一方是否存在过错情形（重婚、与他人同居、家暴、虐待遗弃、其他重大过错）；
- 一方是否因抚育子女、照料老人、协助另一方工作负担较多义务；
- 一方是否生活困难；
- 是否有隐匿、转移财产的迹象。

缺失处理：房产价值不明写【待补：双方确认价值或评估价】，不要估；贷款余额不明写【待补：截至交割日贷款余额】，不要让一方「大概还欠几十万」。**任何数字没有来源就进占位符。**

## 工作流程

### 第零步：读法律档案

先读 `~/.deepwhale/深鲸法律档案.md`。不存在时，把仓库 `templates/法律档案.md` 复制到该路径，再逐项问用户。重点看：角色（律师/当事人）、立场（代理男方/女方/双方中立）、地区（房产限售、公积金提取、登记材料地方差异）、行文风格。

### 第一步：确认能不能协议离婚

先过三关，任何一关不过就不该出这份协议：

1. **双方自愿**，且对子女抚养、财产、债务已协商一致（《民法典》第一千零七十六条）；
2. **在中国内地登记结婚**，双方亲自到场（婚姻登记机关管辖按现行《婚姻登记条例》）；
3. **不存在必须诉讼的情形**：一方下落不明、被限制人身自由、无民事行为能力/限制民事行为能力、结婚登记不在内地——这些只能诉讼离婚。

提示冷静期：自申请之日起三十日内任何一方可撤回；期限届满后三十日内双方须亲自申请发证，未申请视为撤回（第一千零七十七条）。

### 第二步：搭结构（六段）

| 段 | 必写内容 | 常见漏项 |
|---|---|---|
| 一、身份与婚姻 | 双方信息、结婚时间、登记机关、结婚证号、自愿离婚 | 结婚证号、登记机关 |
| 二、子女抚养与探望 | 直接抚养方、抚养费、大额支出、探望、调整机制、户口与学籍 | 探望的接送方式、寒暑假、过夜 |
| 三、财产分割 | 房产、车辆、存款、股权、公积金、保险、贵重物品、债权 | 贷款承接、过户税费、腾退、户口迁出 |
| 四、债务 | 共同债务清单、各自债务、追偿、债权人通知 | 内部约定不能对抗债权人 |
| 五、补偿与赔偿 | 家务劳动补偿、经济帮助、离婚损害赔偿（如有） | 需要主张的没主张，登记后另行主张难度大 |
| 六、违约、争议解决、生效 | 违约金、管辖、生效条件、附件 | 生效条件写成「签字即生效」 |

### 第三步：逐项填实（重点四类财产）

细则见 `references/财产分割与条款写法.md`，这里只给判断顺序：

**房产**

1. 权属：登记在谁名下、婚前还是婚后购买、谁出资、是否有父母出资（父母出资性质需证据，不当然推定赠与一方）；
2. 贷款：余额、还款人、能否转贷、银行是否同意带押过户；
3. 归属与补偿：归一方 → 另一方拿补偿款，写清金额、支付节点、逾期违约金；共有 → 写清份额、出售条件、优先购买权；
4. 过户：时间（登记离婚后 X 日内）、双方配合义务、税费承担、不配合的违约后果；
5. 居住：是否需要设定居住权（《民法典》第三百六十六条、第三百六十八条，须书面合同并登记）或约定腾退期限；
6. 户口：迁出期限与违约金（户口迁移不能强制，只能靠违约金约束）。

**股权/出资额**

1. 是有限责任公司出资额还是股份公司股票；
2. 另一方是否成为股东：需其他股东过半数同意且放弃优先购买权，否则只能分割转让所得价款（《民法典婚姻家庭编解释（一）》相关规定，条号待核）；
3. 估值口径：净资产、评估值、双方协商值，写清基准日；
4. 分红、表决权、后续增资的归属。

**住房公积金**

1. 只分割**婚姻关系存续期间实际取得**的部分；
2. 公积金提取受《住房公积金管理条例》限制，通常不能直接提现分割 → 写成「一方保留，按差额补偿另一方」；
3. 写清补偿金额与支付时间，不写「各自公积金归各自」了事（可能显失公平）。

**保险**

1. 区分保障型、年金型、万能型；分割的是**保单现金价值**；
2. 投保人变更需被保险人同意；受益人变更按保险合同约定；
3. 为子女投保的，写明后续保费由谁承担。

### 第四步：写债务条款（内外有别）

1. 列明已知共同债务：债权人、金额、形成时间、用途、凭证；
2. 约定内部承担比例与追偿；
3. **必须写一句提示**：本协议关于债务承担的约定仅在双方之间有效，不能对抗善意债权人；一方就共同债务对外清偿后，可依本协议向另一方追偿（《民法典》第一千零六十四条、第一千零六十五条、第一千零八十九条）；
4. 未列入清单的债务：写明「一方以个人名义所负、未用于家庭共同生活或共同生产经营的债务，由该方自行承担」；
5. 虚构债务的后果提示（第一千零九十二条）。

### 第五步：写违约与救济

- 逾期支付补偿款/抚养费：日万分之【待补：比例】违约金，或按 LPR 计息；注意违约金过高可被调整（《民法典》第五百八十五条）；
- 逾期过户/不配合办理：按日计违约金 + 视为授权单方办理（能否单方办理取决于登记机构，需核实）；
- 逾期腾退：按日占用费；
- 逾期迁户口：一次性违约金（无法强制迁出，只能靠钱约束）；
- 争议解决：约定「向【待补：被告住所地/不动产所在地】人民法院起诉」，协议管辖须与争议有实际联系（《民事诉讼法》第三十五条）。

### 第六步：写生效条件与附件

生效条款建议原文：

> 本协议自双方签字并按指印，且双方在婚姻登记机关办理离婚登记、领取《离婚证》之日起生效。双方未办理离婚登记的，本协议不生效，双方应按法律规定处理。

依据：离婚协议是附生效条件的协议；以登记离婚为条件的财产分割协议，双方协议离婚未成、一方在离婚诉讼中反悔的，该协议不生效（《民法典婚姻家庭编解释（一）》相关规定，条号待核）。

附件：财产清单、债务清单、房产证/车辆登记证/保单/股权证明复印件、子女出生医学证明。附件与正文同等效力。

### 第七步：复核与交付

按质量闸门逐条过；对无法核实的信息保留占位符，并在交付说明里列出「必须由当事人确认的 5 项」。提醒：登记前不要处分财产、不要单方转移存款（可能触发第一千零九十二条）。

## 质量闸门（交付前自检）

- [ ] 身份信息、结婚登记信息完整，缺失处为【待补：xx】
- [ ] 有明确的生效条件条款，写明「办理离婚登记、领取离婚证之日起生效」
- [ ] 每项不动产都写了：归属、补偿金额与节点、贷款承接、过户期限、税费、腾退、户口
- [ ] 抚养费写了金额、支付方式、支付至何时、大额支出分担、调整机制
- [ ] 探望写了频率、时段、接送、节假日与寒暑假、过夜、临时变更
- [ ] 债务条款区分内部承担与对外效力，未承诺「一方不承担即债权人不能追」
- [ ] 股权分割写了其他股东同意/优先购买权，或明确只分割转让价款
- [ ] 公积金、保险写的是补偿/现金价值，不是「直接提取」
- [ ] 违约金比例是占位符或有依据，未编造具体数额
- [ ] 没有编造房产证号、身份证号、金额、日期
- [ ] 文末有「AI 辅助生成，需承办律师复核」

## 输出示例

```markdown
## 三、财产分割

### 3.1 房产

（1）坐落于【待补：市/区/路/号】的房屋（不动产权证号：【待补：证号】），
登记在男方名下，婚后购买，现由双方共同居住，剩余按揭贷款约【待补：金额】元。

（2）双方确认：该房屋归男方所有，女方放弃共有份额。男方应于领取《离婚证》之日起
【待补：60】日内，向女方支付房屋折价补偿款人民币【待补：金额】元，支付至女方
指定账户（开户行：【待补】，账号：【待补】）。

（3）剩余按揭贷款由男方独自偿还。男方应于上述期限内向贷款银行申请变更还款人；
银行不同意变更的，男方仍应按时还款，不得以女方名义逾期。

（4）双方应于领取《离婚证》之日起【待补：30】日内共同办理不动产转移登记，
税费按法律规定各自承担（或：【待补：约定】）。一方无正当理由不配合的，
每逾期一日按补偿款总额的万分之【待补：比例】支付违约金。

（5）女方应于转移登记完成之日起【待补：15】日内腾退并交房，逾期按每日
【待补：金额】元支付占用费；女方及子女户口应于【待补：期限】内迁出。
```
