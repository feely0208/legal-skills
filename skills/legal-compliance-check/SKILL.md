# 用工合规体检技能

## 这个技能解决什么

多数用工风险不是因为「没有制度」，而是制度本身违法、程序没走、或者拿不出证据：

- 手册写「旷工 3 天视为自动离职」，真辞退时被认定违法解除；
- 1 年合同约定 3 个月试用期，超期部分要按第 83 条赔；
- 让员工签「自愿放弃社保」，承诺无效，还要补缴 + 滞纳金；
- 竞业限制全员签、离职后不给补偿，条款主张不了。

本技能把这些问题按八个模块扫一遍，输出能直接派活的整改清单。**它只做提示，不做违法认定，也不替代律师。**

## 适用 / 不适用

| 适用 | 不适用 |
|---|---|
| 企业自查用工制度、合同模板、员工手册 | 个体争议已发生、要算请求金额 → `legal-labor-arbitration` |
| 融资/并购/上市前的劳动用工尽调初筛 | 商业合同逐条审 → `legal-contract-review` |
| 裁员、组织调整前的风险预判 | 股权、数据、税务合规 → 另行委托 |
| 员工方核查公司制度是否违法（立场切换） | 要出具签章法律意见 → `legal-opinion` |
| 整改后复检、建立年度体检机制 | 代理仲裁/诉讼、写答辩 → 诉讼技能 |

## 输入

**必需**

1. 体检对象：公司/工厂/门店，人数、行业、所在省市。
2. 立场：企业方自查 / 员工方核查 / 中立（投前尽调）。
3. 材料（有多少给多少）：
   - 劳动合同模板（最好含在用的不同版本）
   - 员工手册 / 规章制度 / 奖惩办法
   - 考勤与工时制度、加班审批流程
   - 薪酬结构、工资表（可脱敏）、社保公积金缴纳明细
   - 解除/终止通知书、离职文件模板
   - 竞业限制、保密、培训服务期协议
   - 特殊人员名单：三期女职工、工伤/职业病、未成年工、派遣/外包、退休返聘、实习生

**可选**：近 12 个月劳动争议/仲裁记录、行政处罚记录、工会/职代会情况。

材料缺失时列「未提供」，**不要假设合规**。例如没给工资表，就不能写「薪酬发放合规」，只能写「未提供，无法核查」。

## 工作流程

### 第零步：读法律档案

先读 `~/.deepwhale/深鲸法律档案.md`。不存在时，把仓库里的 `templates/法律档案.md` 复制过去，再逐项问用户：角色、立场、执业地域、行文风格、风险偏好、升级链。档案里没填的，不要假设。

地域决定最低工资、社保基数、地方人口与计划生育条例（奖励假）、特殊工时审批口径；立场决定建议是「怎么改」还是「哪里可以主张」。

### 第一步：定范围与口径

出一张「本次体检范围表」：

| 模块 | 是否覆盖 | 依据材料 | 未提供 |
|---|---|---|---|
| 招聘 | 是 | 招聘启事、录用条件 | 背景调查授权书 |
| 合同 | 是 | 合同模板 v3 | 已签合同抽样 |
| …… | | | |

范围外的模块，报告里明确写「本次未覆盖」，不假装扫过。

### 第二步：八模块逐项比对

按 `references/labor-compliance-checklist.md` 的顺序走，每个模块至少查 6–12 项。每查一项，记录四要素：

**检查项 → 现状 → 依据（条号）→ 判断（合规/瑕疵/高风险/未提供）**

判断词只用这四个，不用「基本合规」「问题不大」这类模糊说法。

### 第三步：定风险等级

| 等级 | 判定标准（满足其一） | 典型例子 |
|---|---|---|
| 🔴 必须处理 | 条款可能被认定无效/违法；可能触发二倍工资、2 倍赔偿金、补缴 + 滞纳金、行政处罚；程序缺失足以导致败诉 | 自愿放弃社保、超期试用、无补偿竞业、未通知工会即解除 |
| 🟡 建议处理 | 条款有效但举证不利、口径不清、制度缺口，争议时可能吃亏 | 加班无审批记录、工资条无签收、手册未公示 |
| ⚪ 提示 | 优化项、文本一致性、留痕习惯 | 条款编号混乱、送达地址未更新、模板版本未统一 |

**不要把「没看到材料」判成 🔴**，应单列「未提供，无法判断」，避免用风险等级制造恐慌。

### 第四步：写整改建议

每条风险点给三件事，缺一不可：

1. **改什么**：条款怎么改（给可替换的方向性文本，不给「建议完善」这种空话）；
2. **做什么**：程序动作（民主程序、公示、签收、通知工会、送达）；
3. **留什么**：证据留痕（签收表、会议纪要、邮件、考勤记录保存年限）。

整改建议要能派活：写清责任部门（HR/法务/财务/业务）与建议时限（立即/30 天/下轮修订）。

### 第五步：出报告

结构：

1. 体检结论摘要（🔴 几条、🟡 几条、未提供几项）
2. 范围与方法（含「不构成违法认定」声明）
3. 八模块明细表（风险点—依据—现状—等级—整改建议）
4. 整改清单（按优先级排序，可导出 CSV）
5. 未提供材料清单与补充建议
6. 高风险事项升级提示（解除、裁员、集体争议、工伤）

## 输出规范

- 主报告：`用工合规体检报告-<公司简称>-<YYYYMMDD>.md`；八模块明细统一用四列表：
  **风险点 — 依据 — 整改建议 — 优先级**（优先级即 🔴/🟡/⚪，另可加「现状」「责任部门」列）
- 整改清单：`整改清单-<公司简称>-<YYYYMMDD>.csv`
  列：`编号,模块,风险点,依据,等级,整改建议,责任部门,建议时限,状态`
- 需要正式交付：`chinese-doc-formatter` 转 `.docx` / `.pdf`
- 报告首页与文末固定：

```
本报告为合规提示，不构成对具体行为违法性的认定，不替代律师审核。
AI 辅助生成，需承办律师复核；涉及解除、裁员、集体争议的事项，处理前必须经律师确认。
```

## 质量闸门（交付前自检）

- [ ] 八个模块都覆盖，未覆盖的写明「本次未覆盖」
- [ ] 每条风险点有依据（法条到条 / 制度条款到条），无源不写
- [ ] 风险等级只用 🔴/🟡/⚪，判定理由能对上标准
- [ ] 「未提供材料」单列，没有被判成合规或高风险
- [ ] 整改建议含「改条款 + 走程序 + 留证据」三件套
- [ ] 没有编造地方最低工资、社保基数、赔偿标准；需要时标【待核：当地标准】
- [ ] 区分「条款无效」与「有败诉风险」，没有一刀切说「违法」
- [ ] 特殊保护模块（三期、工伤、未成年工、派遣）逐项查过
- [ ] 带「AI 辅助生成，需承办律师复核」与「不替代律师」声明
- [ ] 没有「保证通过检查」「一定不会败诉」这类承诺

## 输出示例

```markdown
# 用工合规体检报告：XX 制造（80 人）

## 一、结论摘要
- 🔴 必须处理 3 项：试用期超法定上限、员工手册「自动离职」条款、社保放弃承诺。
- 🟡 建议处理 4 项：加班无审批记录、工资条无签收、竞业限制全员适用且无补偿、手册未公示。
- ⚪ 提示 2 项：合同模板版本不统一、送达地址条款缺失。
- 未提供：考勤原始记录、工资表、社保缴费明细（相关结论无法核查）。

## 二、范围与方法
本次覆盖招聘、合同、工时、薪酬、社保、解除、竞业、特殊保护八模块；
依据为提供的合同模板与手册，未对已签合同抽样。本报告不构成违法认定。

## 三、明细（节选）
| 模块 | 风险点 | 依据 | 等级 | 整改建议 |
|---|---|---|---|---|
| 合同 | 1 年期合同约定 3 个月试用期 | 劳动合同法第 19 条 | 🔴 | 改为不超过 2 个月；已履行的超期部分按第 83 条评估赔偿 |
| 解除 | 手册写「旷工 3 日视为自动离职」 | 劳动合同法第 39 条、第 43 条 | 🔴 | 删除「自动离职」，改为「严重违纪可解除」，并补通知工会与送达 |
| 社保 | 员工签署自愿放弃社保承诺 | 社会保险法第 58、60、86 条 | 🔴 | 停止使用承诺书，补缴并评估滞纳金 |

## 四、整改清单
见 `整改清单-XX制造-20261029.csv`，按 🔴 → 🟡 → ⚪ 排序。

本报告为合规提示，不构成对具体行为违法性的认定，不替代律师审核。
AI 辅助生成，需承办律师复核。
```
