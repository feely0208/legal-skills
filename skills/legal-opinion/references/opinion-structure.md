# 法律意见书的结构、结论分级与措辞

> 本文件是 `legal-opinion` 的写作口径。核心只有一句：**结论必须带边界，边界必须写在纸面上。**

## 一、七段结构

| 段落 | 必写 | 不写 | 常见错 |
|---|---|---|---|
| 1 标题与致送 | 事项、致送对象、文号（可选）、日期 | 夸张定语 | 标题写成「关于一切法律问题的意见」 |
| 2 声明与假设 | 委托背景、材料范围、假设清单、用途限制 | 「已审阅全部材料」（没看完就别写） | 假设藏在正文里，读者看不到 |
| 3 事实基础 | 已核实 / 陈述未核实 / 待补，三类分开 | 未经证实的推测写成事实 | 把客户口述写成「经查」 |
| 4 法律依据 | 条号、文号、核验状态、对应哪个问题 | 会议纪要、普通案例混进「法律」 | 只写「根据相关法律规定」 |
| 5 逐项分析 | 规则 → 涵摄 → 结论 → 反向情形 | 情绪、道德评价、商业判断 | 只写结论不写推理 |
| 6 结论 | 四档分级，逐条编号 | 把四档揉成一段「总体可行」 | 附条件结论漏掉条件 |
| 7 限制与签署 | 用途、依赖、不更新、责任边界、签署栏 | 承诺结果 | 没有签署栏就交付 |

段落顺序不是形式。读者往往只看第 2 段和第 6 段，所以这两段必须能独立读懂。

## 二、事实基础：三分法

### 2.1 已核实事实

写法：「经审阅《XX 合同》（2025 年 3 月 1 日签署版）第 4.2 条，……」

要求：文件名 + 版本/日期 + 条款号或页码。没有条款号的文件，写清是哪一节。

### 2.2 委托人陈述未核实

写法：「根据委托人 2026 年 10 月 20 日书面说明，……。本所未对该陈述进行独立核实。」

要求：注明时间与形式（书面/邮件/访谈），并明确「未独立核实」。不要写「据了解」——看不出是谁了解的。

### 2.3 假设

写法：「本意见假设：（1）……真实、合法、有效；（2）……已取得必要的内部授权；（3）……」

要求：集中列示、编号、可被读者逐条检验。假设越多，结论越弱，必须在结论里呼应。

### 2.4 缺口

统一写【待补：具体文件/事实】。禁止用「一般而言」「通常情况下」把缺口盖过去。

## 三、结论四档

### 判定顺序

```
关键事实是否齐全？
├─ 否 → 无法出具（或先出「阶段性意见」，明确不构成最终结论）
└─ 是 → 规则是否明确、无实质争议？
        ├─ 是，且无未满足前提 → 确定结论
        ├─ 是，但结论依赖某前提 → 附条件结论
        └─ 否（规则有争议/裁判不统一） → 保留结论
```

### 3.1 确定结论

适用：事实清楚、规则明确、要件全部满足。

句式：
- 「本所认为，……符合《XX 法》第 X 条的规定，在现有材料范围内未发现无效情形。」
- 「基于上述事实，……不构成……」

注意：即使确定，也要限定「在现有材料范围内」，不写「不存在任何风险」。

### 3.2 附条件结论

适用：结论本身成立，但依赖尚未完成的行为或尚未取得文件。

句式：
- 「在……完成工商变更登记的前提下，……；如未完成，则……。」
- 「若股东会依章程作出决议，则……；否则，该条款可能因……无法履行。」

要求：条件必须可验证（谁、做什么、什么文件），不能写「待相关手续完善后」。

### 3.3 保留结论

适用：规则本身有争议、类案分歧、或关键事实只能部分确认。

句式：
- 「基于现有材料，本所倾向于认为……；但鉴于……存在不确定性，本所对此保留意见。」
- 「该问题在司法实践中存在不同认识，主流观点为……，亦有裁判认为……。」

要求：说清不确定来自哪里（法律空白/裁判分歧/事实缺口），不能只写「有待进一步研究」。

### 3.4 无法出具

适用：关键事实缺失、事项超出执业范围、存在利益冲突。

句式：
- 「现有材料不足以支持对……作出判断，本所暂不出具意见。」
- 「……超出本次委托范围，本所未发表意见。」

要求：说明缺什么、补什么可以再出，不要一句「无法回答」了事。

### 四档对照（同一个问题）

| 档位 | 写法 | 问题 |
|---|---|---|
| 确定 | 「该条款有效。」 | 事实齐、规则明 |
| 附条件 | 「在完成减资程序的前提下，该回购义务可以履行。」 | 缺程序性前提 |
| 保留 | 「该条款效力倾向于有效，但……存在被认定无效的可能，本所保留意见。」 | 规则有争议 |
| 无法出具 | 「因未见公司章程与股东会决议，本所暂不判断该条款能否履行。」 | 关键材料缺失 |

## 四、假设条款模板

```
本意见基于以下假设出具：
（1）委托人提供的文件均为真实、完整、有效的原件或与原件一致的复印件；
（2）文件上的签署人均已取得合法授权，签署行为为其真实意思表示；
（3）自文件签署日至本意见出具日，相关事实与法律状态未发生重大变化；
（4）不存在未向本所披露的补充协议、口头约定、侧协议或政府批复；
（5）相关主体均依法设立、有效存续，不存在破产、清算、被列为失信被执行人的情形；
（6）本意见仅依据中华人民共和国大陆地区现行法律出具，不涉及境外法、地方性法规及行业监管特别规定。
```

使用时逐条删改，不要整段照抄；与本案无关的假设写进去反而暴露没读材料。

## 五、限制条款模板

```
## 限制与保留
1. 用途限制：本意见仅供委托人[内部投资决策]使用，未经本所书面同意，不得向第三方提供或依赖。
2. 材料依赖：本所仅就委托人提供的材料发表意见，未对材料真实性作独立核查。
3. 不更新义务：本所无义务就本意见出具后发生的事实或法律变化更新意见。
4. 责任边界：本意见不构成对交易商业可行性、估值合理性的判断，亦不构成对任何第三方（含监管机关）的承诺。
5. 可分性：若本意见某部分被认定不准确，不影响其他部分的效力。
6. 签署：本意见须经承办律师签字并加盖律所公章后生效。
```

## 六、常见错误对照

| 错误写法 | 问题 | 正确写法 |
|---|---|---|
| 「合法有效，不存在任何风险」 | 绝对化、承诺结果 | 「在现有材料范围内，未发现……无效情形；仍存在……风险」 |
| 「已审阅全部材料」 | 没看完就是虚假陈述 | 「本意见基于下列材料出具（清单见附件）」 |
| 「根据相关法律规定」 | 无出处 | 写明法名 + 条号 |
| 「根据《九民纪要》第 5 条，应认定有效」 | 纪要不是法源 | 「参照《九民纪要》第 5 条的说理，……」 |
| 「待手续完善后即可履行」 | 条件不可验证 | 「在完成减资决议、公告及工商变更后，……」 |
| 「一般来说没问题」 | 模糊、无法依赖 | 落入四档之一，写清依据 |
| 结论只写「总体可行」 | 客户无法执行 | 逐项编号，每项一个档位 |
| 把「效力」与「可履行性」混为一谈 | 对赌、回购类高频错误 | 分两节：效力 / 履行 |
| 引用《合同法》 | 已废止 | 改引《民法典》合同编对应条文 |
| 超范围回答估值、税务、刑事 | 超出委托与能力 | 「超出本次委托范围，未发表意见」 |
| 没有签署栏 | 无法对外出具 | 承办律师、律所盖章、日期 |
| 用「我们保证」 | 执业风险 | 「本所认为」「倾向于」 |

## 七、对外出具前的闸门

1. **谁签**：必须由执业律师签字，律所盖章；AI 与法务不能替代。
2. **给谁**：核对致送对象与用途；给 A 的意见被 B 依赖，要提前写限制。
3. **版本**：文件名带日期与版本号（v1/v2），避免旧版流出。
4. **附件**：材料清单、依据清单、检索记录一并归档。
5. **冲突**：出具前查利益冲突；有冲突不出具。
6. **留痕**：邮件发送记录、签收记录、修改稿一并保存。
