# 验收样例 01：对赌回购条款的效力与履行

## 委托背景

C 基金拟以 2000 万元增资入股 A 科技有限责任公司，取得增资后 10% 股权。双方已签《投资条款清单》（TS），尚未签正式增资协议。

TS 第 3.2 条原文：

> 「若 A 公司未能在交割后 3 年内完成合格 IPO，A 公司应按 C 基金投资款加年化 8% 单利回购 C 基金所持全部股权。」

## 委托事项（客户原话）

「你帮我们出个法律意见，这个回购条款到底有没有效？真到那天能不能拿到钱？投委会下周要看。要不要改成让创始人个人回购？」

## 已知信息

| 项目 | 内容 |
|---|---|
| 委托人 | C 基金（投资人） |
| 目标公司 | A 科技有限责任公司，注册资本 1000 万元 |
| 交易 | 增资 2000 万元，取得 10% 股权 |
| 回购义务人 | TS 写的是「A 公司」 |
| 回购价 | 投资款 + 年化 8% 单利 |
| 触发条件 | 交割后 3 年内未完成合格 IPO |
| 文件状态 | 仅 TS；正式增资协议、章程、股东会决议均未提供 |
| 实缴情况 | 不明 |
| 用途 | 投委会内部决策 |

## 信息缺口（至少四项，技能必须逐项追问）

1. **回购义务主体是否最终确定**：TS 写 A 公司，但客户口头提到「可能改成创始人」，以哪版为准？
2. **A 公司章程与股东会决议**：章程是否限制公司回购？其他股东是否同意？是否已完成增资决议？
3. **减资可行性**：A 公司是否有可分配利润、能否履行通知债权人和公告程序？这直接决定「能不能拿到钱」。
4. **投资款是否已实缴**：2000 万元是否到账、有无验资或银行回单？
5. **是否涉及特殊审批**：A 公司是否有国资、外资股东，增资/回购是否需要审批或备案？
6. **回购程序条款**：TS 未约定回购通知、期限、价款支付方式、违约责任。

## 容易写错的点（重点验收）

**陷阱一：把「有效」直接等同于「能拿到钱」。**
与目标公司对赌，协议效力与可履行性要分开判断。协议本身在无法定无效事由时通常认定有效；但公司实际履行回购，往往需要先完成减资程序，否则可能因资本维持原则无法履行。只答「有效，可以回购」是错的。

**陷阱二：把《九民纪要》当法律依据。**
《全国法院民商事审判工作会议纪要》不是司法解释，不能作为裁判依据援引，只能在说理部分参照。写成「根据《九民纪要》第 5 条，应认定有效」不合格；应写「参照《九民纪要》第 5 条的处理思路」，并把《民法典》第 143 条等作为效力依据。

**陷阱三：忽略「名股实债」风险。**
固定年化 8% + 到期回购 + 不参与经营，可能被认定为借贷关系。若被认定借贷，回报上限、公司间借贷规则都会变化。必须在分析里提示，并说明判断要素（是否参与经营、是否登记为股东、收益是否与经营挂钩）。

**陷阱四：结论超出委托范围。**
客户问「能不能上市」「估值合不合理」，属于商业判断或超出能力范围，应写「未发表意见」，不要顺口答。

**陷阱五：把附条件结论写成确定结论。**
在公司章程、决议、减资程序都未知的情况下，任何「可以履行」都只能是附条件或保留。
