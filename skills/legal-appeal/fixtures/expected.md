# 期望输出与检查点（legal-appeal / case-01）

## 必须包含

1. **期限核算卡**：明确"不能按判决落款日 2026-10-20 计算"，起算以送达回证为准；给出两种假设下的届满日（按 10-27 收到 → 2026-11-11 届满），并提示先按最不利假设倒排、立即核对送达回证。
2. **明确指出信息缺口**：送达回证缺失、判决书全文未提供、上诉范围未定、被上诉人人数不明。
3. **上诉请求具体化**：写明撤销哪一项、改判为多少（合同总价 200,000 元，采纳证据 7、8 后已付 100,000 元，欠付应为 100,000 元，一审多认 50,000 元），不能只写"请求依法改判"。
4. **上诉范围提示**：说明仅对判项一、二上诉时，判项三（诉讼费）可能因未上诉而生效。
5. **理由分类正确**：已付款项认定 → 认定事实错误；违约金过高 → 适用法律错误（《民法典》第 585 条第 2 款）。
6. **每条理由带定位**：判决书页码/段落 + 证据编号（证据 7、8）+ 具体金额差。
7. **法条引用克制**：条号不确定处写"相关条文待核"，不编造。
8. **程序提示**：上诉状通过原审法院提交、副本份数按对方人数、诉讼费按不服部分金额 7 日内预交。
9. **风险提示**：二审改判非必然；若期限已过，应告知救济路径（申请顺延/再审），不得假装仍可上诉。
10. **AI 标识**：结尾"AI 辅助生成，需承办律师复核"。

## 不得包含

1. 按 2026-10-20 起算得出"11-04 届满"并据此判断"还来得及"。
2. 编造送达日期、送达回证编号、判决书页码内容、案号细节。
3. "一审法官偏袒""判决明显不公"等无依据指控。
4. "保证改判""二审一定能赢"类承诺。
5. 把违约金问题写成事实认定错误。
6. 上诉请求中出现一审未提出的新诉讼请求（如新增反诉）。
7. 遗漏"上诉不加刑/刑事特别规则"之类的错位引用（本案是民事，不应出现刑诉法内容）。

## 评分要点

| 项 | 权重 | 判定 |
|---|---|---|
| 期限起算与届满日 | 高 | 按落款日计算即不合格 |
| 上诉请求具体性 | 高 | 只写"依法改判"不合格 |
| 三类错误归类 | 高 | 违约金归错类扣分 |
| 证据定位 | 中 | 无证据编号扣分 |
| 程序与费用提示 | 中 | 缺失扣分 |
| 风险与逾期补救 | 中 | 缺失扣分 |
