# 上诉状技能

## 这个技能解决什么

一审判决到手，最贵的错误有两个：**错过上诉期**，和**上诉状只写情绪不写错误**。

二审的审理范围原则上围绕上诉请求（《民事诉讼法》第一百七十五条），上诉状没写的，二审一般不主动审。所以上诉状不是"再讲一遍故事"，而是**逐项指出一审错在哪、错得影响什么结果**。

本技能先算期限，再做争点筛选，最后按三类错误落笔。

## 适用 / 不适用

| 适用 | 不适用 |
|---|---|
| 民事一审判决/裁定不服，准备上诉 | 一审起诉、立案材料（找 legal-complaint） |
| 刑事一审判决不服（被告人/辩护人/近亲属） | 作为被上诉人写答辩（另行起草答辩状） |
| 行政一审判决/裁定不服 | 生效判决申请再审（程序、期限、事由均不同） |
| 判断上诉有没有改判空间 | 执行阶段异议（找 legal-enforcement） |

相邻交接：需要补强事实与证据 → `legal-evidence-chain`、`legal-evidence-catalog`；二审开庭要质证 → `legal-evidence-examination`；文书排版 → `chinese-doc-formatter`。

## 输入

必需：

1. 一审判决书/裁定书全文（含落款日期、审判人员、案号）；
2. **送达回证或签收日期**（决定上诉期起算，缺此项不能算期限）；
3. 案件类型（民事 / 刑事 / 行政）；
4. 上诉人身份信息（自然人：姓名、性别、出生日期、住所、身份证号；法人：名称、住所、统一社会信用代码、法定代表人）；
5. 不服的具体内容（哪几项判项、哪段认定）。

可选：一审证据目录、庭审笔录、代理词、对方上诉情况（双方都上诉时的地位）。

送达日期缺失：写【待补：收到判决书之日，以送达回证为准】，并提示"期限未定，先按最不利假设倒排"。

## 工作流程

### 第零步：读法律档案

先读 `~/.deepwhale/深鲸法律档案.md`。不存在时，把仓库 `templates/法律档案.md` 复制过去，逐项问：角色、立场（一审原告还是被告）、执业地域、行文风格、风险偏好、升级链。档案没填的不要假设——一审是原告还是被告，直接决定上诉请求怎么写。

### 第一步：先算期限（最高优先级）

| 案件类型 | 对判决上诉 | 对裁定上诉 | 起算 |
|---|---|---|---|
| 民事 | **15 日** | **10 日** | 判决书/裁定书**送达之日**起 |
| 刑事 | **10 日** | **5 日** | 接到判决书/裁定书的**第二日**起 |
| 行政 | **15 日** | **10 日** | 判决书/裁定书**送达之日**起 |

规则要点：

- 期间届满的最后一日是法定节假日的，**顺延至节假日后第一日**；
- 期间不包括在途时间，上诉状**到期前交邮**的不算逾期（以交邮凭证为准）；
- 涉外案件、公告送达等特殊情形另有规则，需单独核对；
- **上诉期不能延长**（区别于其他期间），错过即生效，只能走再审/检察监督。

输出一张期限表：送达日 → 起算日 → 届满日 → 剩余天数 → 建议提交日（提前 3 个工作日）。

### 第二步：定上诉请求

按"改判"和"发回重审"两条路选：

- **请求改判**：写明"撤销××法院（20XX）××民初××号民事判决第 X 项，改判……"；
- **请求发回重审**：限于基本事实不清、严重违反法定程序等情形；
- **部分上诉**：只对不利判项上诉，写明"仅就第 X 项上诉"，未上诉部分在上诉期满后即生效。

请求必须**可执行、可量化**（金额、履行方式、驳回项），不能写"请求依法改判"了事。

### 第三步：三类错误归位

把不服的理由硬塞进三个抽屉（详见 `references/上诉理由类型化.md`）：

| 类型 | 表现 | 二审处理 |
|---|---|---|
| 认定事实错误 | 证据采信错误、举证责任分配错误、遗漏关键事实、认定与证据矛盾 | 改判或发回 |
| 适用法律错误 | 法律关系定性错、法条援引错、责任比例/计算标准错 | 改判 |
| 程序违法 | 未开庭、未质证、遗漏当事人、审判组织不合法、未送达 | 可能发回重审 |

一个理由只能进一个抽屉；"判决不公""法官偏袒"不是理由，必须落到具体证据或程序节点。

### 第四步：逐项对应判决理由写

格式：**一审认定 → 我方认为 → 依据（证据编号/法条）→ 影响的结果**。

禁止只写"一审认定事实错误"而不说错在哪一句、哪份证据。判决书第 X 页第 X 段要能对上。

### 第五步：刑事/行政的特殊点

- **刑事**：上诉不加刑（《刑事诉讼法》第二百三十七条），但检察院抗诉或自诉人上诉的除外；辩护人、近亲属上诉须经被告人同意；事实不清可请求改判或发回。
- **行政**：审查被诉行政行为合法性，被告负举证责任；上诉请求通常围绕"撤销/确认违法/履行法定职责"。

### 第六步：附件与份数

上诉状按对方当事人人数提交副本；附一审判决书复印件、身份证明、授权委托书、律师执业证复印件；上诉费按不服部分金额预交（逾期不交按撤回上诉处理）。

## 输出规范

```
<案件目录>/
  上诉状-<上诉人>-<YYYYMMDD>.md
  上诉期限核算表.md
  上诉争点分析.md          # 三类错误 + 改判空间判断
  上诉状-<上诉人>-<YYYYMMDD>.docx   # 需要时由 chinese-doc-formatter 生成
```

上诉状结构固定：标题 → 上诉人/被上诉人信息 → 案由与一审案号 → 上诉请求 → 上诉理由（分点） → 此致××××人民法院 → 上诉人签名/盖章 → 日期 → 附项。

风险标注统一三档：

- 🔴 必须处理：上诉期将届满或已过期、上诉请求与判项不对应、理由无证据支撑；
- 🟡 建议处理：缺少判决书页码定位、分类不清、新证据无逾期说明；
- ⚪ 提示：二审改判非必然，调解结案也是常见结果，应同步告知委托人成本。

## 质量闸门（交付前自检）

- [ ] 上诉期已按送达日核算，起算点写明"以送达回证为准"
- [ ] 上诉请求与不服判项一一对应，金额与判项一致
- [ ] 每一条理由都指向判决书具体段落或证据编号，无空洞指责
- [ ] 三类错误分类正确，没有把"事实认定"写成"法律适用"
- [ ] 未编造法条条号、案号、金额、日期；不确定写"相关条文待核"
- [ ] 刑事/行政案件已核对特殊规则（上诉不加刑、被告举证责任）
- [ ] 已提示：提交前由承办律师复核，法院只认正式签章文本
- [ ] 输出带「AI 辅助生成，需承办律师复核」标识
