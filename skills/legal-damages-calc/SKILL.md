# 损害赔偿计算器技能

## 这个技能解决什么

赔偿金额的争议，多数不在「该不该赔」，而在**算错**：误工费按 30 天乘、经济补偿的年限口径搞反、利息天数算头又算尾、违约金比例套错基数。算错一次，谈判和起诉都被动。

本技能把四类最常见请求拆成**固定公式 + 显式代入值**，每一项都能被对方拿着计算器复核；算不了的地方写「按当地标准待填」，绝不编数字。

## 适用 / 不适用

| 适用 | 不适用 |
|---|---|
| 人身损害赔偿逐项试算（医疗、误工、护理、营养、伙食、残疾赔偿金、精神抚慰金、交通） | 判断伤残等级、判断因果关系与责任比例 |
| 劳动争议：经济补偿 N、违法解除 2N、代通知金、加班费、未休年假、二倍工资差额 | 判断是「合法解除」还是「违法解除」（这是定性，不是算术） |
| 借款/欠款利息：单利、按日计息、分段利率 | 判断利率是否超过司法保护上限（只提示，不替用户定） |
| 违约金：按约定比例算金额、与损失 30% 比对提示调减风险 | 代替法院行使酌减权、预测判决结果 |

## 输入

先问清三类信息，缺一项就问，不要替用户填：

1. **类型**：人身损害 / 劳动 / 利息 / 违约金（可多类一起算）。
2. **基础数据**：金额、天数、起止日期、月工资、工作年限、约定利率/比例。
3. **口径参数**：当地上一年度城镇居民人均可支配收入、当地社平工资、伤残系数——**这些必须用户给或写「待填」**；本技能不内置任何地方标准数字。

拿不到的口径，在表里写「【待填：xx】」，并进入「待核项」。

## 工作流程

### 第零步：读法律档案

先读 `~/.deepwhale/深鲸法律档案.md`。不存在时，把仓库里的 `templates/法律档案.md` 复制过去并逐项问用户：
角色（律师/法务/当事人）、立场、执业地域、行文风格、风险偏好、升级链。
档案里没填的，不要假设。立场影响表述：代理被告时，同一份计算要同时给出「对方可能主张的口径」与「可抗辩点」。

### 第一步：定类型、收数据

按四类分别列字段（见 `references/计算口径.md`）。逐项确认单位：

- 金额：元；比例：百分数（如 20% 填 20，不是 0.2）；天数：自然日。
- 日期：`YYYY-MM-DD`。
- 利率：年利率百分数（如 3.45%）。

### 第二步：跑计算脚本

```bash
python3 scripts/calc.py --type injury  --medical 12000 --daily-income 300 --lost-days 20 ...
python3 scripts/calc.py --type labor   --monthly-wage 8000 --work-years 3.5 --mode N
python3 scripts/calc.py --type interest --principal 100000 --rate 6 --start 2024-01-01 --end 2024-12-31
python3 scripts/calc.py --type penalty --base 200000 --rate 20 --actual-loss 20000
python3 scripts/calc.py --demo --out ./赔偿计算
```

脚本只做算术与校验，不联网、不查标准。加 `--json` 输出机器可读结果，加 `--out DIR` 直接落 `计算表.csv` 与 `计算说明.md`。

### 第三步：人工复核三件事

1. **每个数字都有出处**：票据金额、工资流水、合同条款号、日历天数。
2. **口径写清楚**：误工按实际减少收入还是按行业标准；利息算头不算尾；N 的年限进位规则。
3. **区分「可主张」与「能拿到」**：表格算的是请求额，不是判决额；调减、封顶、举证不能都要在提示里写出来。

### 第四步：产出并交付

见「输出规范」。表里的每一行都必须能独立手算复现：`公式` 列写算式，`代入值` 列写实际数字。

## 输出规范

固定两份，放在用户指定目录（默认 `./赔偿计算/`）：

| 文件 | 内容 |
|---|---|
| `计算表.csv` | 列：类别、项目、公式、代入值、金额（元）、依据、待核项。UTF-8 带 BOM，Excel 双击可开 |
| `计算说明.md` | 汇总合计、逐项说明、法条依据、待核清单、免责声明 |

规则：

- 金额一律两位小数；合计 = 各行金额之和（先各自四舍五入再相加，保证表能对上）。
- 每个项目必须有「依据」：法条（写到条）、合同条款号、票据/流水编号，三者之一。
- 算不出来的项写 `【待填：当地上一年度城镇居民人均可支配收入】`，金额列留空并计入「待核项」，**不要用 0 冒充**。
- 需要正式提交的文书，转 `chinese-doc-formatter` 出 .docx/.pdf；本技能只出计算表。
- 结尾固定加：「本表为可复算草稿，不构成法律意见；正式主张前由承办律师复核当地标准与证据。」

## 质量闸门（交付前自检）

- [ ] 每个金额都能用「公式 + 代入值」手算出来，且结果一致
- [ ] 没有编造任何地方标准数字（人均可支配收入、社平工资、护理日标准）
- [ ] 伤残系数、年限、利率、比例的单位没有混（% vs 小数、日 vs 月）
- [ ] 经济补偿 N 与赔偿金 2N 没有叠加计算
- [ ] 利息天数口径写明（算头不算尾），分段已按利率调整日拆开
- [ ] 违约金已做 30% 损失比对，或明确写「未填损失，无法比对」
- [ ] 缺失信息用【待填：xx】，已列入待核清单
- [ ] 已加「AI 辅助生成，需承办律师复核」标识

## 输出示例

```
## 合计：106,650.00 元（人身损害，8 项）

| 项目 | 公式 | 代入值 | 金额（元） |
|---|---|---|---|
| 医疗费 | 按票据金额 | 票据 12,000.00 | 12000.00 |
| 误工费 | 日收入 × 误工天数 | 300.00 × 20 | 6000.00 |
| 残疾赔偿金 | 基数 × 年限 × 伤残系数 | 40000.00 × 20 × 10% | 80000.00 |
| 精神损害抚慰金 | 酌定（无公式） | 填报 5,000.00 | 5000.00 |

待核项：
- 残疾赔偿金基数 40000.00 为示例填报值，须按受诉法院所在地上一年度城镇居民人均可支配收入核定。
```
