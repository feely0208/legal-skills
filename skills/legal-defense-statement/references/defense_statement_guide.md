# 答辩状撰写指南

以中国执业律师视角，系统性地指导答辩状的撰写。涵盖法律依据、格式规范、各类案件答辩要点、原被告差异化策略及注意事项。

---

## 一、答辩状的法律依据

### 1.1 答辩权的法律基础

| 法律依据 | 条款内容 | 实务要点 |
|---------|---------|---------|
| 《民事诉讼法》第125条 | 人民法院应当在立案之日起五日内将起诉状副本发送被告，被告应当在收到之日起十五日内提出答辩状。 | **15日答辩期**严格把握，逾期可能丧失程序性抗辩权利 |
| 《民诉法解释》第233条 | 被告在答辩期内提出答辩状是权利而非义务，不提交答辩状不影响案件审理 | 答辩状不影响缺席判决的可能性 |
| 《民事诉讼法》第127条 | 管辖权异议应在提交答辩状期间提出 | 管辖权异议与答辩状可以同时提交，但管辖权异议需在答辩期内单独提出 |

### 1.2 答辩状的效力

- 答辩状中承认的事实，可能构成**诉讼上的自认**（《证据规定》第3-9条），具有免除对方举证责任的效力
- 答辩状中的否认需要有合理的理由支撑
- 答辩状中可以提出程序性抗辩（诉讼时效、管辖等）

## 二、答辩状格式规范

### 2.1 标题

- 民事案件：**民事答辩状**
- 行政案件：**行政答辩状**
- 二审案件：**民事上诉答辩状** / **行政上诉答辩状**
- 再审案件：**再审答辩状**

### 2.2 当事人信息

#### 自然人答辩人

```
答辩人：姓名，性别，XXXX年XX月XX日出生，X族，
         身份证号码：XXXXXXXXXXXXXXXXXX，
         职业：XXXX，住址：XXXXXXXXXXXXXX，
         联系电话：XXXXXXXXXXX。
```

#### 法人答辩人

```
答辩人：公司全称，
         统一社会信用代码：XXXXXXXXXXXXXXXXXX，
         住所地：XXXXXXXXXXXXXX，
         法定代表人：姓名，职务：XXXX，
         联系电话：XXXXXXXXXXX。
```

#### 被答辩人信息格式同上

### 2.3 正文结构

1. **案号、案由**：明确案件编号和纠纷类型
2. **引言**：说明答辩人针对何案提出答辩
3. **答辩请求**：逐项回应原告诉讼请求
4. **事实与理由**：系统性阐述答辩理由
5. **结论**：总结答辩意见，请求法院公正裁判

### 2.4 结尾格式

```
此致
XX人民法院

附：
1. 本答辩状副本X份
2. 证据材料X页

                                  答辩人（签名/盖章）：
                                  委托代理人（签名）：
                                  日期：    年    月    日
```

## 三、答辩策略设计

### 3.1 原告/被告立场自动判断逻辑

```
if 对方文书为"民事起诉状":
    答辩人 = 被告（最常见）
elif 对方文书为"民事上诉状":
    答辩人 = 被上诉人
elif 对方文书为"再审申请书":
    答辩人 = 被申请人
elif 对方文书为"反诉状":
    答辩人 = 本诉原告/反诉被告
```

### 3.2 被告答辩的核心策略

| 策略维度 | 操作方法 | 适用场景 |
|---------|---------|---------|
| **全面否认** | 逐项否认原告的全部诉讼请求和事实主张 | 原告起诉完全缺乏事实依据 |
| **部分承认+部分否认** | 承认对己方无害的事实，否认核心争议事实 | 部分事实属实，但法律责任不在己方 |
| **法律适用抗辩** | 援引有利的法条，指出原告法律适用的错误 | 事实争议不大，但原告法律论证有缺陷 |
| **程序抗辩** | 提出时效、管辖等程序性问题 | 存在明显的程序瑕疵 |
| **积极抗辩** | 主动提出答辩人的权利主张（如抵销） | 答辩人对原告也有债权/权利 |

### 3.3 原告作为答辩人的策略（反诉/上诉场景）

| 策略维度 | 操作方法 | 适用场景 |
|---------|---------|---------|
| **维护己方立场** | 反驳被告反诉理由，维护原告诉讼请求 | 被告提起反诉 |
| **强调举证责任** | 指出被告未能提供充分证据支持其主张 | 被告事实主张缺乏证据 |
| **指出程序问题** | 被告反诉不符合受理条件等 | 反诉与本诉无牵连关系 |
| **一审判决维护** | 引用一审判决的正确论述 | 上诉审中作为被上诉人 |

## 四、常见案件类型答辩要点

### 4.1 合同纠纷答辩要点

| 争议类型 | 答辩要点 | 关键法条 |
|---------|---------|---------|
| 货款/价款纠纷 | 验收是否合格、付款条件是否成就、是否存在质量瑕疵 | 《民法典》第525、526、595-647条 |
| 质量纠纷 | 是否在检验期内提出异议、质量标准的约定、是否经双方确认 | 《民法典》第617-624条 |
| 违约金纠纷 | 是否存在违约、违约金的计算基础、违约金是否过高 | 《民法典》第584、585条 |
| 合同效力纠纷 | 合同是否成立、是否存在无效情形、是否可撤销 | 《民法典》第143-157条 |
| 合同解除纠纷 | 解除条件是否成就、解除程序是否合法、解除后果如何处理 | 《民法典》第562-566条 |

### 4.2 民间借贷纠纷答辩要点

| 争议类型 | 答辩要点 | 关键法条 |
|---------|---------|---------|
| 借款事实 | 是否存在借款合意、是否实际交付、转账记录是否完整 | 《民法典》第679条 |
| 利息争议 | 利率是否超过LPR四倍、是否存在预扣利息、是否已还部分 | 《民间借贷司法解释》第25-29条 |
| 还款事实 | 已还款金额和时间的举证、还款性质的认定 | 《民法典》第561条（清偿抵充顺序） |
| 担保争议 | 保证方式是否明确、保证期间是否经过、公司担保是否经决议 | 《民法典》第686-702条 |

### 4.3 侵权纠纷答辩要点

| 争议类型 | 答辩要点 | 关键法条 |
|---------|---------|---------|
| 人身损害 | 因果关系是否存在、是否有过错、是否存在免责事由 | 《民法典》第1165-1179条 |
| 财产损害 | 损失金额的计算依据、是否存在被侵权人过错 | 《民法典》第1182-1184条 |
| 网络侵权 | 是否尽到合理注意义务、"通知-删除"规则是否适用 | 《民法典》第1194-1197条 |
| 产品责任 | 缺陷是否存在、是否系被侵权人使用不当、是否已过除斥期间 | 《民法典》第1202-1207条 |

### 4.4 劳动争议答辩要点

| 争议类型 | 答辩要点 | 关键法条 |
|---------|---------|---------|
| 解除争议 | 解除是否合法、是否支付经济补偿/赔偿金、解除程序是否合规 | 《劳动合同法》第39-48条 |
| 工资争议 | 工资标准的约定、加班费的计算、欠薪的事实 | 《劳动合同法》第30、31条 |
| 工伤争议 | 是否构成工伤、伤残等级认定、赔偿标准 | 《工伤保险条例》相关条款 |

### 4.5 婚姻家庭纠纷答辩要点

| 争议类型 | 答辩要点 | 关键法条 |
|---------|---------|---------|
| 离婚纠纷 | 感情是否确已破裂、是否存在法定离婚事由 | 《民法典》第1079条 |
| 子女抚养 | 抚养权的归属、抚养费的数额、探视权 | 《民法典》第1084-1087条 |
| 财产分割 | 婚前/婚后财产认定、是否存在隐藏/转移财产行为 | 《民法典》第1062-1066、1087条 |

## 五、证据组织建议

### 5.1 证据与答辩状中的事实对应

答辩状中每一个关键事实主张，原则上应有对应的证据支撑：

| 事实主张 | 建议证据类型 |
|---------|-------------|
| 付款事实 | 银行转账凭证、收据、发票、对账单 |
| 质量瑕疵 | 验收记录、检测报告、照片/视频、质量异议通知 |
| 合同内容 | 书面合同、补充协议、往来邮件 |
| 送达事实 | 邮寄凭证（EMS/快递单）、电子邮件、微信记录 |
| 履行过程 | 履约记录、验收单、进度报告、现场照片 |
| 时效中断 | 催款函、还款承诺书、部分还款记录 |

### 5.2 证据目录与答辩状的呼应

- 答辩状中引用的证据应有对应的证据编号
- 建议在答辩状的附件中列明证据清单
- 重要证据在答辩状正文中引用时应注明"（见证据X）"

## 六、常见错误及注意事项

### 6.1 格式错误

| 错误 | 纠正 |
|------|------|
| 标题写"答辩书" | 应为"民事答辩状"或"行政答辩状" |
| 将答辩人写成"被告" | 应写"答辩人"（虽然答辩人通常是被告，但文书格式用语为"答辩人"） |
| 将被答辩人写成"原告" | 应写"被答辩人" |

### 6.2 内容错误

| 错误 | 纠正 |
|------|------|
| 答辩请求不逐项对应 | 每个原告诉讼请求都应有对应的答辩意见 |
| 事实陈述过于笼统 | 应按时间顺序具体陈述 |
| 只有事实陈述，没有法律分析 | 事实与法律应结合论述 |
| 全盘否认，不给理由 | 每项否认都应有合理理由 |
| 在答辩状中提起反诉 | 反诉应另写反诉状，不要在答辩状中直接反诉 |

### 6.3 策略错误

| 错误 | 纠正 |
|------|------|
| 盲目全面否认 | 对己方无害的事实可以承认，有助于建立可信度 |
| 忽视程序抗辩 | 时效抗辩、管辖异议等是有效的防御手段 |
| 自认不利事实 | 答辩状中对己方不利且不必要的事实不要主动承认 |
| 引用失效法条 | 使用法条前确认是否现行有效 |
| 情绪化表达 | 保持专业、理性的语气，避免人身攻击 |

## 八、特殊类型答辩状的注意事项

### 8.1 上诉人答辩状（被上诉人）

- 重点在于维护一审判决，强调一审认定事实清楚、适用法律正确
- 指出上诉人未提出新证据、新理由
- 不要重复一审的全部论证，聚焦于上诉理由

### 8.2 反诉答辩状

- 答辩人是本诉原告，反诉被告
- 答辩状应针对反诉请求，不涉及本诉（本诉通过其他方式处理）
- 本诉和反诉可以合并审理

### 8.3 行政答辩状

- 被告（行政机关）承担举证责任
- 重点在于证明行政行为的合法性（事实清楚、证据确凿、程序合法、适用法律正确）
- 应提交作出行政行为的证据和依据
