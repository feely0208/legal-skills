# 证据链方法：从材料到待证事实

> 适用于民商事案件的诉前梳理。所有条号以现行文本为准，拿不准的已标「待核」。

## 一、先定要件，再谈证据

不看要件就读材料，一定会漏。常见案由的要件对应：

| 案由 | 待证事实（示例） | 举证要点 |
|---|---|---|
| 民间借贷 | F1 借贷合意；F2 款项交付；F3 到期未还 | 仅有转账凭证不足以证明借贷合意；被告抗辩系偿还旧债并举证后，原告仍须就合意举证（民间借贷司法解释相关规定，条号待核） |
| 买卖合同 | F1 合同成立；F2 交付；F3 价款未付/质量瑕疵 | 交付凭证是胜负手：签收单、物流签收、验收单 |
| 服务合同 | F1 服务内容与标准；F2 实际履行；F3 验收或视为验收 | 微信确认需求、过程稿、验收邮件 |
| 房屋租赁 | F1 租赁关系；F2 交付与返还；F3 欠租/损坏 | 交接单、水电读数、押金收据 |
| 劳动争议 | F1 劳动关系；F2 工资标准；F3 解除事实与理由 | 考勤、工资流水、解除通知；用人单位对解除合法性举证 |
| 离婚后财产 | F1 财产存在；F2 属共同财产；F3 对方隐匿/转移 | 不动产登记、股权登记、银行流水 |

写法要求：F 必须是**可被证据直接证明的事实**。「被告违约」不是事实，是结论；「被告 2024-06-01 未按约交付 200 箱货」才是。

## 二、四要素抽取：逐字段的判断标准

### 1. 时间

- 聊天记录取消息时间，不取截图时间；银行流水取交易时间，不取入账时间；
- 合同取双方签署时间；只有一方盖章的，取最后签署时间并注明；
- 时间只到月的，写「2024-03（具体日期待补）」，不要补一个具体日；
- 跨年、跨时效节点的日期必须双人核对——差一天可能改变时效结论。

### 2. 主体

这是最容易被跳过、也最容易被对方打掉的一环：

| 材料 | 要锁定的主体信息 |
|---|---|
| 微信 | 微信号、绑定手机号、实名信息（转账页可显示姓名尾字）、头像/朋友圈、聊天中的自称 |
| 支付宝 | 账号、实名、转账备注、账单详情 |
| 银行流水 | 户名、账号后四位、开户行 |
| 合同 | 签署人、盖章主体、授权文件 |
| 录音 | 说话人身份，靠称呼、自报、后续行为印证 |

主体对不上，整份材料降为「待补」。不要用「就是这个人」结案。

### 3. 金额

- 写清币种、数额、方向（A→B）、是否含息/费；
- 多笔转账做小计，并注明是否包含重复计算；
- 现金交付必须另有佐证（取现记录、见证人、当日聊天），否则标待补；
- 金额涂改、大小写不一致的借条/合同，标🔴并单独说明。

### 4. 行为

- 用动词短语，一句话一个动作；
- 区分「意思表示」与「实际履行」：答应还款 ≠ 还款；
- 沉默一般不构成意思表示，除非法律规定、当事人约定或交易习惯（《民法典》第一百四十条）；
- 语气词、表情包不单独作为意思表示，只作辅助。

## 三、映射表怎么写

```markdown
### F-02 款项交付｜要件：实际支付 200,000 元

| 方向 | 证据 | 证明内容 | 强度 |
|---|---|---|---|
| 支持 | E-01 银行流水 | 2024-03-01 张某账户转出 200,000 至李某账户 | 强（原始载体） |
| 支持 | E-02 微信 | 李某「收到了」 | 中（主体待证） |
| 反对 | E-07 李某流水 | 同日李某向张某转回 50,000 | 需解释 |

状态：**矛盾** 🔴
冲突字段：金额（200,000 vs 净额 150,000）
处理：核实 50,000 性质（还款/共同消费/走账），调取双方完整流水。
```

三条硬规则：

1. 一个 F 至少一行支持、一行「还差什么」，没有缺口的 F 多半是没看细；
2. 「强度」只能用强/中/弱，并给理由，不写「较充分」；
3. 矛盾必须写清**冲突字段**和**处理动作**，不能只写「存在矛盾」。

## 四、三性与证明力快检

### 真实性

- 原件、原始载体优先；复印件、截图不能单独作为认定事实的依据（《民事诉讼证据规定》第九十条）；
- 电子数据：制作者制作的与原件一致的副本、直接来源于电子数据的打印件，可视为原件（同规定第十五条）；
- 审查因素：系统硬件软件环境是否完整、是否处于正常运行状态、有无有效防止出错的监测核查手段、是否被完整保存传输提取、保存传输提取方式是否可靠（同规定第九十三条）；
- 对方不认可时，可申请公证保全、当庭演示原始载体、申请平台调取。

### 合法性

以严重侵害他人合法权益、违反法律禁止性规定或严重违背公序良俗的方法形成或获取的证据，不得作为认定事实的根据（《民诉法解释》第一百零六条）。

| 情形 | 判断 |
|---|---|
| 自己在自己参与的对话中录音 | 通常可用 |
| 在对方家中、酒店房间安装设备偷录 | 🔴 高风险，可能被排除 |
| 擅自登录对方微信导出记录 | 🔴 高风险，且可能涉刑 |
| 通过律师调查令调取银行流水 | 通常可用 |
| 购买、胁迫取得的材料 | 🔴 不可用 |

### 关联性

主体能否对应、时间能否对应、内容是否指向本案争议。三者有一项断裂，标「待补」而不是「已证」。

### 孤证与补强

不能单独作为认定案件事实根据的证据（《民事诉讼证据规定》第九十条）：当事人陈述、与一方有利害关系的证人证言、存有疑点的视听资料/电子数据、无法与原件核对的复制件等。遇到孤证：找第二份独立来源的材料，或转成公证/鉴定。

## 五、视角差异：同一材料的两种读法

| 材料 | 原告用法 | 被告用法 |
|---|---|---|
| 对方承认欠款 | 核心自认，固定原始载体 | 查上下文、查是否已抵销、查是否附条件 |
| 长期无催告 | 解释为关系良好、口头催过 | 时效抗辩（《民法典》第一百八十八条，三年） |
| 部分还款 | 证明债务存在（部分履行即承认） | 证明已履行部分、主张抵充顺序 |
| 合同未盖章 | 主张实际履行成立事实合同 | 主张合同未成立、无授权 |
| 己方发解除函 | 证明解除时点、后续损失起算 | 审查解除权是否成就、程序是否合法 |

输出时必须声明本次立场。中立审查则两列都写，并注明「两列仅供比较，不代表任何一方结论」。

## 六、常见错误对照

| 错误写法 | 正确写法 | 原因 |
|---|---|---|
| 「微信记录证明被告借款」 | 「E-02 微信记录显示李某于 2024-03-01 回复『收到了，年底还』，待证账号主体为李某」 | 结论不能代替证据描述 |
| 「时间约在 2024 年初」 | 「2024-03-01（E-01 流水时间）」 | 模糊时间无法排时间线 |
| 「转账 20 万」 | 「2024-03-01 张某→李某 200,000 元，附言『借款』」 | 缺主体、方向、时间 |
| 「证据充分，可以起诉」 | 「F1 已证，F2 待补交付凭证，建议补后再诉」 | 不做胜负承诺 |
| 「存在矛盾」 | 「金额矛盾：E-01 为 200,000，E-07 显示同日回转 50,000」 | 必须落到字段 |

## 七、缺口清单的优先级

- 🔴 必须补：不补则该要件不成立，直接影响能否立案或胜诉；
- 🟡 建议补：影响数额认定、证明力强弱或庭审主动权；
- ⚪ 提示：对方可能提出、但目前无需主动处理。

排序依据是「要件重要性 × 取得可行性」，不是「客户最在意」。取得不能的（超过保存期限、对方已注销），要写替代方案（间接证据组合、申请法院调取、证人），不能只写「无法取得」。

## 八、边界

- 本方法不判断证据能否被采信，只做结构化整理与风险提示；
- 不替代公证、鉴定、审计等专业程序；
- 涉密、涉个人信息材料只在本地处理，导出前脱敏。
