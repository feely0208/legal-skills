# 律师函技能

## 这个技能解决什么

律师函的成败不在措辞强硬，而在三件事：**主体写对、诉求写清、期限写死**。

写错主体（告错公司、法定代表人与公司混写）、诉求含糊（"尽快还款"没有金额和账户）、期限缺失（"限期答复"没有天数），函发出去等于白发——既不能中断诉讼时效，也拿不到对方恶意的证据。

本技能先把发函目的定下来，再按目的选结构，最后把送达和留痕一起交付。

## 适用 / 不适用

| 适用 | 不适用 |
|---|---|
| 合同已到期/违约，先催告再起诉 | 需要向法院提交的起诉状、答辩状、上诉状 |
| 行使法定或约定解除权，需通知对方 | 需要律师签名盖章对外出具的法律意见书 |
| 知识产权/商誉侵权，要求停止并保留追责 | 刑事控告书、报案材料 |
| 债权到期不还，催收并中断时效 | 行政投诉、举报信 |
| 劳动争议前的沟通函、履约催告 | 对方已起诉，需要应诉（找 legal-defense-statement） |

相邻交接：起诉 → `legal-complaint`；应诉 → `legal-defense-statement`；上诉 → `legal-appeal`；要先固定证据和时间线 → `legal-evidence-chain`；正式排版 → `chinese-doc-formatter`。

## 输入

必需：

1. 委托人主体信息（名称/姓名、统一社会信用代码或身份证号、住所、联系人）；
2. 收函人主体信息（同上；公司要写清法定代表人或主要负责人）；
3. 基础法律关系（合同名称与签订日期、借款/买卖/服务/侵权事实）；
4. 诉求（要多少钱、要做什么、要不要解除合同）；
5. 发函目的（催告 / 解除 / 侵权警告 / 催收）。

可选：已方证据编号、约定管辖、往来沟通记录、希望给出的答复期限。

缺失的一律写【待补：xx】，不要用"某公司""大约""近期"糊过去。

## 工作流程

### 第零步：读法律档案

先读 `~/.deepwhale/深鲸法律档案.md`。不存在时，把仓库 `templates/法律档案.md` 复制到该路径，再逐项问用户：角色（律师/法务/当事人）、立场、执业地域、行文风格、风险偏好、升级链。档案里没填的，不要假设。

重点取三项：称呼习惯（本律师/我们）、语气（克制/强硬）、对外发文前的复核人。

### 第一步：定目的，选函型

| 目的 | 函型 | 核心诉求 | 关键期限 |
|---|---|---|---|
| 让对方履行 | 催告函 | 履行具体义务 + 违约金 | 7–15 日 |
| 终止合同关系 | 解除通知函 | 确认解除 + 结算 + 返还 | 到达即解除，另给结算期 |
| 制止侵权 | 侵权警告函 | 停止 + 删除 + 赔偿 + 保证 | 3–7 日 |
| 收钱 | 催收函 | 本金 + 利息/违约金 + 费用 | 7–15 日 |

目的不清就先问，不要一函多目的（既解除又要继续履行，自相矛盾）。

### 第二步：核主体与金额

- 公司：名称与统一社会信用代码、注册地址、法定代表人，四项齐全；
- 个人：姓名、身份证号（可只写部分）、住所；
- 金额：本金、利息起算日与利率、违约金计算方式、已付金额，逐项列明，给出合计；
- 合同依据：写条款号，不写"合同约定"了事。

金额算不出就写【待补：截至X日的欠付本金及利息，按XX计算】。

### 第三步：写五段

1. **事实**：时间、主体、行为、金额，按时间顺序，只写有证据支撑的；
2. **依据**：合同条款 + 法律条文（条号拿不准写"相关条文待核"）；
3. **要求**：可执行、可验收（付到哪个账户、几天内、做什么动作）；
4. **期限**：明确天数与截止日，写"自本函送达之日起 X 日内"；
5. **后果**：逾期将采取的措施（诉讼、保全、举报、公开），只写做得到的。

### 第四步：定调子

强硬不等于辱骂。禁止出现：人身攻击、威胁曝光隐私、以刑事报案相要挟索取财物、虚构已立案/已查封。这类表述可能反成对方证据（敲诈勒索、名誉侵权、虚假陈述）。

### 第五步：送达与留痕

单独出一份清单（见 `references/送达与留痕.md`）：EMS 法院专递/邮政特快 + 详情单写明"律师函"、内件品名、保留面单与投递查询记录；电子邮件需合同约定或对方确认的地址；微信/短信需可识别身份。送达地址优先用合同约定地址，其次工商登记地址。

### 第六步：复核与交付

逐项过质量闸门；输出 .md 定稿 + 送达清单；需要正式 Word/PDF 时用同套件 `chinese-doc-formatter` 排版（律师函通常用函件格式，不用公文红头）。

## 输出规范

```
<案件目录>/
  律师函-<对方简称>-<YYYYMMDD>.md      # 正文，未排版
  律师函-<对方简称>-<YYYYMMDD>.docx    # 需要时由 chinese-doc-formatter 生成
  送达与留痕清单.md
  发函前核对表.md                      # 可选，逐项打勾
```

正文结构固定：标题（"律师函"）→ 编号【待补：所函号】→ 收函人 → 正文五段 → 落款（律所名称、律师姓名、日期）→ 附件清单。

风险标注统一三档，写在正文末尾与清单里：

- 🔴 必须处理：主体信息错误、金额无法复算、期限缺失、依据缺失、可能构成胁迫/诽谤的表述；
- 🟡 建议处理：送达方式单一、缺少对方回复渠道、后果段过于笼统；
- ⚪ 提示：律师函不必然产生法律效果，是否需要同步起诉/保全由承办律师判断。

## 质量闸门（交付前自检）

- [ ] 每个法律结论都有依据（合同条款号 / 法条 / 证据编号），无源不写
- [ ] 没有编造法条条号、案号、金额、日期；不确定的写"相关条文待核"
- [ ] 信息缺失处用【待补：xx】占位，不猜
- [ ] 主体信息与工商登记/身份证件一致，法定代表人与公司未混写
- [ ] 金额可复算：本金 + 利息 + 违约金 = 合计，计算口径写明
- [ ] 期限写成"自送达之日起 X 日内"，不是"尽快""限三日内答复"这类模糊表述
- [ ] 没有"保证胜诉""一定追回""已立案""已查封"等不实表述
- [ ] 输出带「AI 辅助生成，需承办律师复核」标识
- [ ] 发函前已提示：律师签字、律所盖章、编号登记、送达留痕，由承办律师人工确认
