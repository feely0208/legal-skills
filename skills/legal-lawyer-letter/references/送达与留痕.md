# 送达与留痕清单

> 律师函本身不是生效裁判，它的价值在于"证明对方已被告知"。送达不成立，内容再硬也白写。

## 一、送达方式效力排序

| 优先级 | 方式 | 证明力 | 前提 |
|---|---|---|---|
| 1 | 合同约定的送达地址 + EMS 邮政特快 | 强 | 合同有效且地址写明"可作为送达地址" |
| 2 | 工商登记地址 / 身份证住址 + EMS | 强 | 地址与登记一致，退件也算送达 |
| 3 | 公证送达 | 最强 | 费用高，用于重大案件 |
| 4 | 电子邮件（合同约定邮箱） | 中 | 需证明邮箱归属 |
| 5 | 微信/短信/传真 | 弱 | 需证明号码/账号为对方本人使用 |
| 6 | 托人转交、口头告知 | 很弱 | 一般不足以单独证明 |

**结论：能用 EMS 就用 EMS，同时补发一封电子邮件。**

## 二、EMS 填写要点

- [ ] 收件人写**公司全称**（不是"王总"），电话写工商登记或合同上的号码
- [ ] 地址写**工商登记地址**；与合同地址不一致时，两个地址各寄一份
- [ ] 内件品名写"**律师函（关于××拖欠货款事宜）**"，不要写"文件"
- [ ] 选择**邮政特快专递（EMS）**，不用普通快递；法院专递仅用于诉讼文书
- [ ] 保留：寄件人存联原件、面单照片、内件拍照（函件与信封同框）、投递查询截图
- [ ] 投递结果打印或截图存档：签收人、签收时间；**拒收/退回同样要留存退回件，原封不动保存**

## 三、邮件/微信送达要点

- [ ] 邮件发至合同约定邮箱；无约定的，发至对方在往来函件/名片/官网上公示的邮箱
- [ ] 邮件主题写明"律师函：关于××事宜（××律师事务所）"
- [ ] 开启"已读回执"，保留发送成功记录与完整邮件原文（含邮件头）
- [ ] 微信发送时，先确认对方身份（实名、头像、聊天记录中自认的身份），保留原始载体，不删除对话
- [ ] 重要案件可对发送过程做**时间戳/公证**

## 四、留痕证据清单（交付时附上）

| 序号 | 材料 | 作用 |
|---|---|---|
| 1 | 律师函定稿（PDF） | 证明内容 |
| 2 | 律所函件登记表/编号 | 证明发文主体与时间 |
| 3 | EMS 面单 + 内件照片 | 证明寄出内容 |
| 4 | 投递查询记录（签收/拒收/退回） | 证明送达结果 |
| 5 | 电子邮件原文与发送记录 | 补充送达 |
| 6 | 对方回复（如有） | 证明对方已知悉、可能构成自认 |
| 7 | 委托书、授权范围 | 证明发函权限 |

## 五、送达的法律效果与常见误判

1. **诉讼时效中断**：权利人向义务人提出履行请求，时效中断，从中断时起重新计算（《民法典》第 195 条）。前提是**能证明请求已到达对方**——这正是留痕的意义。
2. **合同解除的生效时点**：解除通知到达对方时合同解除（《民法典》第 565 条）。解除函的送达日直接决定解除日，进而影响结算、违约金起算。
3. **拒收不等于未送达**：寄至合同约定地址或工商登记地址，因对方原因拒收、无人签收而退回的，通常可主张已尽通知义务；但需保留退回原件。
4. **地址写错 = 白寄**：寄到对方已搬迁的旧地址且无证据证明其仍在该处，难以认定送达。

## 六、常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 用普通快递寄律师函 | 证明力弱，对方可否认收到 | 用 EMS 或挂号信 |
| 内件品名写"文件" | 无法证明寄的是律师函 | 写明"律师函+事由" |
| 只发微信，未保留原始载体 | 截图真实性易被否 | 双通道 + 原始设备留存 |
| 寄出后不查投递结果 | 不知是否送达，时效中断存疑 | 一周内查询并截图归档 |
| 退回件拆开丢弃 | 丧失"已尽通知义务"的证据 | 原封保存退回件 |
| 送达地址与合同约定不一致且未说明 | 对方抗辩未收到 | 按约定地址优先，另址补寄 |

> 本清单为操作提示，具体送达效力由法院结合证据认定。

## 七、送达地址的三个来源与优先级

1. **合同约定的送达地址**（最优）：合同里写了"本地址可作为诉讼文书及法律文书的送达地址"的，即使对方搬走，寄至该地址通常也视为送达。
2. **工商登记/户籍地址**（次优）：公司以国家企业信用信息公示系统登记地址为准；个人以身份证地址或户籍地为准。寄前截图留存登记信息，证明寄送时地址有效。
3. **实际经营地/常用联系地址**（补充）：从合同履行、发票抬头、名片、官网上获取，需能说明来源；建议与 1、2 同时寄送。

三者不一致时，**两个地址各寄一份**，并在清单里记录两个单号。多花一份邮费，换掉一个送达争议。

## 八、一次完整送达的时间线（示例）

| 日期 | 动作 | 留存 |
|---|---|---|
| D-1 | 定稿、律所盖章、编号登记 | 定稿 PDF、函件登记表 |
| D | EMS 寄出（内件拍照） | 面单存联、内件与信封同框照 |
| D+1 | 邮件同步发送 | 邮件原文、已读回执 |
| D+3 | 查询投递状态 | 查询截图（签收人/时间） |
| D+7 | 仍未签收则电话核实、必要时补寄 | 通话记录、补寄单号 |
| D+15 | 归档：函件 + 全部送达凭证 | 案件卷宗 |

## 九、对方常见抗辩与应对

| 对方说法 | 应对 |
|---|---|
| "没收到" | 出示 EMS 投递记录 + 合同约定地址条款 |
| "收到的是空白纸/其他文件" | 出示内件照片、内件品名记录 |
| "这个地址早就不用了" | 出示寄送时的工商登记截图；合同约定地址优先 |
| "邮件不是我们公司邮箱" | 出示该邮箱在合同、发票、官网上的使用记录 |
| "微信不是本人" | 出示聊天中对方自认身份、转账记录、实名信息 |
| "函件内容不实，损害商誉" | 逐项对应证据，确保每句有出处；必要时先做证据保全 |

## 十、归档要求

一个案件一个函件文件夹，命名 `YYYYMMDD-律师函-收函人简称`，内含：定稿、盖章扫描件、面单、投递记录、邮件原文、对方回复。诉讼阶段可直接作为证据提交，不用回头翻聊天记录。
