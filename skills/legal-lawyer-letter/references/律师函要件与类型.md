# 律师函要件与类型对照

> 用途：起草前对照、交付前自查。条号依 2021 年修正的《民事诉讼法》文本标注；2023 年修正后请以国家法律法规数据库现行文本核对。

## 一、四类函的必备要素

| 要素 | 催告函 | 解除通知函 | 侵权警告函 | 催收函 |
|---|---|---|---|---|
| 发函主体 | 委托人 + 律所 | 同左 | 权利人 + 律所 | 债权人 + 律所 |
| 必须写明的权利基础 | 合同条款 + 履行期 | 约定解除权条款 / 法定解除事由 | 权利证书号（商标/专利/著作权登记号） | 借据/合同 + 到期日 |
| 核心诉求 | 履行具体义务 | 确认合同于到达日解除 | 停止 + 删除 + 下架 + 赔偿 | 还本 + 付息 |
| 期限 | 7–15 日 | 解除即时生效，另给 15–30 日结算期 | 3–7 日 | 7–15 日 |
| 附带动作 | 保留解除权 | 要求返还财物、结算、交接 | 要求提供销售数据、出具不再侵权承诺 | 要求提供还款计划、追加担保 |
| 典型后果表述 | 起诉 + 主张违约金 | 起诉确认解除效力 + 索赔 | 行政投诉 + 诉讼 + 平台投诉 | 起诉 + 保全 + 申请限高 |

## 二、五段式逐段检查表

### 1. 事实段

- [ ] 时间精确到日，不写"去年""前段时间"
- [ ] 主体用全称，首次出现给简称并加引号
- [ ] 金额写明币种、是否含税、已付与未付
- [ ] 每个关键事实能在附件里找到对应证据
- [ ] 不写未经证实的主观判断（"贵司恶意欺诈"需有依据，否则改"贵司未按约履行"）

### 2. 依据段

- [ ] 合同引用到条款号，并摘录关键句
- [ ] 法条引用到条，条号不确定写"相关条文待核"
- [ ] 不使用已废止的《合同法》《物权法》《担保法》（2021-01-01 起由《民法典》取代）
- [ ] 违约金标准写明计算方式，不写"按法律规定"

常用条文（按需选用，均需核对现行文本）：

| 场景 | 条文 | 要点 |
|---|---|---|
| 金钱债务履行 | 《民法典》第 579 条 | 一方未支付价款、报酬等，对方可请求支付 |
| 违约责任 | 《民法典》第 577 条 | 继续履行、补救措施、赔偿损失 |
| 逾期付款利息 | 《民法典》第 676 条 | 借款逾期应按约定或国家规定支付逾期利息 |
| 合同解除通知 | 《民法典》第 565 条 | 通知到达对方时合同解除；可诉请确认解除效力 |
| 法定解除情形 | 《民法典》第 563 条 | 迟延履行主要债务经催告后仍不履行等 |
| 诉讼时效中断 | 《民法典》第 195 条 | 向义务人提出履行请求，时效中断 |
| 侵权责任 | 《民法典》第 1165 条 | 过错侵权，行为人承担侵权责任 |
| 网络侵权通知 | 《民法典》第 1195 条 | 权利人通知平台采取删除、屏蔽等措施 |

### 3. 要求段

- [ ] 动词可执行：支付、交付、停止、删除、书面答复
- [ ] 金额给出总数，同时给计算过程
- [ ] 收款账户信息完整（户名、开户行、账号），避免对方"没账户没法付"
- [ ] 要求书面答复的，给出收件邮箱/地址

### 4. 期限段

| 写法 | 评价 |
|---|---|
| "自本函送达之日起 10 日内" | ✅ 起算点明确 |
| "10 日内" | 🟡 起算点不明，易争议 |
| "尽快""限期""三日内答复" | 🔴 无法验收，等于没写 |
| "2026年11月10日前" | ✅ 但需同时说明送达方式与推定送达日 |

### 5. 后果段

- [ ] 只写做得到的事（没委托诉讼阶段就不要写"已向法院起诉"）
- [ ] 不写"将追究刑事责任"作为施压手段（可能被认定为要挟）
- [ ] 保留权利条款必备："本函不构成对任何权利的放弃"

## 三、绝对不要写的表述

| 错误写法 | 风险 | 改为 |
|---|---|---|
| "保证胜诉""一定能追回" | 违反执业规范，构成不当承诺 | "本律师将依授权采取法律措施" |
| "已向法院立案/已查封"（未发生） | 虚假陈述，反成对方证据 | 删除，或改为"将于X日内提起诉讼" |
| "不还钱就让你坐牢" | 可能构成敲诈勒索、胁迫 | "将依法主张民事权利" |
| "将向媒体曝光你个人隐私" | 侵犯隐私/名誉，可能被反诉 | "将依法向监管部门投诉" |
| 人身侮辱、辱骂 | 名誉侵权，函件丧失证明价值 | 删除，只陈述事实 |
| "你方涉嫌合同诈骗"（无证据） | 诽谤风险 | "你方未按约履行，已构成违约" |

## 四、常见错误对照

| 错误 | 正确 | 原因 |
|---|---|---|
| 收函人写"××公司负责人" | 写公司全称 + 法定代表人 | 送达对象不明，无法证明已通知 |
| 把法定代表人个人列为收函人 | 公司与个人分开列，视是否主张个人责任 | 公司债务原则上不及股东/法定代表人 |
| 金额只写"欠款约20万" | 写"人民币 200,000 元（含本金180,000元、利息20,000元）" | 诉求不确定，诉讼时无法对应 |
| 解除函写"限你方3日内整改，否则解除" | 先催告（给合理期限），届满再发解除函 | 解除权行使附条件，混写会削弱效力 |
| 侵权函不写权利证书号 | 写明商标注册号/专利号/登记号 | 无权利基础，警告函可能构成不正当竞争 |
| 只发微信截图，无原始载体 | EMS + 电子邮件双通道，保留原始记录 | 截图易被质疑真实性 |
| 函件无编号、无存档 | 律所统一编号并归档 | 后续诉讼需证明发函事实 |

## 五、发函前的三个判断

1. **发函是否有实际意义？** 对方已明确拒付且无履行能力，函件只增加时间成本；此时可直接起诉并申请保全。
2. **会不会打草惊蛇？** 有转移财产迹象的，先保全后发函，或同步进行。
3. **函件内容会不会成为对方证据？** 函中自认的事实（如"我方确实延迟交货3天"）会被对方引用，落笔前先想清楚。

> 本文件为起草辅助，不构成法律意见。正式发函须由承办律师复核并签字。
