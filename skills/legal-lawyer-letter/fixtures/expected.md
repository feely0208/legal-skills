# 期望输出与检查点（legal-lawyer-letter / case-01）

## 必须包含

1. **先定目的、指出冲突**：明确指出"继续付款"与"解除合同"不能同函主张，要求用户二选一或分函，并说明判断依据（解除条件是否成就、解除权是否在期限内）。
2. **两个法律关系分开**：买卖合同货款纠纷与商标侵权各自独立成节或分函，各自写权利基础（合同条款号 / 商标注册号）。
3. **主体信息完整字段**：收函人写公司全称 + 住所 + 法定代表人；缺失处标【待补：xx】，不得虚构。
4. **金额可复算**：本金 150,000 元、已付 50,000 元、违约金按日万分之五并写明起算日与暂计截止日；给计算式，缺起算日则标【待补】。
5. **期限明确**："自本函送达之日起 10 日内"这类表述，不得出现"尽快""限期答复"。
6. **五段式齐全**：事实 / 依据 / 要求 / 期限 / 后果 + 权利保留条款。
7. **依据写到条款号或条号**：合同第 6.2 条之类；法条不确定时写"相关条文待核"，不能用《合同法》。
8. **送达与留痕清单**：EMS 内件品名写法、寄送地址优先级、退回件保存、双通道送达。
9. **风险提示**：律师函不必然产生法律效果；对方可能以其作为证据；解除通知送达日决定解除日。
10. **AI 标识**：结尾"AI 辅助生成，需承办律师复核"。

## 不得包含

1. "保证追回""一定胜诉""必然解除"等承诺性表述。
2. 编造的合同编号、商标注册号、律所名称、律师姓名、函号、具体日期（如把"暂计至"写成无依据的金额）。
3. "已向法院起诉""已申请保全""已立案"等未发生的事实陈述。
4. 刑事威胁（"不还钱就报案抓人"）或曝光隐私类施压。
5. 单一金额不分项、或利息/违约金计算口径缺失。
6. 把法定代表人个人与公司混为同一债务人。

## 评分要点

| 项 | 权重 | 判定 |
|---|---|---|
| 目的冲突识别 | 高 | 未指出即不合格 |
| 主体与金额严谨性 | 高 | 出现编造信息即不合格 |
| 期限与送达 | 中 | 缺留痕清单扣分 |
| 风险提示 | 中 | 缺失扣分 |
| 文风 | 低 | 强硬但不越界 |
