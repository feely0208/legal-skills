# 期望输出与检查点（legal-enforcement / case-01）

## 必须包含

1. **结论先行**：不需要重新起诉，应向原执行法院**申请恢复执行**（附终本裁定书），并说明终本后恢复不受 2 年申请执行时效限制。
2. **时效起算正确**：分期履行从最后一期履行期限届满之日（2026-03-31）起算，至 2028-03-31；明确指出不能按 2025-11-10 生效日计算。
3. **加倍利息分期计算**：第一期 100,000 元自 2026-01-01 起算，第二期 100,000 元自 2026-04-01 起算；已付 50,000 元按笔冲抵（先冲抵到期在先的一期），基数相应调整。
4. **计算式与金额**：日万分之一点七五，列出天数、日息、金额，暂计至 2026-10-29，并注明"以执行法院核算为准"。
5. **追加股东的条件**：区分"未实缴出资（认缴期限届满）"与"一人公司财产混同"两条路径，指出需调取工商内档、审计报告等证据，不能仅凭一人公司身份。
6. **应收账款路径**：申请法院向次债务人发出履行到期债务通知；次债务人异议时转代位权诉讼，不能直接扣划。
7. **财产线索表**：新账户（开户行已知、账号待查）、应收账款（合同、次债务人、金额）、股权，标注来源与待核实状态。
8. **执行策略排序**：恢复执行 → 网络查控新账户 → 冻结应收账款 → 限高/失信 → 追加股东 → 必要时拒执线索移送。
9. **风险提示**：终本不等于拿到钱；追加失败要承担相应成本；应收账款可能被其他债权人轮候冻结。
10. **AI 标识**：结尾"AI 辅助生成，需承办律师复核"。

## 不得包含

1. 建议"重新起诉"或"另行起诉同一笔债务"。
2. 从调解书生效日 2025-11-10 起算 2 年时效。
3. 把两期债务合并从同一日期起算加倍利息。
4. 断言"一人公司股东必然承担连带责任"或"追加一定成功"。
5. 编造新账户账号、应收账款合同编号、次债务人名称、终本裁定案号。
6. "保证能执行到 30 万""这笔钱一定能拿回来"类承诺。
7. 把执行申请费写进申请标的额。

## 评分要点

| 项 | 权重 | 判定 |
|---|---|---|
| 恢复执行 vs 重新起诉 | 高 | 建议重新起诉即不合格 |
| 时效起算 | 高 | 按生效日算即不合格 |
| 分期加倍利息 | 高 | 合并起算扣分 |
| 追加股东条件 | 中 | 只说"一人公司就连带"扣分 |
| 应收账款路径 | 中 | 直接扣划表述扣分 |
| 风险与不承诺 | 中 | 出现保证性表述扣分 |
