# 强制执行申请技能

## 这个技能解决什么

拿到胜诉判决只是拿到一张纸。执行阶段真正决定成败的是三件事：**文书生效了没有、时效过了没有、财产在哪**。

最常见的浪费：履行期还没届满就去申请（被退回）、超过 2 年才想起来（法院受理但对方一提出时效抗辩就麻烦）、申请书只写"请求强制执行"而不提供任何财产线索（只能等总对总查询碰运气）。

本技能先做三道资格核对，再写申请书，最后给执行策略与终本预案。

## 适用 / 不适用

| 适用 | 不适用 |
|---|---|
| 判决/裁定/调解书生效，对方逾期不履行 | 一审还没生效，需要上诉（找 legal-appeal） |
| 仲裁裁决、公证债权文书、支付令不履行 | 诉讼中防转移财产（找 legal-preservation） |
| 已终本，发现新财产要恢复执行 | 执行异议、案外人异议的实体争议审理 |
| 需要追加股东/关联公司为被执行人 | 破产申请（程序不同） |
| 要评估限高、失信、拒执罪的适用 | 刑事附带民事的执行之外的其他刑事程序 |

相邻交接：查财产线索与资金流向 → `legal-evidence-chain`；诉前/诉中保全 → `legal-preservation`；文书排版 → `chinese-doc-formatter`。

## 输入

必需：

1. 执行依据（判决书/裁定书/调解书/仲裁裁决/公证债权文书）全文，含**生效日期**；
2. 履行期限与履行情况（付了多少、还欠多少、有没有部分履行）；
3. 申请执行人、被执行人身份信息（公司：全称+统一社会信用代码+住所+法定代表人；个人：姓名+身份证号+住所）；
4. 是否已申请过执行、是否终本（终本裁定日期与案号）。

可选：已知财产线索、被执行人涉诉/涉执情况、是否有转移财产迹象、担保人信息。

**关键**：文书写"本判决于 X 年 X 月 X 日生效"，必须有生效证明或送达回证支撑；没有就写【待补：生效日期，以生效证明为准】。

## 工作流程

### 第零步：读法律档案

先读 `~/.deepwhale/深鲸法律档案.md`。不存在时，把仓库 `templates/法律档案.md` 复制过去，逐项问：角色、立场、执业地域、行文风格、风险偏好、升级链。重点取：常用法院、风险偏好（决定是否激进申请拘留/拒执移送）。

### 第一步：三道资格核对（不过就别写）

| 核对项 | 标准 | 不过怎么办 |
|---|---|---|
| 文书是否生效 | 一审判决过了上诉期未上诉；二审判决作出即生效；调解书签收即生效 | 等生效或先上诉 |
| 履行期是否届满 | 判决主文确定的履行期限最后一日已过 | 等届满，届满次日再申请 |
| 时效是否经过 | 一般 **2 年**，自履行期间最后一日起算；分期履行的从最后一期起算；未定履行期的从生效之日起算 | 已过：仍可申请，但对方提时效抗辩风险高；核查有无中止/中断事由 |

时效可中止、中断（适用诉讼时效规则）：申请执行、对方同意履行、部分履行、达成和解等可构成中断。**每次催告都要留痕**。

### 第二步：定管辖

- 第一审人民法院，或
- 与第一审人民法院同级的**被执行人财产所在地**人民法院。

两者可选其一；财产集中在外地的，选财产所在地更利于查控。仲裁裁决、公证债权文书向被执行人住所地或财产所在地中级/基层法院申请（按标的额确定级别管辖）。

### 第三步：算钱

执行标的 = 本金 + 一般债务利息（按生效文书确定的口径）+ 迟延履行期间的加倍部分债务利息 + 诉讼费/保全费 + 执行费（由被执行人负担，申请人不预交）。

**加倍部分债务利息 = 债务本金 × 日万分之一点七五 × 迟延履行期间天数**（《最高人民法院关于执行程序中计算迟延履行期间的债务利息适用法律若干问题的解释》）。一般债务利息按文书确定另算，两者不重复。

计算口径与示例见 `references/执行流程与期限.md`。

### 第四步：财产线索表

逐条给字段（开户行+账号、不动产坐落+证号、车辆车牌+车架号、股权公司+比例、应收账款次债务人），并标注来源与核实状态。没有线索也要交空表并说明"申请法院启动总对总查控"。

### 第五步：写执行策略

按"先控后压"排序：

1. **查控**：申请网络查控（银行存款、不动产、车辆、证券、网络资金）；
2. **限高**：限制高消费（乘坐飞机高铁、星级酒店、子女就读高收费学校等）；
3. **失信**：纳入失信被执行人名单（有履行能力而拒不履行等情形）；
4. **限制出境**：必要时申请；
5. **追加被执行人**：股东未实缴出资、抽逃出资、一人公司财产混同、未经清算注销等（依《最高人民法院关于民事执行中变更、追加当事人若干问题的规定》）；
6. **刑事**：拒不执行判决、裁定罪线索移送；
7. **其他**：审计调查、悬赏公告、代位执行到期债权。

### 第六步：终本预案

法院穷尽措施未发现可供执行财产的，会裁定终结本次执行程序。终本不是结案：

- 终本后发现有可供执行财产的，可**再次申请执行，不受 2 年时效限制**；
- 终本期间仍可申请续封、恢复查控、申请限高/失信；
- 每 6 个月可申请查询一次财产情况（以法院实际操作与规定为准）。

## 输出规范

```
<案件目录>/
  强制执行申请书-<被执行人>-<YYYYMMDD>.md
  执行标的计算表.csv
  被执行人财产线索表.csv
  执行策略与终本预案.md
```

申请书结构：标题 → 申请执行人/被执行人信息 → 请求事项（执行标的金额 + 执行依据）→ 事实与理由（生效、履行期届满、未履行、时效未过）→ 此致法院 → 申请人签章 → 日期 → 附件。

风险标注统一三档：

- 🔴 必须处理：文书未生效、履行期未届满、2 年时效存疑、金额无法复算；
- 🟡 建议处理：无线索、未申请限高/失信、终本后未安排恢复；
- ⚪ 提示：执行到位取决于被执行人财产状况，不承诺结果；追加被执行人有败诉成本。

## 质量闸门（交付前自检）

- [ ] 已核对生效日期、履行期届满日、2 年时效起算点，三项各有依据
- [ ] 执行标的金额可复算（本金、利息、加倍利息、费用分列）
- [ ] 加倍部分按日万分之一点七五计算，未与一般债务利息混算
- [ ] 财产线索有具体字段，无编造账号/证号/车牌
- [ ] 终本后的恢复执行路径已说明
- [ ] 未承诺"一定能执行到""保证拿回钱"
- [ ] 已提示：执行申请需提交原件/生效证明，由承办律师复核
- [ ] 输出带「AI 辅助生成，需承办律师复核」标识
