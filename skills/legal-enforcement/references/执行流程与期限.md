# 执行流程与期限

> 条号以现行《民事诉讼法》及执行类司法解释文本核对。地方执行实践差异大，以受理法院口径为准。

## 一、申请执行时效

| 情形 | 起算点 |
|---|---|
| 文书规定了履行期间 | 履行期间的**最后一日起**算 |
| 分期履行 | 从**最后一期**履行期限届满之日起算 |
| 未规定履行期间 | 文书**生效之日**起算 |
| 一般期间 | **2 年** |

- 适用诉讼时效的中止、中断规则；
- 中断事由：申请执行、被执行人同意履行、部分履行、达成执行和解、书面催告等；
- 超过 2 年申请，法院仍应受理，但被执行人提出时效抗辩且成立的，可能裁定不予执行；
- **终本后再次申请不受 2 年限制**（《民事诉讼法司法解释》关于终本后恢复执行的条款，条号待核）。

## 二、申请材料清单

| 序号 | 材料 | 注意 |
|---|---|---|
| 1 | 执行申请书 | 按被执行人人数 + 1 份 |
| 2 | 生效法律文书原件/复印件 | 判决书、裁定书、调解书、仲裁裁决书、公证债权文书 |
| 3 | 生效证明 | 一审判决需法院出具；二审判决以送达即生效说明 |
| 4 | 申请人身份证明 | 自然人身份证；法人营业执照 + 法定代表人身份证明 |
| 5 | 授权委托书 + 律师证复印件 | 注明代理权限（代为申请执行、代收款项等） |
| 6 | 被执行人身份信息 | 公司需工商登记信息；个人需身份证号/户籍地址 |
| 7 | 财产线索材料 | 有则提供，无则申请法院查控 |
| 8 | 履行情况说明 | 已付/未付金额、催告记录 |
| 9 | 送达地址确认书 | 各法院格式不同 |

## 三、执行措施与启动条件

| 措施 | 条件 | 期限/效果 |
|---|---|---|
| 网络查控 | 立案后即可申请 | 覆盖银行存款、不动产、车辆、证券、网络资金 |
| 限制高消费 | 被执行人未按执行通知书指定期间履行 | 无期限，履行完毕或提供担保后解除 |
| 纳入失信名单 | 有履行能力而拒不履行、妨碍抗拒执行等 | 一般 2 年，情节严重可延长 |
| 限制出境 | 有必要 | 由法院通报出入境管理机关 |
| 查封/扣押/冻结 | 查到财产 | 存款 1 年、动产 2 年、不动产及其他财产权 3 年，到期需续 |
| 罚款、拘留 | 拒不履行、妨害执行 | 拘留最长 15 日 |
| 拒不执行判决裁定罪 | 情节严重 | 移送公安，可自诉 |
| 追加被执行人 | 股东未实缴/抽逃出资、一人公司混同、未经清算注销等 | 依《变更追加当事人规定》 |

## 四、执行中的期限表

| 事项 | 期限 | 说明 |
|---|---|---|
| 执行通知书发出 | 立案后 10 日内 | 法院向被执行人发出 |
| 被执行人申报财产 | 收到通知后 | 拒绝报告/虚假报告可罚款拘留 |
| 执行行为异议 | 收到裁定/行为发生后及时提出，书面 | 法院 15 日内审查，不服可 10 日内向上一级法院申请复议 |
| 案外人执行异议 | 执行程序终结前 | 法院 15 日内审查，不服可提执行异议之诉 |
| 执行期限 | 一般 6 个月内执结 | 超期可向上一级法院申请督促 |
| 终本后查询 | 每 6 个月可申请查询 | 以法院规定为准 |
| 保全/查封续期 | 届满前 7 日申请 | 逾期失效 |

## 五、终本（终结本次执行程序）

**条件**（《最高人民法院关于严格规范终结本次执行程序的规定（试行）》）：

1. 已向被执行人发出执行通知、责令报告财产；
2. 已穷尽财产调查措施，未发现可供执行财产或发现的财产不能处置；
3. 已向被执行人发出限制消费令，符合条件的纳入失信名单；
4. 自执行案件立案之日起已超过 3 个月；
5. 被执行人下落不明的已依法查找，妨害执行的已依法采取强制措施。

**终本后的动作**：

- 发现新财产 → 申请恢复执行（不受 2 年时效限制）；
- 可继续申请续封、限制出境、追加被执行人；
- 定期查询财产，留存查询记录；
- 被执行人死亡的，可申请变更被执行人为遗产管理人/继承人在遗产范围内承担责任。

## 六、常见错误

| 错误 | 后果 | 正确 |
|---|---|---|
| 履行期未满就申请 | 不予受理，浪费时间 | 届满次日申请 |
| 按判决落款日算 2 年时效 | 算错起算点 | 按履行期最后一日起算 |
| 申请书不写具体金额 | 立案补正，拖延 | 分项列明并附计算表 |
| 不提供任何财产线索 | 只能等总对总查询 | 能提供的都提供，并注明来源 |
| 认为终本=结案 | 放弃后续权利 | 终本后仍可恢复执行 |
| 和解后不申请中止/不提请确认 | 时效与查封脱节 | 执行和解需法院记录在案 |
| 只告公司，不查股东出资 | 空壳公司执行不到 | 核查实缴情况，符合条件追加 |
| 限高/失信自动生效 | 实际需申请 | 主动提交书面申请 |

## 七、给委托人的实话

1. 执行不是"法院帮你要钱"，法院做的是查控与强制，财产线索主要靠申请人和律师；
2. 被执行人确无财产的，任何措施都拿不到钱；
3. 终本是阶段性结束，不是权利消灭；
4. 追加被执行人、拒执罪移送都需要证据，不是写个申请就行。
