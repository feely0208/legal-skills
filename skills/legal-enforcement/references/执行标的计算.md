# 执行标的计算口径

> 依据：《最高人民法院关于执行程序中计算迟延履行期间的债务利息适用法律若干问题的解释》（法释〔2014〕8 号）、《诉讼费用交纳办法》。条号与费率以现行文本核对。

## 一、执行标的的构成

```
执行标的 = 本金
         + 一般债务利息（按生效文书确定的口径）
         + 迟延履行期间加倍部分债务利息
         + 诉讼费/保全费（由被执行人负担的部分）
         + 执行费（由被执行人负担，申请人不预交）
```

注意：**一般债务利息**与**加倍部分债务利息**是两笔，分开算、不重复、不互相计息。

## 二、加倍部分债务利息

### 公式

```
加倍部分 = 尚未清偿的金钱债务本金 × 0.000175 × 迟延履行天数
```

- 日万分之一点七五 = 0.000175，**固定值**，不随 LPR 变化；
- 计算基数**不含**一般债务利息，也不含诉讼费；
- 不计算复利；
- 非金钱债务（交付房屋、停止侵害等）不适用加倍利息，可能转为迟延履行金（金额由法院确定）。

### 迟延履行期间的起止

| 情形 | 起算 |
|---|---|
| 文书确定履行期间 | 履行期间**届满之次日**（解释表述为"届满之日起"，实务按次日起算，以法院口径为准） |
| 分期履行 | 每次履行期间届满之次日起分别计算 |
| 未确定履行期间 | 法律文书**生效之日**起 |
| 截止 | 实际履行之日 / 执行款到账之日；申请时先"暂计至申请日" |

### 部分履行的处理

被执行人部分履行的，按**剩余未清偿本金**计算，已履行部分不再计息。要给一张履行流水表，逐笔冲抵。

## 三、算例（可直接套用）

**案情**：判决本金 200,000 元，2026-06-20 生效，判决"生效之日起 10 日内付清"，即履行期最后一日 2026-06-30。被执行人分文未付，2026-10-29 申请执行。

| 步骤 | 计算 |
|---|---|
| 迟延起算日 | 2026-07-01 |
| 截止日 | 2026-10-29 |
| 天数 | 7 月 31 天 + 8 月 31 天 + 9 月 30 天 + 10 月 29 天 = **121 天** |
| 日息 | 200,000 × 0.000175 = **35 元/天** |
| 加倍部分 | 35 × 121 = **4,235 元** |
| 本金 | 200,000 元 |
| 诉讼费 | 4,300 元（按判决负担部分） |
| 执行费（法院收，被执行人负担） | 见下节 |
| 小计（不含一般利息、执行费） | **208,535 元** |

若判决另定"按年利率 6% 支付逾期利息"，则一般债务利息 = 200,000 × 6% ÷ 365 × 121 ≈ 3,978 元，**另加**在 208,535 元之上。

## 四、执行申请费

| 执行金额 | 费率 |
|---|---|
| 无执行金额或价额 | 每件 50–500 元 |
| 不超过 1 万元 | 每件 50 元 |
| 超过 1 万元至 50 万元的部分 | 1.5% |
| 超过 50 万元至 500 万元的部分 | 1% |
| 超过 500 万元至 1000 万元的部分 | 0.5% |
| 超过 1000 万元的部分 | 0.1% |

示例：执行标的 20 万元 → 50 + （200,000 − 10,000）× 1.5% = 50 + 2,850 = **2,900 元**。

**执行费由被执行人负担，申请执行人不预交**；执行完毕后从执行款中优先扣除。

## 五、常见算错情形

| 错误 | 后果 | 正确 |
|---|---|---|
| 从判决落款日算迟延 | 多算或少算天数 | 从履行期届满次日起算 |
| 把一般利息也乘 0.000175 | 重复计息，金额虚高 | 基数只含本金 |
| 基数包含诉讼费 | 多算 | 诉讼费不计入加倍部分 |
| 用 LPR 的四倍代替 0.000175 | 口径错误 | 加倍部分固定日万分之一点七五 |
| 部分履行后仍按全额计息 | 多算 | 按剩余本金 |
| 天数按"月数×30"估算 | 误差大，法院要求重算 | 逐日计算，用日历 |
| 忘记暂计截止日 | 金额无法核对 | 写明"暂计至 X 年 X 月 X 日" |
| 把执行费算进申请标的 | 立案金额不符 | 执行费单列，由法院核定 |
