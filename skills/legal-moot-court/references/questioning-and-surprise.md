# 发问提纲与证据突袭应对

> 配 `legal-moot-court` 使用。发问是庭审里唯一由律师主动控制节奏的环节，用不好会反过来帮对方举证。

## 一、先定位：发问不是什么

- 不是辩论。说理留给法庭辩论，发问只要事实。
- 不是举证。你问出来的答案，对方可以否认，不能替代书证。
- 不是表演。问得漂亮不如问得准。

目标只有一个：**让对方在庭上说出对我方有利、且与书证/常理一致的事实**，或者暴露其陈述的矛盾。

## 二、三种句式

| 句式 | 形式 | 适用 | 风险 |
|---|---|---|---|
| 开放式 | 「请说明……」 | 己方证人陈述经过；法官询问 | 给对方发挥空间，庭上少用 |
| 封闭式 | 「是不是」「有没有」「哪一天」「多少」 | 对对方当事人、对方证人 | 连续否定会显得咄咄逼人，需节奏 |
| 选择式 | 「是 A 还是 B」 | 逼对方在两项中选一项 | 两项都不利时对方会答「都不是」，需预判 |

**庭上主用封闭式，开放式只留给己方证人的铺垫。**

## 三、对对方当事人：三条线

### 3.1 设计规则

1. **一次只问一件事**。复合问题（「你是不是没验收也没付款」）会给对方「部分否定」的空间。
2. **只问已经知道答案的问题**。答案来自书证、己方证人、常理；不知道答案的问题，庭上不问。
3. **不问「为什么」**。为什么 = 邀请解释 = 给对方讲故事的机会。
4. **先易后难**。先用无争议事实建立节奏，再问关键点，最后收口。
5. **关键点只问一次**。问两遍等于提示对方「这题重要，想清楚再答」。

### 3.2 组合套路

以「设备是否验收」为例：

```
铺垫：这批设备是 2023-04-10 到你们厂的，对吗？
铺垫：到货当天，是谁签的收货单？
锁定：收货单上写的是「收到货物 3 台」，没有写「验收合格」，对吗？
锁定：签收之后，你们有没有开箱通电？
收口：第一次通电运行，是哪一天？
```

四问之内拿到「签收 ≠ 验收 + 实际通电时间」，比一段辩论有用。

### 3.3 对方答「记不清」怎么办

- 先给锚点：「是 4 月，还是 5 月？」——把「记不清」逼成「二选一」；
- 再对书证：「这份 4 月 12 日的邮件，是不是你发的？」
- 仍不答，记录下来，在辩论阶段主张「对该事实未能作出合理解释」。

## 四、对证人：五步顺序

| 步骤 | 问什么 | 目的 |
|---|---|---|
| 1 资格 | 姓名、职业、与当事人关系、有无利害 | 建立弹劾基础 |
| 2 感知 | 当时在哪、距离多远、是否在场、光线/噪音 | 质疑能否看见/听见 |
| 3 记忆 | 何时回忆、有无当场记录、是否与他人讨论过 | 质疑记忆可靠性 |
| 4 表达 | 能否准确描述、有无障碍 | 质疑陈述能力 |
| 5 实体 | 关键事实 | 锁定或弹劾 |

**弹劾的合法方式**：指出前后陈述不一致、与书证矛盾、与常理不符、存在利害关系。不攻击人格，不质问动机。

## 五、诱导性发问：边界

- 对**己方证人**：不得诱导。问了会被审判长制止，证言可信度连带受损。
- 对**对方当事人、对方证人**：实践中允许一定引导，但以审判长许可为限；被制止立即改开放式，不争辩。
- 判断标准：问题里是否已经包含答案。含答案即为诱导。

## 六、发问禁忌对照表

| 错误问法 | 为什么错 | 改成 |
|---|---|---|
| 「你为什么违约？」 | 递解释机会 | 「合同约定的付款日是几号？那天付了吗？」 |
| 「你是不是早就知道设备有问题？」 | 问心理状态，无法举证 | 「卖方在发货前，有没有向你方提供检测报告？」 |
| 「你们公司管理是不是很混乱？」 | 评价性、攻击性 | 「这份送货单，为什么没有签收人身份证号？」 |
| 「证人，你和被告是什么关系？」（问完就停） | 只问不追，弹劾无效 | 追问「2023 年至今，你是否在被告处领取报酬？」 |
| 「你说的是真的吗？」 | 无意义，证人只会答「是真的」 | 用书证矛盾点直接对质 |
| 连续十个封闭问题 | 对方警觉，法官不耐 | 3–5 问一组，穿插书证出示 |
| 问自己不知道答案的问题 | 可能问出不利事实 | 删掉 |
| 「根据法律规定，你应当……」 | 发问变辩论 | 删掉，留到辩论 |
| 重复问同一个关键点 | 提示对方重点 | 只问一次，矛盾点留到辩论 |
| 对己方证人诱导 | 被制止，证言受损 | 开放式，让证人自己说 |

## 七、不为对方递刀：删除清单

发问前逐条自检，命中任一条就删：

- 可能引出「我方也曾违约/迟延/知情」的问题；
- 可能让对方向法庭说明其抗辩理由的问题；
- 可能补强对方证据链条的问题（如问出对方曾书面催告）；
- 答案有多种可能、且每种都不利于我方的问题；
- 涉及我方尚未核实的内部事实的问题。

## 八、证据突袭：三级应对

### 8.1 先判断三件事

1. **是否在举证期限内**：逾期即为程序异议的理由；
2. **是否属于「新的证据」**：一审庭审后新发现、客观原因无法取得等；
3. **是否与基本事实有关**：有关则法院可能采纳，只是训诫/罚款，不能指望排除。

### 8.2 三级应对

| 级别 | 动作 | 话术要点 |
|---|---|---|
| 一级：程序异议 | 当庭提出逾期举证，要求对方说明理由 | 「该证据未在举证期限内提交，请法庭责令其说明理由。」 |
| 二级：实体质证 | 要求出示原件、核对形成时间与来源；当庭只质证三性，保留详细意见 | 「对真实性暂不认可，请求核对原件；关联性与证明目的庭后书面质证。」 |
| 三级：留后手 | 申请休庭/延期，庭后提交书面质证意见与反驳证据 | 「因该证据当庭出示，我方需核实，申请给予质证期限。」 |

依据：《民事诉讼法》第 68 条（及时提供证据、逾期举证的处理）、《民诉法解释》第 102 条（故意或重大过失逾期举证的后果）。条号与现行文本须回原文核对。

### 8.3 不要做的事

- 不要只说「不认可」而不提理由——等于没质证；
- 不要当庭对不熟悉的证据逐页发表意见——容易被抓住漏洞；
- 不要情绪化指责对方「搞突然袭击」——记录在案即可；
- 不要拒绝质证——拒绝质证可能被视为放弃质证权利。

## 九、其他突发

| 突发 | 处理 |
|---|---|
| 证人当庭翻证 | 先问「此前在 X 处的陈述是否属实」，再出示书面陈述；不追骂 |
| 对方情绪激动 | 停止发问，请法庭维持秩序；不与之对吵 |
| 法官打断发问 | 立即停止，问「是否可以换个方式提问」；不争辩 |
| 法官当庭要求表态 | 程序性可表态，实体一律「庭后书面补充」 |
| 当庭提出调解 | 只谈已授权区间；超出即「需回去请示」 |
| 线上庭审断线 | 立即书面告知书记员并留存记录，申请延期或补庭 |

## 十、自检清单

- [ ] 每个问题只问一件事
- [ ] 每个问题我都知道答案，且答案对我方有利
- [ ] 没有「为什么」「你怎么看」类开放问题（己方证人除外）
- [ ] 关键点只问一次
- [ ] 对证人的五步顺序完整，资格与利害关系问到了
- [ ] 己方证人没有诱导性发问
- [ ] 已按「递刀清单」逐条删除风险问题
- [ ] 证据突袭有三级应对，且准备了当庭话术
- [ ] 每个问题都标了目的、预期回答、若答否则下一问
