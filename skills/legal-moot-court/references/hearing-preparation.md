# 要件式庭审准备

> 配 `legal-moot-court` 使用。核心主张：庭审准备不是「熟悉材料」，而是**把每个要件对应到证据、把每个证据对应到问法**。

## 一、四步法

```
请求权 → 构成要件 → 证据映射 → 问法与答法
```

1. **定请求权**：本案主张的是付款、赔偿、解除、返还，还是确认。一个案子可能有多个请求权，分别拆。
2. **拆要件**：每个请求权 3–6 个要件。要件来自法律规范，不来自「事情经过」。
3. **证据映射**：每个要件对应哪些证据；没有证据的要件标红，它就是对方的入口。
4. **问法与答法**：对己方不利的要件，设计防守答法；对对方薄弱的要件，设计发问。

## 二、要件表模板

以买卖合同·卖方请求支付货款为例（条号待核，用前回原文核对）：

| 要件 | 谁举证 | 现有证据 | 缺口 | 对方可能的反证 |
|---|---|---|---|---|
| 合同成立并生效 | 卖方 | 合同原件、签字页 | 无 | 盖章系伪造、签约人无权限 |
| 已交付标的物 | 卖方 | 送货单、签收记录 | 签收人身份 | 签收人非员工、仅签收外包装 |
| 价款到期 | 卖方 | 合同付款条款、验收单 | 验收是否完成 | 未验收、付款条件未成就 |
| 标的物质量符合约定 | 卖方 | 出厂检测报告 | 交付时状态的证据 | 隐蔽瑕疵、使用后损坏 |
| 买方未付款 | 卖方 | 对账函、流水 | 已付部分 | 已抵销、已部分支付 |

填表规则：

- 「谁举证」写具体一方，不写「双方」。
- 「缺口」一栏必须写具体缺什么（缺原件？缺签收人身份？缺时间点？），不写「证据不足」。
- 对方可能的反证，宁多勿少；每一条都要在第三步有应对。

## 三、举证责任分配

| 情形 | 谁承担 | 说明 |
|---|---|---|
| 一般规则 | 主张者 | 谁主张谁举证（《民事诉讼法》第 67 条） |
| 合同成立 | 主张成立的一方 | 通常为原告 |
| 已履行 | 履行方 | 付款、交付、通知各自举证 |
| 抗辩事由 | 抗辩方 | 时效、抵销、免责、质量不符 |
| 举证责任倒置 | 法律特别规定 | 环境污染、产品缺陷、医疗损害等特定情形，须逐案核对法条 |
| 自认 | 对方 | 一方陈述不利事实，另一方明确认可，可免除举证 |

**易错**：把「对方否认」当成「对方举证」。否认不转移举证责任，但会让本证的证明标准提高。

## 四、法官提问的五个来源

法官的问题基本来自这五处，按此准备不会跑偏：

1. **诉讼请求本身**：是否变更、金额怎么构成、是否主张利息/违约金、是否重复主张。
2. **要件缺口**：哪个要件证据薄，法官就会追问那个。
3. **证据形成过程**：谁做的、什么时候做的、为什么现在才提交。
4. **程序事项**：管辖、时效、主体资格、是否申请鉴定、是否追加当事人。
5. **纠纷解决**：能否调解、底线多少、是否接受分期。

## 五、问题设计：无效 vs 有效

| 无效问法 | 有效问法 | 原因 |
|---|---|---|
| 你对这个问题怎么看？ | 这份验收单上，签字的是不是你公司员工？ | 前者开放，给对方发挥空间 |
| 你们是不是故意不付款？ | 2023-09-02 之后，你方是否支付过任何款项？ | 前者问动机，无法举证 |
| 设备有没有问题？ | 设备在 2023-08 之前，是否出现过温控报警记录？ | 前者给对方概括机会 |
| 你为什么现在才说？ | 你方第一次书面提出质量异议是哪一天？ | 前者引出解释，后者锁定时间 |

原则：**问事实，不问评价；问时间点，不问原因；问封闭项，不问开放项。**

## 六、十问配比

| 档位 | 数量 | 用途 |
|---|---|---|
| 必问 | 3–4 | 每个案子都会问，回答必须背熟，控制在 30 秒 |
| 可能问 | 4–5 | 取决于证据与法官风格，准备要点即可 |
| 刁钻问 | 2 | 最不想被问到的，必须准备完整答法 + 退路 |

「刁钻问」的找法：把自己放在对方律师位置，问「这个案子最致命的弱点是什么」，把它写成法官的口吻。

## 七、各阶段动作清单

### 庭前 T-7

- 证据原件逐份核对，编号与目录一致；
- 证人是否需出庭、是否已书面申请、是否告知利弊；
- 是否需要鉴定、评估、调查取证，评估申请期限；
- 管辖异议、时效抗辩是否还有空间。

### 庭前 T-1

- 材料按争议焦点分组，不按时间堆叠；
- 准备一页「庭审提示卡」：三个必答、两个退路、一个底线；
- 线上庭审测试设备、网络、麦克风、上传通道；
- 明确分工：谁主陈述、谁质证、谁记录、谁递材料。

### 庭审中

- 法院归纳争点时，逐条比对自己的争点表；有遗漏当庭提出「还有一项争点未归纳」；
- 质证一组一质，顺序固定：真实性 → 合法性 → 关联性 → 证明目的；
- 对方发问时，先听清再答，不确定的答「需要核实」，不当庭编；
- 法官问「是否申请鉴定」，提前有决定，不在庭上临时讨论。

### 庭后

- 当日整理庭审记录，标出法官关注点与未答清的问题；
- 需要补充的书面意见，在法庭指定的期限内提交；
- 把当庭陈述与书面意见对齐，避免前后矛盾。

## 八、常见失分点

1. 把辩论意见提前到陈述阶段说完，辩论时无话可说。
2. 一揽子质证「三性均有异议」，等于没有质证。
3. 当庭承认未核实的事实，事后无法撤回。
4. 对方提交新证据，只喊「不认可」，不提出程序异议、不要求给质证时间。
5. 法官归纳争点漏项，不当庭提出，判决后再主张未审理。
6. 发问时问「为什么」，把解释机会递给对方。
7. 对己方证人使用诱导性发问，被审判长制止，证言可信度受损。
8. 调解时超出授权当庭答应，事后无法履行。

## 九、自检清单

- [ ] 每个请求权都拆到了要件，没有用「事情经过」代替
- [ ] 每个要件都有证据或明确标了缺口
- [ ] 举证责任逐项写清，没有「双方举证」
- [ ] 十问按要件排序，含 2 个刁钻问
- [ ] 每问都有 30 秒答法与雷区
- [ ] 庭前 T-7/T-1 清单逐项打过勾
- [ ] 庭审分工到人，物料清单齐全
- [ ] 调解底线与授权区间已书面确认
