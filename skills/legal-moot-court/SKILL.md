# 庭审模拟与对抗预演技能

## 这个技能解决什么

开庭前的准备，多数人做成「把材料再看一遍」。真正让人在庭上失分的，是三件没准备的事：法官问了一个没想过的问题、对方打了一个没预案的点、自己发问反而替对方把证据补圆了。

本技能把一场庭**提前演一遍**：站在法官位置想他会问什么，站在对方位置找他最强的打法，站在自己位置把发问顺序排好。产出是两份能直接带上庭的东西，不是事后总结。

**模拟不等于预测。** 推演得再细，也不代表法官会这么问、法院会这么判。本技能不评估胜率、不承诺结果。

## 适用 / 不适用

| 适用 | 不适用 |
|---|---|
| 开庭前 1–14 天，要做庭前准备 | 要起草答辩状、代理词、上诉状 → 诉讼文书类技能 |
| 要预判法官关注点、准备应答口径 | 要逐份证据写质证意见 → `legal-evidence-examination` |
| 要设计对对方当事人/证人的发问 | 要整理证据目录、证据链 → `legal-evidence-catalog` |
| 对方可能提新证据，要有应急预案 | 要检索法条与类案 → `legal-research` |
| 实习律师、新执业者的庭审训练 | 要出正式法律意见书 → `legal-opinion` |

## 输入

**必需**

1. 角色与立场：代理原告 / 被告 / 第三人；当事人是自然人还是公司。
2. 案由与诉讼请求（含金额、是否已变更）。
3. 起诉状、答辩状（有一份即可，缺的那份按对方立场推演）。
4. 证据目录或材料，至少要有证据编号与证明目的。
5. 事实时间线（签约、履行、违约、催告、起诉）与程序信息（审级、独任/合议、开庭日期、线上线下）。

**可选**：对方证据、此前庭审笔录、鉴定意见、法官公开裁判文书、类案。

**追问规则**：证据编号、金额、日期、诉讼请求项数，缺一项问一项，不猜。没有证据目录也能做，但发问提纲里会出现大量【待补：证据 X】，需在交付时明说。

## 工作流程

### 第零步：读法律档案

先读 `~/.deepwhale/深鲸法律档案.md`。不存在时，把仓库里的 `templates/法律档案.md` 复制过去，逐项问用户：角色、立场、执业地域、行文风格、风险偏好、升级链。没填的不要假设。

档案里的「风险偏好」决定第三步应对尺度：保守型只写有证据支撑的回应，进取型才设计主动出击的问题。本次委托与档案不一致时，以本次为准并记下差异。

### 第一步：事实时间线 + 要件表

先做两张表，后面所有推演都从这两张表长出来：

- 事实表：`时间｜事件｜证据编号｜证明目的｜对方是否认可`
- 要件表：`要件｜谁举证｜现有证据｜缺口｜对方可能的反证`

要件按请求权基础拆，不按「事情经过」拆。方法见 `references/hearing-preparation.md` 第一节。

**没有证据支撑的要件，就是对方的攻击入口**，在第二步要重点标记。

### 第二步：法官视角——按要件顺序出 10 问

法官的问题不是随机的，通常沿三条线：**要件是否成立 → 证据是否可信 → 程序是否合规**。

1. 每个核心要件配 1–2 问，合计 10 问；不按时间顺序排，按要件顺序排。
2. 问题必须「法官真的会问」，不是律师想问对方的问题。典型来源：诉讼请求是否变更、金额怎么算出来的、证据来源与形成过程、逾期举证的理由、是否申请鉴定、有无调解可能。
3. 每问写三行：**法官为什么问（他担心什么）→ 我方 30 秒回答 → 回答的雷区**。
4. 分三档：`必问`（每个案子都会问）/ `可能问` / `刁钻问`（最不想被问到的，必须准备）。

「刁钻问」至少 2 个。全是必问的预案，等于没做预案。

### 第三步：对方视角——最强攻击点与应对

按这个顺序找攻击点，越靠前越致命：**证据能力**（能不能用）→ **证明力**（能证明到什么程度）→ **要件缺失**（根本没证）→ **法律适用**（用错法）→ **程序**（管辖/时效/主体）。

每个攻击点写四栏：`攻击点｜对方会怎么说（尽量用原话）｜我方应对｜兜底（退到哪一步）`。

应对只有三种合法路径：**事实反驳**（不是这样）、**证据反击**（有证据证明不是这样）、**法律区分**（即使是事实，法律上也不产生该效果）。写「我们会据理力争」不算应对。

**红队原则**：把对方想得比自己强。先找「如果我是对方律师，我最想打哪里」，再写防守。凡是自己都觉得虚的地方，对方一定看得见。

### 第四步：己方视角——发问提纲

分两组：对**对方当事人**、对**证人**。写法与禁忌见 `references/questioning-and-surprise.md`。

对对方当事人：

- 封闭式为主（是/不是、有/没有、哪天、多少），一次只问一件事；
- 只问自己已经知道答案、且答案对我方有利的问题；
- 不问「为什么」，那是给对方解释机会；
- 每问标注：目的 / 预期回答 / 若答否则下一问 / 风险。

对证人：

- 先问资格与利害关系（与当事人什么关系、有无利害）；
- 再问感知条件（当时在哪、光线/距离/是否在场）；
- 再问记忆与表达（何时回忆、有无记录）；
- 最后才问实体事实。

**不为对方递刀**：任何可能引出对我方不利事实的问题，删掉。发问不是辩论，说理留给法庭辩论。

### 第五步：庭审流程时间表

按阶段排，每阶段写「我方动作 / 时间 / 负责人 / 物料」；阶段顺序依据《民事诉讼法》法庭调查、法庭辩论的规定（条号待核，庭前核对）。

| 阶段 | 关键动作 | 常见失误 |
|---|---|---|
| 庭前 T-7～T-1 | 证据原件、证人通知、鉴定/管辖异议评估、设备调试、角色分工 | 原件没带、线上庭审未测设备 |
| 宣布开庭·核对身份 | 授权手续、代理权限（是否特别授权） | 授权书没带、权限不足 |
| 法庭调查·陈述与答辩 | 按诉讼请求逐项陈述，不展开辩论 | 把辩论意见提前说完 |
| 法庭调查·归纳争点 | 记录法院归纳的争点，与自己的争点表比对 | 法院归纳漏项，未当庭提出 |
| 法庭调查·举证质证 | 一组一质，先真实性再合法性再关联性 | 一揽子质证，事后无法补充 |
| 法庭调查·法官询问 | 按第二步的 10 问应答 | 临场编事实 |
| 法庭辩论 | 按争点顺序，先结论后依据 | 重复质证意见、情绪化 |
| 最后陈述·调解 | 一句话立场 + 请求；预设调解底线与授权区间 | 长篇重复、当庭答应超出授权 |

### 第六步：证据突袭与突发预案

按「先程序、后实体、留后手」处理，不要当庭硬扛：

| 突发 | 第一步 | 第二步 | 后手 |
|---|---|---|---|
| 对方提交新证据 | 核对是否在举证期限内，提出逾期举证异议 | 要求当庭出示原件、给质证时间 | 申请休庭/延期，庭后提交书面质证意见 |
| 对方申请新证人 | 核对是否在举证期限内、是否已通知 | 就资格与利害关系发问 | 申请延期，准备证人背景调查 |
| 变更诉请 / 当庭反诉 | 是否属新请求、是否需重新指定举证期限；反诉条件与管辖 | 当庭表示是否需答辩期 | 申请休庭、评估移送 |
| 法院当庭要求表态 | 只表态程序性事项 | 实体问题一律「庭后书面补充」 | 记录当庭陈述，避免口误 |
| 线上庭审断线/设备故障 | 立即书面记录并告知书记员 | 申请延期或重新开庭 | 留存截图与通话记录 |

依据：《民事诉讼法》第 68 条（及时提供证据、逾期举证的处理）、《民诉法解释》第 102 条（故意或重大过失逾期举证的后果），条号与现行文本需回原文核对。

## 输出规范

**主文件 `庭审预案.md`**，八节：

1. 案件速览（当事人、请求、金额、程序、开庭时间）
2. 争点与要件表（含证据缺口）
3. 法官十问（三档，每问三行）
4. 对方最强攻击点与应对（含兜底）
5. 发问提纲摘要（详版另附）
6. 庭审流程时间表（含分工与物料）
7. 突发与证据突袭预案
8. 风险分级（🔴/🟡/⚪）与免责声明（模板见下）

**附件 `发问提纲.md`**：按「对对方当事人 / 对证人」分组，每问四栏（问题 / 目的 / 预期回答 / 风险与下一问）。

命名 `庭审预案-<案由>-<YYYYMMDD>.md`，放本次工作目录。需要正式排版用 `chinese-doc-formatter` 转 `.docx` / `.pdf`。

免责段固定写入，不得删改：

```
模拟不等于预测：本预案基于现有材料推演，法官提问、对方策略、裁判结果均可能不同。
本文件仅供内部庭审准备，不对外出具，不构成对结果的承诺。
AI 辅助生成，需承办律师复核；开庭前须核对证据原件、法条现行文本与管辖规定。
```

## 质量闸门（交付前自检）

- [ ] 法官十问按要件顺序排，不是按时间顺序；每问都有「为什么问 + 30 秒回答 + 雷区」
- [ ] 至少有 2 个「刁钻问」，且不是必问项的换皮
- [ ] 对方攻击点按「证据能力→证明力→要件→法律→程序」排序，每个都有具体应对，没有「据理力争」
- [ ] 每个攻击点都有兜底方案（退到哪一步），不是全有或全无
- [ ] 发问提纲以封闭式为主，一次一问；己方证人问题不含诱导性
- [ ] 删除了可能引出不利事实的问题（没有为对方递刀）
- [ ] 流程表覆盖庭前 T-7 到最后一陈述，有分工与物料；突袭预案区分「程序异议/实体质证/庭后补书面」
- [ ] 没有编造证据、金额、日期、案号、法条条号；缺失处标【待补】
- [ ] 没有胜率、没有「必胜/稳赢/一定支持」；免责段完整；对外提交或当庭表态处已标注人工复核闸门

## 输出示例

```markdown
# 庭审预案：买卖合同纠纷（代理被告买方）

### 一、案件速览
原告 A 公司诉请尾款 68 万元及逾期利息；我方代理 B 公司，主张质量瑕疵拒付。一审·普通程序，2026-11-12 09:30 线下开庭。

### 三、法官十问（节选）
| # | 档位 | 法官问题 | 他担心什么 | 我方 30 秒回答 | 雷区 |
|---|---|---|---|---|---|
| 1 | 必问 | 对原告提交的验收单，被告是否认可真实性？ | 交付与验收事实 | 认可签收事实，不认可「验收合格」的证明力：签收仅确认数量，未开箱通电 | 不要否认签收，否则要承担举证不能 |
| 6 | 刁钻 | 合同约定 7 日检验期，被告为何四个月后才提出？ | 是否怠于行使权利 | 故障在连续运行 6 小时后才出现，收货时无法发现，属隐蔽瑕疵，自发现时起算 | 不要说「没注意看合同」 |

### 四、对方最强攻击点
| 攻击点 | 对方会怎么说 | 我方应对 | 兜底 |
|---|---|---|---|
| 逾期异议 | 「合同白纸黑字 7 天，被告自己签的字」 | 法律区分：检验期针对外观与常规性能，隐蔽瑕疵自发现时起算（《民法典》第 622 条：约定检验期过短仅及于外观瑕疵，隐蔽瑕疵适用合理期限；条号待核） | 退守减价，不主张全额拒付 |

### 八、风险分级
- 🔴 若无法证明「收货时无法发现」，隐蔽瑕疵主张不成立，逾期异议抗辩成立。
- 🟡 微信中「参数偏了」的表达是否构成卖方自认，需结合上下文。
- ⚪ 法院可能当庭询问是否申请鉴定，需提前决定并准备费用预案。

模拟不等于预测：本预案基于现有材料推演，法官提问、对方策略、裁判结果均可能不同。
AI 辅助生成，需承办律师复核。
```
