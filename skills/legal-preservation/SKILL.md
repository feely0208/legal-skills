# 财产保全申请技能

## 这个技能解决什么

保全的价值在于"抢时间"，但它也是**唯一一个申请人可能倒赔钱**的诉讼动作。

三类常见翻车：①只写申请不写担保，法院直接驳回；②财产线索写"对方名下银行存款"这种等于没写的信息，法院无法查控；③诉前保全做完就不管了，30 日内没起诉，保全自动解除，白花钱还打草惊蛇。

本技能按阶段生成申请书，把线索、担保、期限、风险四件事一次交清。

## 适用 / 不适用

| 适用 | 不适用 |
|---|---|
| 起诉前情况紧急，需先查封冻结 | 判决生效后申请强制执行（找 legal-enforcement） |
| 诉讼中申请保全，防止转移财产 | 证据保全（公证、勘验、鉴定材料固定） |
| 判决生效、进入执行前申请保全 | 行为保全/禁令（停止侵权、排除妨碍） |
| 保全到期需要续封 | 执行异议、案外人异议 |
| 评估担保成本与错误保全风险 | 刑事涉案财物查封（由司法机关依职权） |

相邻交接：还没起诉 → `legal-complaint`；要看对方财产流向 → `legal-evidence-chain`；执行阶段查控 → `legal-enforcement`；排版 → `chinese-doc-formatter`。

## 输入

必需：

1. 案件基本情况（案由、争议金额、双方主体）；
2. 保全阶段（诉前 / 诉中 / 执行前）；
3. 被申请人身份信息（公司全称+统一社会信用代码，或个人姓名+身份证号）；
4. **财产线索**（银行账户开户行与账号、房产坐落与产权证号、车辆车牌与车架号、股权所在公司及比例、应收账款债务人）；
5. 担保方式（现金 / 保全保函 / 房产抵押 / 保证保险 / 保证人）；
6. 紧急性理由（正在转移资产、注销公司、法定代表人失联等具体事实）。

可选：已立案的案号、管辖法院、保全标的额、是否已申请网络查控。

线索缺失：写【待补：xx】，并说明"线索不足时法院可能不予受理或仅做总对总查询"。**不要编造账号、产权证号、车牌号。**

## 工作流程

### 第零步：读法律档案

先读 `~/.deepwhale/深鲸法律档案.md`。不存在时，把仓库 `templates/法律档案.md` 复制过去，逐项问：角色、立场、执业地域、行文风格、风险偏好、升级链。重点取：风险偏好（决定担保方式和保全范围）、常用法院、对外提交前的复核人。

### 第一步：定阶段（决定担保与期限）

| 阶段 | 法律依据 | 担保 | 关键期限 | 管辖 |
|---|---|---|---|---|
| 诉前保全 | 《民事诉讼法》诉前保全条款 | **原则上必须提供**，通常相当于请求保全数额 | 采取保全后 **30 日内**必须起诉或申请仲裁，否则解除 | 被保全财产所在地 / 被申请人住所地 / 有管辖权法院 |
| 诉中保全 | 同法诉中保全条款 | 法院可责令提供，一般不超过请求保全数额的 **30%** | 随案进行，注意续封 | 受理案件的法院 |
| 执行前保全 | 同法执行前保全条款 | 参照诉中 | 法律文书生效后、执行立案前；进入执行后转执行查控 | 执行法院 |

条号以现行文本核对；担保比例依《最高人民法院关于人民法院办理财产保全案件若干问题的规定》，各地法院有细化口径，**以受理法院要求为准**。

### 第二步：写请求事项（写到能执行）

三项必须齐：**保全金额上限 + 具体财产 + 措施种类**。

> 请求对被申请人××名下价值人民币 500,000 元的财产采取保全措施，包括：①冻结其在××银行××支行账号×××内的存款；②查封其名下位于××市××区××路××号房产（产权证号【待补】）。

忌讳：只写"请求查封被申请人全部财产"（范围不明，法院不会批）、金额超过诉讼请求（超标的保全可能被认定错误）。

### 第三步：财产线索清单

按"可查控性"排序，逐条给字段（见 `references/财产线索与担保.md`）。线索来源要写明：合同、发票、转账记录、公开工商信息、实地调查。来源不明的线索标注"待核实"。

### 第四步：担保方案

给 2–3 个方案并算成本：

| 方式 | 成本 | 优点 | 缺点 |
|---|---|---|---|
| 现金/存单 | 占用资金 | 法院最认可 | 占款 |
| 保全保函（保险公司/担保公司） | 保额 0.5%–1.5%/年（市场价，需询价） | 不占款 | 需核保、有小额起收 |
| 房产抵押 | 评估+登记费 | 不占现金 | 流程慢，需无抵押 |
| 保证人担保 | 低 | 快 | 法院审查严，多要求本地单位 |

### 第五步：紧急性论证

诉前保全的核心门槛是"情况紧急，不立即申请将使合法权益受到难以弥补的损害"。要写具体事实：正在注销/减资、供应商集中催款、账户近期大额转出、法定代表人出境、涉多起被执行案件。**空泛写"怕转移财产"不构成理由。**

### 第六步：期限与续封台账

交付时给一张台账：保全裁定日 → 30 日起诉截止日 → 各类财产保全到期日（存款 1 年、动产 2 年、不动产及其他财产权 3 年）→ 续封申请日（届满前 7 日）。到期未续封，保全自动失效。

### 第七步：风险告知

必须书面提示（🔴）：

1. 申请有错误的，申请人应赔偿被申请人因保全所遭受的损失；
2. 超标的保全、保全案外人财产、明知无权利基础仍申请，被认定"错误"的概率高；
3. 诉前保全后 30 日内不起诉，保全解除，担保退还但已付保函费不退；
4. 保全不影响实体审理结果，败诉后仍要解封并可能赔偿。

## 输出规范

```
<案件目录>/
  财产保全申请书-<被申请人>-<YYYYMMDD>.md
  财产线索清单.csv
  担保方案与成本测算.md
  保全期限台账.md
  风险告知书.md
```

申请书结构：标题 → 申请人/被申请人信息 → 请求事项 → 事实与理由（含紧急性）→ 担保说明 → 此致法院 → 申请人签章 → 日期 → 附件（担保材料、线索证据、起诉材料）。

风险标注统一三档：

- 🔴 必须处理：担保未落实、保全金额超过诉请、线索指向案外人财产、30 日起诉期限无安排；
- 🟡 建议处理：线索字段不全、紧急性论证薄弱、未建立续封台账；
- ⚪ 提示：保全只解决控制财产，不解决胜诉；申请错误可能承担赔偿责任。

## 质量闸门（交付前自检）

- [ ] 阶段判断正确，担保要求与阶段匹配（诉前必须担保，诉中可 30%）
- [ ] 保全金额 ≤ 诉讼请求金额，未超标的
- [ ] 财产线索有具体字段，无编造账号/证号/车牌
- [ ] 紧急性理由有具体事实，不是套话
- [ ] 30 日起诉期限与续封时点已进台账
- [ ] 错误保全赔偿风险已书面提示
- [ ] 未承诺"一定能保全到""保证执行到位"
- [ ] 输出带「AI 辅助生成，需承办律师复核」标识
