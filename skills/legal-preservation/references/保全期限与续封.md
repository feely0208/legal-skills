# 保全期限、续封与解除

> 保全是有保质期的。过期不续，等于没保；解除不及时，可能倒赔。

## 一、关键期限总表

| 事项 | 期限 | 依据/说明 |
|---|---|---|
| 诉前保全后起诉/申请仲裁 | **30 日** | 自法院采取保全措施之日起算；逾期不办，法院应解除保全 |
| 情况紧急的保全裁定 | **48 小时内** | 法院接受申请后 |
| 裁定后开始执行 | 立即执行（通常 5 日内启动） | 以法院实际操作时间为准 |
| 对保全裁定申请复议 | **5 日** | 自收到裁定书之日起；向作出裁定的法院提出，复议期间不停止执行 |
| 法院审查复议 | **10 日** | 裁定正确的驳回，不当的变更或撤销 |
| 冻结银行存款 | **1 年** | 到期自动解除 |
| 查封、扣押动产 | **2 年** | 同上 |
| 查封不动产、冻结其他财产权 | **3 年** | 同上 |
| 申请续行保全 | 届满前 **7 日** | 逾期未申请，保全失效 |
| 执行前保全转执行查控 | 执行立案后 | 由执行法院续行查封冻结 |

复议期限依据《最高人民法院关于适用〈中华人民共和国民事诉讼法〉的解释》相关条文（条号以现行文本核对）。

## 二、期限台账模板

| 项 | 内容 |
|---|---|
| 保全裁定日期 | 【待补】 |
| 裁定法院/案号 | 【待补】 |
| 保全金额 | 【待补】 |
| 财产 1（银行存款） | 到期日 = 裁定执行日 + 1 年 |
| 财产 2（房产） | 到期日 = 裁定执行日 + 3 年 |
| 财产 3（车辆） | 到期日 = 裁定执行日 + 2 年 |
| 诉前 30 日起诉截止日 | 【待补】 |
| 续封申请日（各财产届满前 7 日） | 【待补】 |
| 承办人/提醒方式 | 【待补：日历+邮件双重提醒】 |

**台账必须在裁定作出当日建立**，不要等快到期才想起。

## 三、续行保全

1. 在保全期限届满 7 日前向作出裁定的法院提交《续行财产保全申请书》；
2. 附原裁定书、保全情况、续封必要性说明；
3. 续封一般不需要重新提供担保（法院另有要求的除外）；
4. 续封后期限重新计算，仍需登记台账；
5. 案件已进入执行的，向执行法院申请续封，避免审执衔接空档。

## 四、解除保全的情形

| 情形 | 处理 |
|---|---|
| 诉前保全后 30 日内未起诉/仲裁 | 法院依职权或依申请解除 |
| 被申请人提供担保 | 法院应裁定解除 |
| 申请人申请解除（和解、受偿） | 提交解除申请，法院裁定 |
| 保全错误、超标的 | 法院可依申请或依职权解除部分 |
| 案件审结、判决生效并履行完毕 | 申请解除 |
| 保全期限届满未续封 | 自动失效 |

**解除后要跟进**：担保物退还/保函注销、协助执行单位解封回执、征信影响消除（如冻结影响企业贷款）。

## 五、常见错误对照

| 错误 | 后果 | 正确 |
|---|---|---|
| 诉前保全后忙着谈判，忘了 30 日 | 保全解除，对方转移财产 | 立案与谈判并行，先占位 |
| 只保不续，一年后才发现 | 存款解冻，钱被划走 | 台账 + 届满前 7 日申请续封 |
| 续封申请提交太晚（届满前 1 日） | 法院来不及裁定，出现空档 | 提前 7 日，留出裁定时间 |
| 和解后不申请解除 | 对方索赔保全损失，担保被扣 | 受偿当日提交解除申请 |
| 保函有效期短于保全期 | 保函失效，法院要求补担保 | 保函期限覆盖"保全期+续封期+6 个月" |
| 只盯着主债务人，不查关联方 | 财产早被转走 | 同步查关联公司、法定代表人个人财产（有依据时） |
| 保全裁定不送达/不核对 | 不知道实际查封了什么 | 索取协助执行回执、查控反馈 |

## 六、保全与执行的衔接

- 诉中保全的案件，判决生效后申请执行时，**保全措施不自动转为执行查封**，需在执行立案时书面说明并申请续封，避免审执交接期间脱保；
- 执行前保全的，执行立案后由执行法院办理查封冻结的续行手续；
- 保全财产已足额控制且无争议的，执行阶段可直接处置，但需重新作出执行裁定。

## 七、给委托人的三句话

1. 保全要花钱（担保费/保函费/保全费），且不一定能查到财产；
2. 保全错了要赔，金额可能不小；
3. 保全只解决"抢得到"，不解决"判得赢"。

> 本文件为操作提示，具体期限以法院裁定与协助执行通知书载明为准。
