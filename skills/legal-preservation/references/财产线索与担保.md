# 财产线索与担保

> 条号以现行《民事诉讼法》及《最高人民法院关于人民法院办理财产保全案件若干问题的规定》（法释〔2016〕22 号）文本核对。各地法院有细化口径，以受理法院要求为准。

## 一、财产线索字段清单

线索的价值在于"法院拿着就能查控"。缺字段的线索等于没有。

### 1. 银行存款

| 字段 | 是否必需 | 说明 |
|---|---|---|
| 开户银行全称 | 必需 | 写到支行，如"中国工商银行杭州西湖支行" |
| 账号 | 强烈建议 | 无账号时法院只能做总对总查询，命中率低 |
| 户名 | 必需 | 与工商登记一致 |
| 账户类型 | 可选 | 基本户/一般户，基本户资金往来最频繁 |
| 线索来源 | 必需 | 合同收款账户、发票、转账回单 |

### 2. 不动产

| 字段 | 说明 |
|---|---|
| 坐落 | 精确到门牌号 |
| 不动产权证号 | 无证号时给"小区+楼栋+房号" |
| 权利人 | 是否登记在被申请人名下（登记在配偶/关联方名下的不能直接查封） |
| 抵押情况 | 有抵押的，查封后受偿顺位靠后，需评估是否值得 |
| 来源 | 不动产登记查询、合同、实地调查 |

### 3. 车辆

车牌号、车架号（VIN）、车辆识别代号、登记所有人、停放地。仅有车牌时法院可通过车管所查询。

### 4. 股权

被投资公司全称、统一社会信用代码、被申请人持股比例、认缴/实缴出资额。冻结股权需向市场监管部门送达协助执行通知。

### 5. 应收账款

次债务人全称、合同编号、到期日、金额。需提供基础合同与对账单，法院向其发出协助执行通知。

### 6. 其他

机器设备（型号、存放地）、存货、知识产权（专利号/商标注册号）、证券账户、网络店铺保证金、公积金。

## 二、线索来源的合规边界

- 公开渠道：国家企业信用信息公示系统、裁判文书网、不动产登记（需权利人或法院查询）、招投标公告；
- 合同与交易材料：收款账户、开票信息、送货地址；
- **不得**通过购买个人信息、冒充身份查询、侵入系统等方式获取——轻则线索被排除，重则涉刑。

## 三、担保规则

| 阶段 | 担保要求 | 比例口径 |
|---|---|---|
| 诉前保全 | 原则上应当提供，不提供裁定驳回 | 通常相当于请求保全数额；情况特殊可酌情 |
| 诉中保全 | 法院可责令提供 | 一般不超过请求保全数额的 30%；保全财产系争议标的的，不超过争议标的价值的 30% |
| 执行前保全 | 参照诉中 | 同上 |

**注意**：担保比例是上限而非固定值，法院会结合案件类型、申请人资信、保全紧迫性调整；知识产权、金融借款等案件有专门口径。

## 四、担保方式对比

| 方式 | 资金占用 | 费率/成本 | 办理周期 | 适用 |
|---|---|---|---|---|
| 现金/存单质押 | 100% | 无额外费率，仅利息损失 | 当日 | 金额小、时间紧 |
| 保全保函（保险公司） | 0 | 保额 0.5%–1.5%/年（市场价，需询价），多有最低收费 | 1–3 个工作日 | 金额大、需保留现金流 |
| 担保公司保函 | 0 | 略高于保险 | 1–3 个工作日 | 保险公司不承保的案件 |
| 房产抵押 | 0 | 评估费 + 抵押登记费 | 3–10 个工作日 | 有足值无抵押房产 |
| 保证人保证 | 0 | 无 | 快 | 法院审查严，多要求本地企业 |

交付时给一张成本表：保额 × 费率 + 最低收费 + 可能的评估费，算到元。

## 五、错误保全的认定与赔偿

### 常见被认定"申请有错误"的情形

1. **超标的保全**：申请保全 100 万，实际债权 30 万；
2. **保全案外人财产**：查封登记在第三方名下的财产，且无证据证明系被申请人实际所有；
3. **明知无权利基础仍申请**：债权已被清偿、合同已解除，仍申请保全；
4. **诉前保全后不起诉**：30 日内未起诉或申请仲裁；
5. **保全对象错误**：告错主体、查封同名他人账户。

### 赔偿范围

被申请人可主张：资金被冻结的利息损失、经营损失、为解除保全提供的担保费用、律师费等。案由通常为"因申请财产保全损害责任纠纷"，适用过错责任（《民法典》第 1165 条）。

### 降低风险的做法

- 保全金额严格控制在诉讼请求范围内，不"多封一点保险"；
- 线索逐条标注来源与核实状态，来源不明的写"待核实"；
- 诉前保全同步准备起诉材料，确保 30 日内立案；
- 与对方和解或债权受偿后，第一时间申请解除保全；
- 对保全必要性做书面记录（邮件、会议纪要），留痕。

## 六、常见错误对照

| 错误写法/做法 | 正确做法 | 原因 |
|---|---|---|
| "请求查封被申请人全部财产" | 写明金额上限 + 具体财产 + 措施 | 范围不明，法院无法裁定 |
| 线索只写"名下银行存款" | 给开户行、账号、户名 | 无法查控 |
| 诉前保全不附担保 | 同步提交保函/存单 | 不提供担保裁定驳回 |
| 保全金额按"可能判多少"随意放大 | 以诉讼请求为限 | 超标的可能被认定错误 |
| 保全后不跟踪 30 日期限 | 台账管理，届满前立案 | 逾期解除，打草惊蛇 |
| 查封配偶名下房产 | 先确认是否夫妻共同财产/是否有代持证据 | 可能侵害案外人权益 |
| 保函提交复印件 | 提交原件并核对保函有效期覆盖保全期 | 法院不收复印件 |

> 本文件为操作提示，不构成对具体案件的意见。
