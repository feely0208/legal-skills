# 起诉状撰写指南

以中国执业律师视角，系统性地指导起诉状的撰写。涵盖法律依据、格式规范、各类案件起诉要点、证据组织策略及注意事项。

---

## 一、起诉的法律依据

### 1.1 起诉条件的法律基础

| 法律依据 | 条款内容 | 实务要点 |
|---------|---------|---------|
| 《民事诉讼法》第122条 | 起诉必须符合下列条件：(一)原告是与本案有直接利害关系的公民、法人和其他组织；(二)有明确的被告；(三)有具体的诉讼请求和事实、理由；(四)属于人民法院受理民事诉讼的范围和受诉人民法院管辖。 | 四项条件缺一不可，立案审查时法院会逐一审查 |
| 《民事诉讼法》第123条 | 起诉应当向人民法院递交起诉状，并按照被告人数提出副本。 | 起诉状正本1份 + 副本N份（N=被告人数） |
| 《民事诉讼法》第124条 | 起诉状应当记明：原告信息、被告信息、诉讼请求和所根据的事实与理由、证据和证据来源、证人姓名和住所。 | 法定必备内容，缺少任何一项可能导致需补正 |
| 《民法典》第188条 | 向人民法院请求保护民事权利的诉讼时效期间为三年。法律另有规定的，依照其规定。 | **三年诉讼时效**，自权利人知道或应当知道权利受损及义务人之日起算 |

### 1.2 起诉状的效力

- 起诉状中的诉讼请求决定了法院的审理范围（不告不理原则）
- 起诉状中陈述的事实构成原告的主张，原告负有举证责任
- 起诉状提交后，经法院审查符合起诉条件的，应当在7日内立案（《民事诉讼法》第126条）
- 立案后，法院应当在5日内将起诉状副本发送被告（《民事诉讼法》第128条）

## 二、起诉状格式规范

### 2.1 标题

- 民事案件：**民事起诉状**
- 行政案件：**行政起诉状**
- 刑事自诉案件：**刑事自诉状**
- 刑事附带民事：**刑事附带民事起诉状**

### 2.2 当事人信息

#### 自然人原告

```
原告：姓名，性别，XXXX年XX月XX日出生，X族，
       身份证号码：XXXXXXXXXXXXXXXXXX，
       职业：XXXX，住址：XXXXXXXXXXXXXX，
       联系电话：XXXXXXXXXXX。
```

#### 法人原告

```
原告：公司全称，
       统一社会信用代码：XXXXXXXXXXXXXXXXXX，
       住所地：XXXXXXXXXXXXXX，
       法定代表人：姓名，职务：XXXX，
       联系电话：XXXXXXXXXXX。
```

#### 被告信息格式同上

注意：被告信息应尽可能完整，特别是被告的准确住址/住所地（影响管辖法院确定和文书送达）。

### 2.3 正文结构

1. **当事人信息**：原告和被告的基本信息
2. **案由**：案件的法定案由（参照《民事案件案由规定》）
3. **诉讼请求**：逐项列明，明确具体
4. **事实与理由**：系统性阐述案件事实和法律依据
5. **证据和证据来源**：逐一列明
6. **管辖依据**：说明受诉法院具有管辖权的法律依据
7. **结论**：总结诉讼请求，恳请法院支持

### 2.4 结尾格式

```
此致
XX人民法院

附：
1. 本起诉状副本X份
2. 证据材料X页
3. 原告身份证明文件

                                  原告（签名/盖章）：
                                  委托代理人（签名）：
                                  日期：    年    月    日
```

## 三、诉讼策略设计

### 3.1 原告/被告立场自动判断逻辑

```
if 用户请求"写起诉状" / "我要起诉XX" / "帮我告XX":
    用户 = 原告（最常见）
elif 用户请求"写反诉状" / "我要反诉":
    用户 = 反诉原告
elif 用户在已存在诉讼中提出独立请求:
    反诉情景，按反诉处理
else:
    默认按原告起诉处理
```

### 3.2 原告起诉的核心策略

| 策略维度 | 操作方法 | 适用场景 |
|---------|---------|---------|
| 诉讼请求设计 | 主请求→从请求→费用请求，逐层递进 | 所有案件 |
| 事实陈述 | 按时间顺序客观陈述，每项事实配证据 | 所有案件 |
| 证据组织 | 按证明力从强到弱排列证据清单 | 证据较多时 |
| 法律依据 | 引用最直接适用的法条，辅以司法解释 | 法律问题明确时 |
| 金额计算 | 明确计算基数、标准、起止时间 | 金钱给付类请求 |

### 3.3 诉讼请求的层次设计

第一层（主请求）：核心权利主张
第二层（从请求）：利息/违约金/损失赔偿
第三层（费用请求）：诉讼费用由被告承担

## 四、常见案件类型起诉要点

### 4.1 民间借贷纠纷

| 要素 | 内容 |
|------|------|
| 案由 | 民间借贷纠纷 |
| 核心证据 | 借条/欠条、银行转账凭证、微信/支付宝转账记录、现金交付的证人证言 |
| 关键事实 | 借款时间、金额、交付方式、利息约定、还款期限、已还款金额、催收记录 |
| 主要法律依据 | 《民法典》第667-680条（借款合同）、《最高人民法院关于审理民间借贷案件适用法律若干问题的规定》 |
| 诉讼请求范例 | 1. 判令被告偿还借款本金人民币XX元；2. 判令被告支付利息（以XX元为基数，自XX年XX月XX日起按年利率/月利率X%计算至实际清偿之日止）；3. 诉讼费用由被告承担 |
| 利率标准 | 出借人请求按合同约定利率支付利息的，应予支持，但双方约定的利率超过合同成立时一年期贷款市场报价利率（LPR）四倍的除外 |
| 注意事项 | 仅有借条无转账凭证时，需说明现金交付的时间、地点、在场人等细节；大额现金借款需有其他证据佐证 |

### 4.2 买卖合同纠纷

| 要素 | 内容 |
|------|------|
| 案由 | 买卖合同纠纷 |
| 核心证据 | 买卖合同/订单、送货单/签收单、发票、对账单、付款凭证、质量异议通知、催款函 |
| 关键事实 | 合同签订时间、标的物、数量、单价、总价、交货时间/地点/方式、验收情况、付款情况、质量情况 |
| 主要法律依据 | 《民法典》第595-647条（买卖合同） |
| 诉讼请求范例 | 1. 判令被告支付货款人民币XX元；2. 判令被告支付逾期付款违约金/损失（以XX元为基数，自XX年XX月XX日起按XX标准计算至实际付清之日止）；3. 诉讼费用由被告承担 |
| 违约金 | 合同约定违约金过高的（超过造成损失的30%），法院可予减少（《民法典》第585条） |
| 注意事项 | 需证明货物已交付并验收合格；如存在质量问题，需提前考虑被告可能提出质量抗辩 |

### 4.3 侵权损害赔偿纠纷

| 要素 | 内容 |
|------|------|
| 案由 | 视侵权类型而定（生命权/身体权/健康权纠纷、机动车交通事故责任纠纷、产品责任纠纷等） |
| 核心证据 | 侵权事实证明、损害后果证明（医疗费票据、鉴定报告、维修发票）、因果关系证明、被告过错证明 |
| 关键事实 | 侵权行为时间/地点/方式/行为人、损害后果（人身损害/财产损失）、侵权与损害之间的因果关系 |
| 主要法律依据 | 《民法典》第1165-1258条（侵权责任编） |
| 赔偿项目 | 人身损害：医疗费、护理费、交通费、营养费、住院伙食补助费、误工费、残疾赔偿金、死亡赔偿金、精神损害抚慰金等；财产损失：维修费、重置费、贬值损失等 |

### 4.4 离婚纠纷

| 要素 | 内容 |
|------|------|
| 案由 | 离婚纠纷 |
| 核心证据 | 结婚证、身份证、子女出生证明、财产权属证明、感情破裂证据 |
| 诉讼请求 | 1. 判令原告与被告离婚；2. 判令婚生子/女由原告抚养，被告每月支付抚养费XX元；3. 依法分割夫妻共同财产；4. 诉讼费用由被告承担 |
| 感情破裂认定 | 重婚/与他人同居、家庭暴力、遗弃虐待、赌博/吸毒恶习屡教不改、感情不和分居满2年、其他导致感情破裂的情形（《民法典》第1079条） |

### 4.5 劳动争议

| 要素 | 内容 |
|------|------|
| 案由 | 劳动争议 |
| 前置程序 | 一般需先经劳动仲裁（仲裁前置） |
| 起诉对象 | 劳动仲裁裁决书 |
| 起诉期限 | 收到仲裁裁决书之日起15日内 |
| 诉讼请求 | 工资报酬、经济补偿金/赔偿金、社保待遇、工伤待遇等 |

## 五、证据清单编写指南

### 5.1 证据分类

| 证据类型 | 示例 | 证明力 |
|---------|------|--------|
| 书证 | 合同、借条、发票、对账单、书信 | 高（特别是原件） |
| 电子数据 | 微信聊天记录、短信、电子邮件、转账电子凭证 | 中（需注意完整性和真实性） |
| 视听资料 | 录音、录像 | 中（需注意合法性） |
| 证人证言 | 证人出庭作证 | 低-中 |
| 当事人陈述 | 当事人当庭陈述 | 低（补强证据规则） |
| 鉴定意见 | 司法鉴定报告、价格认定书 | 高 |
| 物证 | 实物证据 | 高 |

### 5.2 证据清单格式

每项证据须包含：
1. **编号**：按证明力从强到弱排列
2. **证据名称**：完整准确的名称
3. **证据来源**：谁持有/从哪里获取
4. **证明目的**：该证据用于证明什么事实

## 六、管辖规则速查

### 6.1 地域管辖

| 案件类型 | 管辖法院 | 法律依据 |
|---------|---------|---------|
| 一般民事案件 | 被告住所地法院 | 《民诉法》第22条 |
| 合同纠纷 | 被告住所地或合同履行地法院 | 《民诉法》第24条 |
| 侵权纠纷 | 侵权行为地或被告住所地法院 | 《民诉法》第29条 |
| 不动产纠纷 | 不动产所在地法院（专属管辖） | 《民诉法》第34条 |
| 继承遗产纠纷 | 被继承人死亡时住所地或主要遗产所在地法院 | 《民诉法》第34条 |
| 离婚纠纷 | 被告住所地法院；被告不在国内/下落不明/被监禁等，可由原告住所地管辖 | 《民诉法》第23条 |
| 民间借贷 | 被告住所地或合同履行地（通常为接受货币一方所在地） | 《民间借贷司法解释》第3条 |
| 劳动争议 | 用人单位所在地或劳动合同履行地仲裁委/法院 | 《劳动争议调解仲裁法》第21条 |
| 协议管辖 | 合同约定的与争议有实际联系的地点法院 | 《民诉法》第35条 |

### 6.2 级别管辖

| 法院级别 | 管辖范围 |
|---------|---------|
| 基层人民法院 | 一般第一审民事案件 |
| 中级人民法院 | 重大涉外案件、本辖区有重大影响的案件、最高人民法院确定由中院管辖的案件；诉讼标的额较大的案件（各省标准不同） |
| 高级人民法院 | 本辖区有重大影响的第一审民事案件 |
| 最高人民法院 | 全国有重大影响的案件、认为应当由本院审理的案件 |

## 七、诉讼时效与期间

### 7.1 诉讼时效期间

| 类型 | 期间 | 起算点 | 法律依据 |
|------|------|--------|---------|
| 普通诉讼时效 | 3年 | 知道或应当知道权利受损及义务人之日 | 《民法典》第188条 |
| 国际货物买卖和技术进出口合同 | 4年 | 同上 | 《民法典》第594条 |
| 人寿保险金给付请求权 | 5年 | 同上 | 《保险法》第26条 |
| 最长权利保护期间 | 20年 | 权利受到损害之日 | 《民法典》第188条第2款 |
| 劳动仲裁申请时效 | 1年 | 知道或应当知道权利被侵害之日 | 《劳动争议调解仲裁法》第27条 |

### 7.2 诉讼时效中断事由

- 权利人向义务人提出履行请求（催收）
- 义务人同意履行义务（承诺还款/签署还款计划）
- 权利人提起诉讼或申请仲裁
- 与提起诉讼或申请仲裁具有同等效力的其他情形

### 7.3 诉讼时效中止

在诉讼时效期间的最后六个月内，因以下障碍不能行使请求权的，诉讼时效中止：
- 不可抗力
- 无民事行为能力人或限制民事行为能力人无法定代理人
- 继承开始后未确定继承人或遗产管理人
- 权利人被义务人或其他人控制
- 其他导致权利人不能行使请求权的障碍

## 八、起诉状撰写注意事项

### 8.1 必须做到

1. 诉讼请求明确具体、有可执行性
2. 事实陈述按时间顺序，清晰完整
3. 每项重要事实与证据对应
4. 法条引用准确，不确定的不写编号
5. 证据清单完整，注明来源和证明目的
6. 管辖法院选择合法合理
7. 诉讼时效检查到位
8. 当事人信息准确无误
9. 语言规范、语气理性

### 8.2 禁止事项

- 不得虚构事实、伪造证据
- 不得编造法条编号
- 不得使用侮辱性语言
- 不得隐瞒对诉讼时效有重大影响的事实
- 不得建议向无管辖权的法院起诉
- 不得在起诉状中提出明显不成立的诉讼请求

### 8.3 立案所需材料清单

向法院立案时一般需准备：
1. 起诉状正本1份 + 副本（按被告人数）
2. 原告身份证明（自然人：身份证复印件；法人：营业执照副本复印件 + 法定代表人身份证明）
3. 被告身份信息（尽可能提供）
4. 证据材料复印件（按被告人数+1份）
5. 授权委托书（如有委托代理人）
6. 代理人身份证明（律师执业证复印件等）
7. 诉讼费预交（根据诉讼标的额计算）
