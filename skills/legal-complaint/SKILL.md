# 起诉状技能

以中国执业律师视角，根据用户提供的案件材料和陈述，撰写规范的民事/行政起诉状，最终在桌面生成以案件名命名的文件夹，内含 Word 起诉状、PDF 文件、Markdown 报告和交互式思维导图。

## 完整工作流程

### 第零步：收集案件信息

在开始撰写起诉状前，向用户确认以下信息（信息充分时直接开始）：

#### 必须确认

| 信息项 | 说明 |
|--------|------|
| 用户立场 | 用户是原告还是被告（自动判断，用于确定起诉状类型和策略） |
| 案件基本事实 | 纠纷发生经过、时间线、涉及金额、合同/协议等 |
| 原告信息 | 姓名/名称、性别、出生日期、民族、职业、住址、联系方式（自然人）或公司全称、法定代表人、统一社会信用代码、地址（法人） |
| 被告信息 | 姓名/名称、性别、出生日期、民族、职业、住址、联系方式（自然人）或公司全称、法定代表人、统一社会信用代码、地址（法人） |
| 管辖法院 | 有管辖权的法院名称（一般为被告住所地或合同履行地法院） |

#### 自动判断原告/被告

若用户未明确说明立场，从以下线索自动推断：

- **用户说"我要起诉XX"、"我要告XX"、"想打官司"** → 用户是**原告**
- **用户说"我被XX起诉了，我要反诉"** → 用户是**原告（反诉）**
- **用户说"XX欠我钱不还"、"XX违约了"** → 用户是**原告**
- **用户说"帮我写一份告XX的起诉状"** → 用户是**原告**
- **用户提供的材料中包含"欠条"、"合同"等，要追讨债务** → 用户是**原告**
- **用户提供的材料是对方发来的律师函/催告函** → 用户可能需要起诉或应诉，需进一步确认

#### 原告/被告差异化策略

| 维度 | 原告起诉（最常见） | 被告反诉 |
|------|---------------------|----------|
| 核心目标 | 请求法院支持诉讼请求，判决被告履行义务 | 在诉讼中提出独立的反请求 |
| 诉讼策略 | 清晰陈述案件事实，逐项列明诉讼请求及法律依据 | 除答辩外，另行提出反诉请求 |
| 举证责任 | 原告承担举证责任，需列明证据和证据来源 | 就反诉请求承担举证责任 |
| 常用策略 | 完整呈现事实时间线、引用合同条款和法律规定 | 与答辩状同时提交或另行提交反诉状 |
| 法律依据 | 《民事诉讼法》第122条（起诉条件）等 | 《民事诉讼法》第54条（反诉）等 |

#### 选填信息

| 信息项 | 说明 |
|--------|------|
| 代理人信息 | 代理人姓名、律师事务所、执业证号、联系方式 |
| 补充证据材料 | 用户拟提交的证据文件（合同、欠条、转账记录、聊天记录等） |
| 特殊说明 | 财产保全申请、先予执行申请、证据保全申请等 |
| 案由说明 | 用户对案件性质的判断（如买卖合同纠纷、民间借贷纠纷等） |

### 第一步：读取案件材料

用 `scripts/read_evidence.py` 逐份读取用户提供的案件材料文件：

```bash
python "<skill目录>/scripts/read_evidence.py" "案件材料路径" --output "/tmp/complaint_input_N.txt"
```

支持以下格式：

| 格式 | 扩展名 | 读取方式 |
|------|--------|---------|
| PDF | .pdf | pdfplumber / PyPDF2 |
| Word | .docx | python-docx |
| 旧版Word | .doc | olefile |
| 图片 | .jpg/.jpeg/.png/.bmp | AI视觉识别（通过Read工具直接读取） |
| CSV | .csv | 内置 |
| 纯文本 | .txt | 内置（自动检测编码） |
| JSON | .json | 内置 |
| HTML | .html/.htm | beautifulsoup4 |

**图片文件处理**：对于图片格式的文件（.jpg/.jpeg/.png/.bmp），脚本会返回 `[IMAGE]` 标记及文件路径，此时应使用 **Read 工具**直接读取图片文件，Claude 将自动识别图片中的文字内容和图像信息。

如果文本超过 50000 字符，用 `--max-chars` 参数调整上限。

全部材料读取完成后，开始撰写起诉状。

### 第二步：梳理案件事实与诉讼策略

**务必同时阅读 `references/complaint_guide.md` 获取起诉状格式规范、法律依据汇编和各类案件的起诉要点。**

#### 2.1 案由确定

根据案件事实确定正确的案由（参照《民事案件案由规定》）：

| 常见纠纷类型 | 标准案由 |
|-------------|---------|
| 借钱不还 | 民间借贷纠纷 |
| 货款未付 | 买卖合同纠纷 |
| 工程款未付 | 建设工程施工合同纠纷 |
| 劳务报酬未付 | 劳务合同纠纷 |
| 房租纠纷 | 房屋租赁合同纠纷 |
| 侵权损害赔偿 | 生命权、身体权、健康权纠纷 / 机动车交通事故责任纠纷 |
| 离婚 | 离婚纠纷 |
| 继承 | 法定继承纠纷 / 遗嘱继承纠纷 |
| 劳动争议 | 劳动争议 |
| 股权转让纠纷 | 股权转让纠纷 |

#### 2.2 管辖法院确定

根据"原告就被告"原则确定管辖法院：

- **一般地域管辖**：被告住所地人民法院（《民事诉讼法》第22条）
- **合同纠纷**：被告住所地或合同履行地人民法院（《民事诉讼法》第24条）
- **侵权纠纷**：侵权行为地或被告住所地人民法院（《民事诉讼法》第29条）
- **不动产纠纷**：不动产所在地人民法院（专属管辖，《民事诉讼法》第34条）
- **协议管辖**：合同约定管辖法院（不得违反级别管辖和专属管辖规定，《民事诉讼法》第35条）

#### 2.3 诉讼时效检查

检查是否超过诉讼时效（《民法典》第188条：向人民法院请求保护民事权利的诉讼时效期间为三年），提醒用户：
- 诉讼时效起算点
- 是否存在诉讼时效中断/中止事由
- 超过诉讼时效的起诉风险

#### 2.4 诉讼请求设计

逐项设计诉讼请求：

```
诉讼请求1：判令被告支付货款人民币XX元
诉讼请求2：判令被告支付逾期付款违约金人民币XX元（自XX年XX月XX日起按XX标准计算至实际付清之日止）
诉讼请求3：判令被告承担本案全部诉讼费用
```

### 第三步：撰写起诉状

#### 3.1 起诉状结构

起诉状的正文按以下结构组织：

```
一、当事人信息
   - 原告信息（自然人或法人格式）
   - 被告信息（自然人或法人格式）
   - 代理人信息（如有）

二、诉讼请求
   - 逐项列明，金额明确，计算方式清晰

三、事实与理由
   （一）案件基本事实（按时间顺序）
   （二）被告违约/侵权的事实
   （三）原告遭受的损失/损害
   （四）法律依据
   （五）证据和证据来源

四、结论
```

#### 3.2 诉讼请求撰写要点

| 请求类型 | 撰写规范 | 示例 |
|---------|---------|------|
| **金钱给付** | 明确金额、计算方式、起止时间、利率/标准 | "判令被告支付货款人民币500,000元及逾期付款损失（以500,000元为基数，自2025年6月1日起按全国银行间同业拆借中心公布的贷款市场报价利率计算至实际付清之日止）" |
| **行为履行** | 明确行为内容、履行期限 | "判令被告在判决生效之日起30日内协助原告办理房屋过户登记手续" |
| **确认之诉** | 明确确认的法律关系或事实 | "确认原告与被告之间于2025年3月1日签订的《股权转让协议》合法有效" |
| **变更之诉** | 明确变更的内容 | "判令变更原、被告签订的《XX合同》第X条关于XX的约定为XX" |
| **诉讼费用** | 一般请求被告承担 | "判令被告承担本案全部诉讼费用" |

#### 3.3 事实与理由撰写框架

```
一、案件基本事实

原告与被告于XX年XX月XX日签订了《XX合同》（证据1），约定：……
（按时间顺序客观陈述案件事实，每项重要事实注明对应证据）

二、被告违约/侵权的事实

（详述被告违反约定义务或法定义务的具体行为）
1. XX年XX月XX日，被告……（证据X）
2. XX年XX月XX日，被告……（证据X）

三、原告遭受的损失

1. ……（证据X）
2. ……（证据X）

四、法律依据

1. 《中华人民共和国民法典》第XX条：……
2. 《中华人民共和国民事诉讼法》第XX条：……
3. 相关司法解释/指导案例：……

五、证据和证据来源

1. 原告身份证复印件（原告提供）
2. 《XX合同》原件（原告持有）
3. 银行转账凭证（XX银行打印）
4. 微信聊天记录截屏（原告手机保存）
5. ……
```

#### 3.4 常见案件类型的起诉要点

##### 民间借贷纠纷

| 要素 | 内容 |
|------|------|
| 核心证据 | 借条/欠条、银行转账凭证、微信/支付宝转账记录、现金交付的证人证言 |
| 关键事实 | 借款时间、金额、交付方式、利息约定、还款期限、已还款金额 |
| 主要法律依据 | 《民法典》第667-680条（借款合同）、《民间借贷司法解释》 |
| 诉讼请求范例 | 1. 判令被告偿还借款本金人民币XX元；2. 判令被告支付利息（以XX元为基数，自XX年XX月XX日起按月利率X%计算至实际清偿之日止）；3. 诉讼费用由被告承担 |

##### 买卖合同纠纷

| 要素 | 内容 |
|------|------|
| 核心证据 | 买卖合同、送货单/签收单、发票、对账单、付款凭证、质量异议通知 |
| 关键事实 | 合同签订时间、标的物、数量、单价、总价、交货情况、付款情况、质量情况 |
| 主要法律依据 | 《民法典》第595-647条（买卖合同） |
| 诉讼请求范例 | 1. 判令被告支付货款人民币XX元；2. 判令被告支付逾期付款违约金人民币XX元；3. 诉讼费用由被告承担 |

##### 侵权损害赔偿纠纷

| 要素 | 内容 |
|------|------|
| 核心证据 | 侵权事实证明材料、损害后果证明（医疗费票据、鉴定报告等）、因果关系证明 |
| 关键事实 | 侵权行为时间/地点/方式、损害后果、侵权与损害之间的因果关系、被告过错 |
| 主要法律依据 | 《民法典》第1165-1258条（侵权责任编） |
| 诉讼请求范例 | 1. 判令被告赔偿医疗费XX元、误工费XX元、护理费XX元……合计人民币XX元；2. 判令被告赔偿精神损害抚慰金XX元；3. 诉讼费用由被告承担 |

### 第四步：质量检查

#### 4.1 格式规范性检查

- [ ] 标题正确（"民事起诉状"或"行政起诉状"）
- [ ] 原告信息完整（自然人或法人所需字段齐全）
- [ ] 被告信息完整（尽量获取的身份信息、地址、联系方式）
- [ ] 诉讼请求明确、具体、可执行
- [ ] 每项诉讼请求金额明确或计算方式清晰
- [ ] 事实陈述清晰、时间线完整
- [ ] 事实与证据一一对应
- [ ] 法条引用准确
- [ ] 管辖法院正确
- [ ] 结尾格式正确（此致 + 法院名称）
- [ ] 签名栏和日期栏齐全

#### 4.2 法律逻辑检查

- [ ] 诉讼请求与事实理由之间逻辑自洽
- [ ] 各项诉讼请求之间有逻辑层次（主请求→从请求→费用请求）
- [ ] 法条引用现行有效、编号准确
- [ ] 诉讼时效未届满或有中断/中止事由
- [ ] 管辖法院的选择符合法律规定
- [ ] 不存在明显不成立的诉讼请求

#### 4.3 语言表达检查

- [ ] 用语规范、语气理性平和
- [ ] 不得使用侮辱性、攻击性语言
- [ ] 事实陈述客观、完整
- [ ] "原告""被告"指代一致

  - 起诉状正本1份 + 按被告人数准备的副本
  - 原告身份证明文件
  - 证据材料的复印件（按被告人数+1份准备）

## 起诉原则

### 必须做到

1. **诉讼请求明确具体**：每一项诉讼请求必须明确、可执行，金钱给付请求须有具体金额或明确的计算方式
2. **事实陈述清晰**：按时间顺序陈述案件事实，每项重要事实注明对应证据
3. **法条引用准确**：只引用现行有效法律法规，不确定时以"根据相关法律规定"代替，绝不编造
4. **证据清单完整**：逐一列明证据名称、来源和证明目的，形成完整证据链
5. **管辖法院正确**：根据法律规定确定有管辖权的法院，说明管辖依据
6. **时效检查到位**：检查诉讼时效，如有风险须明确提示用户
7. **语气理性平和**：使用规范法律语言，避免情绪化表达
8. **逐项核实信息**：当事人信息、金额、日期等必须准确无误
9. **立场一致**：全文保持一致的原告视角
10. **格式规范**：符合中国法院法律文书排版习惯

### 禁止事项

- 不得编造不存在的法条编号或证据
- 不得隐瞒对己方不利的重要事实（但可在律师指导下进行有利陈述）
- 不得使用侮辱性、攻击性语言攻击对方
- 不得在诉讼请求中提出超出法院管辖范围的要求
- 不得虚构事实或伪造证据（可能构成虚假诉讼罪，《刑法》第307条之一）
- 不得在起诉状中提出无法律依据的诉讼请求
- 不得将起诉状写成"诉苦书"或"批斗信"——应有理有据、依法论述
- 不得建议用户向无管辖权的法院起诉
