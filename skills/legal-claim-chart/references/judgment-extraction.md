# 判决书要素抽取与引用规范

> 配 `legal-claim-chart` 使用。目标：抽得全、标得准、引得对。

## 一、先认结构：判决书七个部位

| 部位 | 内容 | 对本技能的作用 |
|---|---|---|
| 首部 | 法院全称、文书名称、案号 | 台账「法院/案号」 |
| 当事人 | 原告、被告、第三人及代理人 | 判断主体类型（自然人/公司）、是否同一主体 |
| 程序 | 立案日期、审判组织、公开开庭、到庭情况 | 台账「程序」；缺席判决要降可比性 |
| 诉辩 | 诉讼请求、答辩意见 | 只用于定位争点，**不作极性依据** |
| 查明 | 经审理查明的事实、证据采信 | 事实相似度比对；不作极性依据 |
| 本院认为 | 说理、法律适用、对争点的回应 | **极性的唯一来源** |
| 主文 | 判决结果、诉讼费负担 | 校验说理与结果是否一致 |

尾部（上诉权告知、审判人员署名、日期）用来核对裁判日期与是否生效。

## 二、10 要素抽取表

| 要素 | 在哪找 | 怎么记 | 常见错误 |
|---|---|---|---|
| 法院 | 首部 | 全称，不写简称 | 写「某中院」，后续无法判断地域 |
| 案号 | 首部 | 原样照抄，含括号与年份 | 漏「民初/民终」，把一审当二审 |
| 裁判日期 | 尾部 | YYYY-MM-DD | 用立案日期或开庭日期 |
| 程序 | 首部 + 尾部 | 一审/二审/再审；简易/普通；缺席/到庭 | 只写「一审」，漏「缺席」 |
| 案由 | 首部或立案信息 | 按法院写法定案由 | 自己概括成「合同纠纷」 |
| 诉讼请求 | 诉辩段 | 逐项列，标金额与是否变更 | 把答辩意见混进请求 |
| 争议焦点 | 「本院认为」开头或庭审归纳 | 原文照录 | 用自己拆的争点替换法院原话 |
| 法院认定 | 「本院认为」 | 原文摘录 + 位置 | 只写结论，不写理由 |
| 裁判要旨 | 「本院认为」提炼 | 一句可复用规则 + 本案适用 | 把当事人主张写成要旨 |
| 裁判结果 | 主文 | 全部/部分支持、驳回、改判、发回 | 写「胜诉/败诉」 |

## 三、位置标注规则

三种标法，按材料形态选一种，全表统一：

1. **PDF 有页码**：`第 12 页`（用 PDF 阅读器页码，不用打印页码，两者常差 1）。
2. **文字版**：`本院认为第 3 段`（以「本院认为」为起点数段落，最稳）。
3. **Word/网页**：`第 X 节「关于……的认定」` + 首句前 8 个字。

要求：

- 每个格子至少一个位置；同一判决多处论述时，标最集中的那处，其余列在备注。
- 定位不到就写【待补：段落位置】，不要估算页码。
- 引用跨页时写「第 12–13 页」。

## 四、「法院认定」与「裁判要旨」的区别

这两栏最容易写成一锅粥，实际用途不同：

| | 法院认定 | 裁判要旨 |
|---|---|---|
| 回答什么 | 本案这个事实，法院怎么看 | 这类情形，规则是什么 |
| 写法 | 贴近原文，可含本案细节 | 去掉本案细节的规则句 |
| 用途 | 比事实相似度 | 比法律观点 |

要旨提炼句式（三选一，别自创）：

```
在【情形】下，【规则】；本案因【关键事实】，故【结论】。
【要件】的认定，应以【标准】为准，不能仅以【表面事实】判断。
当事人【行为】的，可认定/不认定【法律效果】。
```

硬规则：**要旨必须能回到原文复现**。原文没有的推论，不写进要旨栏；确有延伸，另起「分析」并标明是你的观点。

## 五、引用规范

### 5.1 完整引用四要素

法院全称 + 案号 + 裁判日期 + 程序。缺一项即为不完整引用。

```
【示例格式】甲市乙区人民法院（20XX）甲0XXX民初XXXX号民事判决书，20XX年X月X日，一审。
```

案号结构：`（年份）+ 法院代字 + 案件类型代字 + 序号`。类型代字常见 `民初`（一审）、`民终`（二审）、`民申`（再审审查）、`民再`（再审）、`执`（执行）。**类型代字写错，等于把审级写错。**

### 5.2 引原文的格式

- 直接引用加引号，并标位置：`「……」（判决 A 第 5 段）`。
- 删节用「……」，不改字、不补词。
- 长引用只留关键句，其余转述并标「转述」。
- 不得把两段不连续的文字拼成一句引文。

### 5.3 不得作为依据引用的情形

| 情形 | 处理 |
|---|---|
| 一审判决且已上诉、尚未生效 | 只能写「一审曾认为」，不进「可用依据」 |
| 已被二审改判、再审撤销 | 不引用；如必须提及，写清后续结果 |
| 只有当事人主张，法院未回应 | 不引用 |
| 裁判文书网已下架、来源不明 | 不引用，标【来源待核】 |
| 新闻报道、公众号、AI 生成的「案例」 | 一律不引用 |
| 调解书、和解协议 | 不产生裁判规则，最多证明结果 |
| 境外判决 | 不是我国法源，只能作比较法背景 |

### 5.4 效力层级（引用时的措辞）

| 类型 | 措辞 | 说明 |
|---|---|---|
| 指导性案例 | 「应当参照」 | 类似案例应当参照裁判要点（依据见最高法案例指导规定，条号待核） |
| 人民法院案例库入库案例 | 「可以参考」 | 参考价值高，但非当然拘束 |
| 公报案例、上级法院判决 | 「可作参考」 | 说理参考 |
| 同省同级、其他普通判决 | 「实践中亦有」 | 只能证明存在此种处理 |
| 外省判决 | 「外省法院有…」 | 不得表述为「法院普遍认为」 |

## 六、脱敏与保密

- 对外交付的对比表，当事人姓名、身份证号、住址、银行账号一律替换为「张某」「A 公司」。
- 案号保留（案号本身不含个人敏感信息），但如果案件不公开审理，案号也建议打码为`（20XX）甲0XXX民初XXXX号`。
- 未公开的判决、调解书、内部阅卷材料，不进对外文件。
- 表格文件默认本地保存，不上传。

- [ ] 程序栏写明简易/普通、缺席/到庭
- [ ] 「法院认定」有原文摘录，不是纯转述

- [ ] 每格都有位置标注，且全文标法统一
- [ ] 未生效、被改判、来源不明的判决已排除
- [ ] 引用措辞与效力层级匹配（参照/参考/实践中亦有）
