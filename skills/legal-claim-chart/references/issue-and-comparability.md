# 争点拆解与可比性判断

> 配 `legal-claim-chart` 使用。本文只讲方法，不评价具体案件。

## 一、争点从哪来：四步拆解法

不要从判决书里抄「争议焦点」。法院归纳的焦点是给本案用的，未必覆盖你要比的维度；而且不同判决归纳口径不一，抄来抄去矩阵的行就对不上。

正确顺序：

1. **找请求权**：本案原告依据什么请求权提出主张（付款、赔偿、解除、确认、返还……）。
2. **拆构成要件**：该请求权的成立需要哪几个要件（合同成立生效、履行、违约、损失、因果关系）。
3. **列抗辩**：被告能提的实体抗辩（未生效、已履行、同时履行、质量不符、时效、免责）。
4. **列再抗辩**：原告对抗辩的反驳（已催告、瑕疵已被明知、时效中断）。

四步走完，得到的每一个「要件是否成立」「抗辩是否成立」，就是一个争点。

## 二、争点写法：对照表

| 错误写法 | 正确写法 | 为什么错 |
|---|---|---|
| 违约金问题 | 约定违约金是否过分高于实际损失 | 是话题，不是可判断命题 |
| 质量问题 | 标的物质量是否符合约定；买方是否在合理期限内提出异议 | 一个话题里藏了两个独立判断 |
| 合同效力 | 合同是否因违反效力性强制性规定而无效 | 太宽，无法落到具体要件 |
| 对方是否有过错 | 卖方是否明知标的物存在隐蔽瑕疵而未告知 | 过错是评价，必须挂到具体行为 |
| 货款该不该付 | 买方能否以质量瑕疵为由拒付全部货款（还是只能减价） | 结论式提问，没有给抗辩留位置 |

判定标准：**一个争点应当能用「是 / 否 / 部分」回答**，且回答后能直接对应到一项诉讼请求或抗辩。

## 三、分层与编号

- 主争点 `I1`、`I2`……：对应一项请求权或一项核心抗辩。
- 子争点 `I1.1`、`I1.2`：主争点成立所需的要件。
- 争点总数 3–7 个。超过 7 个，通常是把「事实细节」当成了「争点」。

示例（买卖合同·买方拒付货款）：

```
I1 买卖合同是否成立并生效
  I1.1 是否就标的物、数量、价款达成合意
  I1.2 是否存在无效事由
I2 卖方交付的标的物是否符合约定
  I2.1 是否符合约定的质量标准
  I2.2 是否属于隐蔽瑕疵（非肉眼可查）
I3 买方是否在约定/合理期限内提出质量异议
I4 买方能否据此拒付全部货款，还是只能主张减价/修理
I5 违约金/逾期付款利息是否过高
```

## 四、常见案由的争点骨架

只给要件名称，具体条号请回原文核对；拿不准标「待核」。

### 买卖合同（买受人拒付）

成立生效 → 交付 → 质量符合约定 → 检验与通知期限 → 救济方式（拒付/减价/修理更换/解除）→ 违约金调整。

易漏：**检验期限**与**质量瑕疵**是两个争点，不能合并。逾期未提异议通常视为质量符合约定，但隐蔽瑕疵、卖方明知或保证品质的情形可能例外（《民法典》第 620–623 条、第 618 条，条号待核）。

### 民间借贷（还款）

借贷合意 → 款项实际交付 → 本金数额（有无砍头息）→ 利率约定与上限 → 已还本息抵扣 → 逾期利息/违约金 → 诉讼时效。

易漏：**交付**与**合意**分开；只有借条没有转账凭证时，交付是独立争点。

### 劳动争议（违法解除）

劳动关系是否存在 → 解除类型（协商/单方/经济性裁员）→ 解除事由是否法定 → 程序是否合法（通知工会等）→ 举证责任分配 → 赔偿金/补偿金计算基数。

易漏：**解除事由**与**解除程序**分开；程序违法也可能构成违法解除。

### 房屋租赁（欠租/解除）

合同有效 → 租金标准与支付期 → 欠付事实与金额 → 解除条件是否成就 → 通知是否到达 → 押金抵扣 → 违约金调整。

## 五、矩阵极性判定规则

| 情形 | 正确标记 | 说明 |
|---|---|---|
| 说理明确采纳 + 主文体现 | ✅ 支持 | 最稳的一类 |
| 说理采纳但主文按比例折算 | ⚠️ 部分支持 | 在格内写清比例/范围 |
| 说理否定 | ❌ 不支持 | 注意否定的是「主张」还是「抗辩」 |
| 判决未审理该争点 | ➖ 未涉及 | 如已调解、撤诉、驳回起诉 |
| 法院提了一句但未展开 | ➖ 未涉及 | 不能算支持；在备注写「仅提及」 |
| 判决驳回「其他诉讼请求」 | 视情况 | 若该争点已被主文覆盖则 ❌；若只是未主张则 ➖ |
| 缺席判决 | 谨慎 | 被告未答辩，说理通常单薄，可比性降级 |
| 一审支持、二审改判 | 以生效判决为准 | 未生效一审判决不进「可用依据」 |

三条硬规则：

1. **极性只认法院说理与主文**，不认「原告主张」「本院查明」。
2. **不要为了整齐把 ⚠️ 写成 ✅**；差异本身就是结论。
3. **➖ 和 ❌ 不能混**。前者是「没判」，后者是「判了不支持」，对本案的意义完全相反。

## 六、可比性四维评分

每维给「高 / 中 / 低」+ 一句理由。综合取**最低维**，不取平均。

| 维度 | 高 | 中 | 低 |
|---|---|---|---|
| 审级 | 二审/再审维持、指导性案例、入库案例 | 二审但被再审审查中；其他省高院 | 基层一审且无上级维持；已被改判 |
| 地域 | 本案管辖法院同省/同市 | 同省不同市；相邻省有类似口径 | 外省且无统一尺度；地方性规定相反 |
| 时间 | 法律、司法解释未变，裁判日期相近 | 跨 1–2 年，规则未变 | 跨越法律修订、新解释施行、指导性案例发布 |
| 事实 | 合同条款、履行状态、证据结构接近 | 主要事实接近，个别情节不同 | 关键事实不同（有无约定、有无鉴定、有无自认） |

理由怎么写：

- ✅「同省基层法院，2024 年判决，裁判时《民法典》及合同编通则解释均已施行，事实结构同为『验收后主张隐蔽瑕疵』。」
- ❌「都是买卖合同纠纷，应该差不多。」——案由相同不是可比性。

低可比判决不是不能用，而是只能放「背景参考」：可以说「实践中也有法院这样处理」，不能说「法院普遍认为」。

## 七、冲突归因五类与验证方法

| 归因 | 表现 | 怎么验证 |
|---|---|---|
| 法律/解释修订 | 旧判决用旧规则 | 比对裁判日期与解释施行日；查是否援引已废止条文 |
| 地域裁判尺度 | 同省一致、跨省分歧 | 查该省高院指导意见、类案检索报告；看是否有统一口径 |
| 审级效力 | 基层与上级结论不同 | 查是否被上诉/改判；上级法院同类判决优先 |
| 事实差异 | 结论不同但说理逻辑一致 | 逐项比对合同条款、履行节点、证据类型；找出「区分点」 |
| 自由裁量 | 同一规则下比例/幅度不同 | 看是否在法定或惯例区间内；幅度差异一般不构成「同案不同判」 |

**假冲突识别**：两份判决说理逻辑相同、只是事实不同，写「结论差异源于事实差异，不构成裁判分歧」。这是本技能最容易加分、也最容易写错的地方——把假冲突写成真分歧，会误导诉讼策略。

**真冲突处理**：归因找不到时，不硬编。写「存在真实裁判分歧，建议检索上级法院、人民法院案例库或指导性案例」，并把该争点标 🔴。

## 八、自检清单

- [ ] 每个争点都能用「是/否/部分」回答
- [ ] 争点来自本案请求与抗辩，不是抄判决书焦点
- [ ] 争点数 3–7 个，主/子编号一致
- [ ] 每个格子的极性有说理或主文支撑
- [ ] 「未涉及」与「不支持」没有混用
- [ ] 可比性四维都写了理由，综合取最低维
- [ ] 冲突先分「真分歧 / 假冲突」，再归因
- [ ] 没有用「案由相同」代替可比性论证
- [ ] 没有断言某判决「判错了」
- [ ] 未生效判决、被改判判决已排除出「可用依据」
